# 比赛二路同步 v0.1.2

用于 B 站多位主播观看同一比赛时，选择其中一路作为主画面，同时听多位主播的声音并合并弹幕。

## 安装与入口

1. 在源码版或 EXE 版「设置 → 插件 → 装载插件」选择 `match-sync-v0.1.2.zip`。
2. 重启这一份程序；插件卡片应显示「比赛二路同步 / 0.1.2 / 已加载」。
3. 点击关注栏底部、布局预设旁的「比赛二路」按钮。左侧关注栏保留，右侧观看区域切换为主画面与合并弹幕，不增加顶部工具栏。
4. 将左侧关注栏卡片拖到右侧观看区域；第一路加入后自动开始，再拖其他卡片加入更多直播间。通过顶部「主画面」选择想看的主播画面。
5. 再次点击「比赛二路」按钮关闭模式，停止插件取流与混音，返回原画面墙；下次开启保留已加入的房间和调节项。

已有旧版时，安装器不支持同 ID 覆盖安装。退出程序后，将新 ZIP 内 `match_sync` 文件夹的文件覆盖到这份程序的 `plugins_user/match_sync/`，再重启；配置文件无需改动。

源码开发目录 `_match_sync` 会被本体跳过，避免开发文件自动装载。ZIP 顶层目录是 `match_sync`；请使用 ZIP 安装。

## 调节

- 点击顶部「各路调节」打开或隐藏悬浮调节窗口；更多主播在该窗口内滚动查看，主画面不被调节项挤占。各路独立启用声音、调音量、启用弹幕、修改主播名称。
- 来源颜色只提供蓝、粉、紫、绿、黄、橙六种预设；界面和弹幕来源标签不显示房间号。
- 「播放偏移」同时调节该路画面、声音和弹幕：点击「+」延后、点击「−」提前，步进 0.1 秒，也可直接输入。提前只能使用已收到的内容；缓存不足时会等待画面，声音静默。旧版弹幕微调值不再使用。
- 自动同步比较共同比赛区域，估计分辨率约 0.5 秒；连续两次一致的结果才应用。自动模式将较快的一路延后到最慢的一路，额外保留约 2 秒基础缓冲。
- 若自动对齐困难，点击该路「选择比赛画面」，框选各主播画面中相同的比赛内容，避开头像、边框和字幕。这告诉插件应比较哪一块画面；正常时无需操作。切换主画面会重新确认匹配。
- 静止画面、不同比赛、遮挡、切场景、重复回放等可能无法判定时间差。界面显示匹配状态与置信度；失败时保持上次确认的偏移，可关闭自动同步并手动调整。
- 点击「停止观看」会暂停插件；再次点击「比赛二路」会关闭模式。两者均停止取流、弹幕与混音，并恢复主程序参与房间当前的静音设定。插件接管声音期间请在二路界面调音，避免两份播放器重复出声。

## 运行与资源

使用已有 FFmpeg、PySide6 与本体 B 站弹幕组件，无需额外安装 pip 包。源码从程序旁边或 PATH 找 FFmpeg；EXE 从其所在目录找。账户只沿用本体现有登录态，不写账号配置。

插件观看区域使用 FFmpeg 解码与 JPEG/PCM 滚动缓存，画面最高 1280×720、30 帧。每路最多 60 秒历史，图像内存上限 96 MiB，音频约 11 MiB；实际可用时长受画面压缩大小影响。缓存达到上限会丢弃最旧内容，较大手动延后量可能无法保留。多路解码会增加 CPU、内存与带宽开销，建议先使用 2–4 路。停止后缓存随会话释放。

原画面墙的布局与房间保留在二路界面背后，关闭模式后恢复；二路界面嵌入右侧观看区域，不弹出独立观看窗口。声音通过独立的 Qt 音频输出混合，避免多路叠加过载；设备更换时重建输出。FFmpeg 子进程按本体现有方式后台运行并加入退出清理 Job。

## 人工验收

源码版与 EXE 版应分别按以下步骤验收，安装位置和配置目录各自独立。不要把源码版验证当作 EXE 验证。

1. 点击关注栏底部「比赛二路」，将两个正在看同一比赛的 B 站关注卡片拖到右侧。应自动开始并收到两路声音和弹幕，来源标签只包含主播名；重复拖动不能添加重复房间。
2. 切换主画面，两路声音与弹幕继续。逐路关闭声音、调音量、关闭弹幕，操作只作用于该房间。
3. 自动同步至少等待 10–20 秒；画面差异较大时分别圈选共同比赛区域。观察匹配状态，再用比赛计时器、击杀提示或场景切换检查两路内容是否对齐；听辨解说应对应当前比赛内容。
4. 点击「各路调节」打开悬浮窗口，加入更多房间应只增加窗口内滚动项，不能压缩主画面。播放偏移从零点击「−」再点击「+」，应回到零；改到 +3 秒时，该路声音与弹幕一起延后，主画面选到该路时画面也延后。切换预设来源颜色，应只改变该路弹幕颜色。
5. 换成不同比赛、主播全屏聊天或静止画面，自动状态应报告匹配不足，不能凭相同启动时间报告同步成功。
6. 调整主窗口大小，二路界面应随右侧观看区域改变；点击「比赛二路」关闭，原画面墙房间与布局应恢复。遇到断流、移除房间、立即开始/停止或退出程序，主程序应继续响应，插件 FFmpeg 与弹幕工作线程最终退出。系统换音频设备后仍可继续听声音。
7. 重开插件，房间与调节项恢复；禁用插件并重启，应无插件入口；删除插件并重启，应停止加载。

自动检查已覆盖同步算法、安装与界面、本地音视频解码、退出清理，以及现有 v0.2 EXE 的插件加载。源码与 EXE 均通过系统默认音频设备的静音输出及播放时钟检查。这些检查使用合成画面和本地音视频，不连接实际账号或比赛；真实直播取流、弹幕与比赛同步效果仍需上述人工验收。

开发检查入口：`dev/selfcheck_match_sync.py --audio-device`、`dev/selfcheck_match_sync_media.py`、`dev/selfcheck_match_sync_exe.py --audio-device`。`--audio-device` 检查实际默认音频设备，只输出静音数据。

实现参考：[FFmpeg 格式与管道说明](https://www.ffmpeg.org/ffmpeg-formats.html)。
