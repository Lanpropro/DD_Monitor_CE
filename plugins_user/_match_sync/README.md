# 比赛二路同步 v0.1.13

用于 B 站及已启用平台插件的多位主播观看同一比赛时，选择其中一路作为主画面，同时听多位主播的声音并合并弹幕。

## 安装与入口

1. 在源码版或 EXE 版「设置 → 插件 → 装载插件」选择 `match-sync-v0.1.13.zip`。
2. 重启这一份程序；插件卡片应显示「比赛二路同步 / 0.1.13 / 已加载」。
3. 点击关注栏底部、布局预设旁的「比赛二路」按钮。左侧关注栏保留，右侧观看区域切换为主画面与合并弹幕，不增加顶部工具栏。
4. 将左侧关注栏卡片拖到右侧观看区域；第一路加入后自动开始，再拖其他卡片加入更多直播间。点击下方设置栏每位主播名字旁的「主画面」按钮选择想看的主播画面，「自动对齐比赛画面」也在同一栏。
5. 再次点击「比赛二路」按钮关闭模式，停止插件取流与混音，返回原画面墙。同次启动关闭再开启保留参与房间，重新取流并清除暂停状态；重启程序后参与列表为空，旧测试房间不会自动加入。重新拖入同一房间可沿用该房间的调节值。

虎牙、斗鱼、抖音等平台需先启用对应平台插件，沿用其公开直播流、画质与弹幕能力；完整多平台弹幕需使用包含该平台弹幕组件的主程序。仍通过关注卡片拖入；独立窗口也支持平台前缀（如 `huya:房间号`）或官方直播链接。

已有旧版时，安装器不支持同 ID 覆盖安装。退出程序后，将新 ZIP 内 `match_sync` 文件夹的文件覆盖到这份程序的 `plugins_user/match_sync/`，再重启；配置文件无需改动。

源码开发目录 `_match_sync` 会被本体跳过，避免开发文件自动装载。ZIP 顶层目录是 `match_sync`；请使用 ZIP 安装。

## 调节

- 右侧弹幕贯穿观看区域全高；各路设置仅占左侧视频下方的无边框滚动栏，拖动分隔线可调高度。每路控件按主播选择、声音、弹幕、偏移、画面区域和移除分组横向铺满面板，组内保持紧凑单行；宽度不足时可横向滚动。音量条旁显示 0–100 的实时数值。右上角「最小化」收起整个设置栏，左侧视频区域底部的「展开设置」恢复原有高度和调节值，期间画面、声音与弹幕继续播放。每路独立启用声音、调音量、选择声道、启用弹幕、修改主播名称。拖入第一路自动开始。
- 设置栏顶部两角与上方播放栏统一为 8 像素圆角，底部保留 12 像素圆角及半透明深色渐变底，控件采用 8 像素圆角与半透明填色。原 Tile 按钮保留本体圆角样式。
- 各平台的二路弹幕统一在昵称前用 `[主播名称]` 标注来源直播间，并采用该路预设颜色。现有粉丝牌数据缺少所属主播信息，无法可靠区分其他主播的牌子，因此二路面板不显示粉丝牌，也不虚构等级；仅修改显示副本。
- 移除最后一个直播间时立即清空画面和弹幕、停止取流与混音，不保留最后一帧；再次拖入任意支持平台的卡片自动开始。移除或重连后重新获取直播地址。
- 声道可选「原始声道 / 仅左输出 / 仅右输出」；仅左或仅右会将这一路的完整声音混为单声道再送到相应耳机一侧，切换即时生效。
- 主画面复用原画面格按钮：悬停右上角选择画质、刷新或移除，下方调音量、静音、暂停/继续、全屏与录制。画质选择重新获取该房间对应档位的流，期间显示原有缓冲动画，收到可播放帧后自动收起，不显示空房间的拖入提示；不会重启其他房间。暂停只冻结并静音主画面这一路，其他房间继续；恢复时返回当前对齐进度。录制保存原始直播流。画面格静音与设置栏的声音开关双向同步；音量数值也同步更新。按 F（或本体配置的放大快捷键）进入或退出二路主画面全屏，退出恢复视频与设置栏的分隔位置；编辑主播名称时不触发全屏。左上角仅保留 LIVE 和主画面直播间标题，不显示获取人数提示；未收到标题时暂用主播名称。
- 来源颜色只提供蓝、粉、紫、绿、黄、橙六种预设；界面和弹幕来源标签不显示房间号。开启二路时隐藏原布局的蓝色观看标记，正在由二路取流的关注卡片改用粉色边框；竖屏头像条同样隐藏旧标记并加粉框。移除或停止取流即取消粉框，退出二路恢复原布局标记。
- 偏移控件下方常驻小字说明：单位为秒，+ 正数延后本路，− 负数相对提前本路。鼠标悬停「+」「−」按钮也会分别弹出说明，涵盖画面、声音和弹幕的作用。
- 「播放偏移」同时调节该路画面、声音和弹幕：点击「+」延后、点击「−」提前，步进 0.1 秒，也可直接输入。负偏移会相对提前本路；超出基础缓冲时，系统同时延后较快的其他路，保证不读取未来画面或音频。实际缓存仍不足时会明确显示等待缓存。旧版弹幕微调值不再使用。
- 点击「对照微调」、进入偏移输入框或按「+/−」会展开各路对照画面，主画面也显示在其中；预览使用和声音相同的当前播放进度，不使用直播最新帧冒充播放帧。各路显示相对主画面的实际提前/延后秒数；可勾选「放大框选区域」查看计时器。对照期间暂停自动匹配，结束对照后按原开关继续，保留微调值。点击「最小化」同时收起对照面板。
- 自动同步比较共同比赛区域，估计分辨率约 0.5 秒；连续两次一致的结果才应用。自动模式将较快的一路延后到最慢的一路，额外保留约 2 秒基础缓冲。
- 若自动对齐困难，点击该路「选择比赛画面」，框选各主播画面中相同的比赛内容，避开头像、边框和字幕。这告诉插件应比较哪一块画面；正常时无需操作。图像指纹提高至 512 位，并优先比较连续画面中发生变化的部分；更换框选区域保留此前确认的偏移，只重新收集该路区域特征。计时器需持续变化，字体、裁剪比例或比赛不同仍可能无法确认；匹配不是读取数字的 OCR。切换主画面会重新确认匹配。
- 静止画面、不同比赛、遮挡、切场景、重复回放等可能无法判定时间差。界面显示匹配状态与置信度；失败时保持上次确认的偏移，可关闭自动同步并手动调整。
- 点击「比赛二路」关闭模式，停止取流、弹幕与混音，并恢复主程序当前的静音设定。二路期间原画面墙隐藏，后台声音由插件接管，避免原生视频覆盖和重复出声；关闭后恢复原画面墙。重新开启会刷新远程流地址，不能沿用上一次已经过期的地址。

## 运行与资源

使用已有 FFmpeg、PySide6、本体 B 站弹幕组件及平台插件提供的弹幕客户端，无需额外安装 pip 包。源码从程序旁边或 PATH 找 FFmpeg；EXE 从其所在目录找。账户只沿用本体现有登录态，不写账号配置。

插件观看区域使用 FFmpeg 解码与 JPEG/PCM 滚动缓存，默认最高 1280×720，选择蓝光或原画后最高 1920×1080，均为 30 帧，实际清晰度受片源与平台提供档位限制。每路最多 60 秒历史，图像内存上限 96 MiB，音频约 11 MiB；实际可用时长受画面压缩大小影响。缓存达到上限会丢弃最旧内容，较大手动延后量可能无法保留。多路解码会增加 CPU、内存与带宽开销，建议先使用 2–4 路。停止后缓存随会话释放。

原画面墙的布局与房间保留，二路期间隐藏，关闭模式后恢复；二路界面嵌入右侧观看区域，不弹出独立观看窗口。斗鱼二路每次启动重新申请流地址，避免复用画面墙已使用的单消费者地址；连续 15 秒未收到画面会结束当前解码并重新取流，B 站轮换候选线路，其他平台重新申请地址。网络读取也有 10 秒超时，避免一直停在加载。各平台共用相同的 FFmpeg 图像/PCM 缓存、自动匹配、手动偏移、画质、暂停、全屏及录制控制。声音通过独立的 Qt 音频输出混合，避免多路叠加过载；设备更换时重建输出。FFmpeg 子进程按本体现有方式后台运行并加入退出清理 Job。

## 人工验收

源码版与 EXE 版应分别按以下步骤验收，安装位置和配置目录各自独立。不要把源码版验证当作 EXE 验证。

1. 点击关注栏底部「比赛二路」，将两个正在看同一比赛的 B 站关注卡片拖到右侧。应自动开始并收到两路声音和弹幕，无论原有粉丝牌属于谁，昵称前都只显示一份来源主播文字标记，不显示原牌或虚构等级；重复拖动不能添加重复房间。
2. 切换主画面，两路声音与弹幕继续。若其他路解说慢约 4–5 秒，在它那一行尝试 −4 至 −5 秒，观察对照区的比赛计时器与相对偏移；较快主画面会相应延后。关闭对照时不停止取流。逐路关闭声音、调音量、关闭弹幕，操作只作用于该房间。确认音量条数值实时更新，格子静音按钮与该主播的声音开关双向一致；画质切换显示缓冲动画，收到画面后消失。
3. 自动同步至少等待 10–20 秒；画面差异较大时分别圈选共同比赛区域。观察匹配状态，再用比赛计时器、击杀提示或场景切换检查两路内容是否对齐；听辨解说应对应当前比赛内容。
4. 主画面选择按钮应紧邻各主播名字，自动对齐应在下方，各路操作应分组横向铺满面板并保持单行。弹幕应贯穿右侧全高，设置栏应仅位于左侧视频下方，能滚动查看更多房间，并可拖动分隔线调高度；点击「最小化」后整栏消失、左侧画面扩大、右侧弹幕高度不变，左侧底部「展开设置」恢复原高度和调节值。播放偏移从零点击「−」再点击「+」，应回到零；改到 +3 秒时，该路声音与弹幕一起延后，主画面选到该路时画面也延后。切换预设来源颜色，应只改变该路弹幕颜色。将两路分别选仅左、仅右，声音应分别来自耳机两侧。
5. 换成不同比赛、主播全屏聊天或静止画面，自动状态应报告匹配不足，不能凭相同启动时间报告同步成功。
6. 调整主窗口大小，二路界面应随右侧观看区域改变；按 F 应放大主画面，再按 F 或 Esc 恢复；名字编辑框中输入 f 不应全屏。左上角应只显示 LIVE 和当前主画面直播间标题。进入二路时原蓝色观看标记消失，二路取流主播出现粉框；点击「比赛二路」关闭，原画面墙房间、布局与标记应恢复。遇到断流、移除房间、立即开始/停止或退出程序，主程序应继续响应，插件 FFmpeg 与弹幕工作线程最终退出。系统换音频设备后仍可继续听声音。
7. 同次启动关闭再开启，应重新收到画面并能暂停/恢复、切换主画面和画质。重启整个程序再开启二路，参与列表应为空，第一张拖入卡片应成为主画面；禁用插件并重启，应无插件入口；删除插件并重启，应停止加载。

另需拖入虎牙、斗鱼、抖音的关注卡片，与 B 站组合切换主画面，逐路测试画质、音量/声道、弹幕、偏移和暂停。移除全部直播间应立即清空，重新拖入应自动播放。

自动检查已覆盖负偏移 4.5 秒的真实 PCM 读取与同进度双路预览、计时器跨分辨率图像匹配、框选区域放大和已确认偏移保留、主画面行按钮、音量数值、双向静音、画质缓冲、F 键及文字编辑隔离、直播标题与无人数提示、粉框与旧标记恢复、多平台接口、弹幕线程生命周期、移除全部房间后的画面清理，以及同步算法、安装与界面、本地音视频解码、退出清理，以及现有 v0.2 EXE 的插件加载。源码与 EXE 均通过系统默认音频设备的静音输出及播放时钟检查。这些检查使用合成画面和本地音视频，不连接实际账号或比赛；真实直播取流、弹幕与比赛同步效果仍需上述人工验收。

本次只更新源码和插件，不导出新的 EXE 包；EXE 检查使用已有程序的隔离副本。

开发检查入口：`dev/selfcheck_match_sync_offsets.py`、`dev/selfcheck_match_sync.py --audio-device`、`dev/selfcheck_match_sync_media.py`、`dev/selfcheck_match_sync_exe.py --audio-device`。`--audio-device` 检查实际默认音频设备，只输出静音数据。

实际直播读取检查可显式运行 `dev/selfcheck_match_sync_live.py 房间号 房间号 --seconds 25`，沿用当前登录态，只读取视频、音频数据和弹幕计数，不播放声音、不发送弹幕、不改配置。

实现参考：[FFmpeg 格式与管道说明](https://www.ffmpeg.org/ffmpeg-formats.html)。
