# 国内直播平台 v0.4.1

一个插件支持虎牙、斗鱼、抖音。添加关注卡片后，可拖入软件格子播放公开直播流，也可右键“加入画面墙”。
格子使用本体现有 VLC 播放器，支持音量、静音、暂停、换位及失败重连。
当前提供房间实际画质档位、封面、头像和平台官网图标；三个平台均不查询或显示人数。
支持静音悬停预览；弹幕留待后续。

## 使用

1. 源码环境执行 `python -m pip install -r requirements.txt`；当前开发环境已安装依赖。
   三个平台播放均需要 FFmpeg（便携包自带，源码环境可放在程序目录或 PATH 中）。
2. 双击仓库根目录 `run.cmd`，在“设置 → 插件”启用“国内直播平台”，保存并重启。
   原“虎牙观看”自动升级为该插件，保留启用状态及原关注；配置标识和目录仍为 `huya_watch`。
3. 添加带平台前缀的房间号或完整官方直播间链接：

   | 平台 | 房间号 | 官方链接格式 |
   | --- | --- | --- |
   | 虎牙 | `huya:660000` | `https://www.huya.com/660000` |
   | 斗鱼 | `douyu:36252` | `https://www.douyu.com/36252` |
   | 抖音 | `douyin:557481980778` | `https://live.douyin.com/557481980778` |

   虎牙支持字母房间标识，虎牙和斗鱼支持官方手机直播间链接；纯数字仍是 B 站房间号。
   抖音支持数字房间链接，以及带 `live_web_rid` 的分类页链接（如 `https://live.douyin.com/categorynew/4_103?live_web_rid=557481980778`）。
   分类页按 `live_web_rid` 识别直播间，`anchor_id` 不作为房间号；分享短链及个人主页需先在浏览器打开并取得直播间完整链接。
4. 房间查询完成后，关注卡片显示主播昵称、标题与直播状态，新增房间沿用
   B 站的自动上墙行为。将卡片拖入指定格子即可在该位置观看。
5. 在“设置”启用悬停预览，鼠标在已开播关注上停留 1 秒即可观看静音预览。
   展开的大卡片直接在封面内播放；简洁列表和收起后的头像使用浮层。
   竖屏顶部关注栏的浮层居中显示在卡片或头像下方，并限制在窗口内。
   移开鼠标、切换横竖屏、主播下播、删除关注或禁用插件会停止预览并清理转流进程。
   竖屏收起头像排在常规状态刷新时保留控件，避免中断正在播放的预览。
   预览独立选择网页提供的最低档位，缺少档位时沿用可用流；不会修改格子的手选画质。

## 画质

- 虎牙：读取房间的 `vMultiStreamInfo`，沿用 `sDisplayName`，使用对应的 `iBitRate/ratio`。
  “蓝光8M”“蓝光4M”等是码率档位，不能直接视为不同像素分辨率。
- 斗鱼：读取房间的 `multirates`，沿用 `name`，用对应 `rate` 请求 AVC 直播流。
  以接口实际返回的 `rate` 更新菜单选中项与画质显示；平台返回其他档位时提示请求与实际的差异。
- 抖音：按公开页面中的具名 FLV 档位选择；保留网页 SDK 的名称、分辨率及帧率。
  分辨率和帧率只显示本房间提供的数据；缺少元数据时显示原始档位名，不猜测 720P/1080P。
- 格子取流完成后才显示该房间的菜单；换平台/直播间时清空旧菜单。
  竖屏小格子的按钮保留短名称，分辨率和帧率放在完整菜单及提示中。
  旧配置的通用画质值自动落到当前最高可用档位，并保存实际选择。
  主画面“原画”、副画面“720P”的自动策略仅适用于 B 站，这三个平台保留手选档位。
  软件保存的整数画质标识仅用于菜单和配置，不是像素高度或平台原生参数。

卡片点击沿用本体的选择行为；只有额外的“用默认浏览器打开直播间”菜单会打开网页。
旧 v0.1.0 虎牙网页卡片自动迁移为格子播放。关注、排序、置顶和格子音量随配置保留。
禁用插件并保存后，三个平台的关注卡片及格子中的房间一起转为暂存，停止播放与状态查询。
重新启用并重启后恢复关注、排序、置顶与原空闲格子；原格子已被其他直播间占用时保留新内容。
关注栏只有一个平台时隐藏平台图标，混合多个平台时才显示。

使用 Streamlink 8.6.1 的网页取流协议，不是平台官方 SDK。仅处理公开直播流，
不读取登录凭据，不接入付费、登录限制或 DRM 内容。网页或 CDN 变化可能导致取流失败。
虎牙使用网页 HLS，斗鱼和抖音使用对应档位的公开 FLV。
斗鱼优先选择接口提供的普通 CDN，播放地址仅交给播放器连接，避免提前探流导致短时断开。
房间状态查询与取流独立，网络错误保留上次状态，不误报下播。
抖音网页请求生成临时访客 nonce，不读取浏览器 Cookie，也不保存该 nonce。
由 FFmpeg 复制音视频并转封装为 VLC 可播放的本机流，
归一化时间戳；不重新编码、不写录像文件、不保存带签名的地址。起播缓存约 4 秒。
首帧出现前不会触发画面静止刷新，HLS 分片允许 8 秒停帧等待，持续异常仍会恢复。

取流协议参考：[斗鱼解析器](https://github.com/streamlink/streamlink/blob/8.6.1/src/streamlink/plugins/douyu.py)、
[抖音解析器](https://github.com/streamlink/streamlink/blob/8.6.1/src/streamlink/plugins/douyin.py)。

## 验收

- 画质离线回归：`python dev/selfcheck_platform_quality.py`，覆盖三个平台原生参数、
  竖屏尺寸/帧率、档位缺失、预览隔离、换台清空菜单、配置保存与 B 站策略。
- 画质联网实测：`python dev/selfcheck_platform_quality_live.py huya:eslcs`，
  可换成 `douyu:36252` 或 `douyin:557481980778`；逐档解码并核对实际尺寸、菜单和保存值。
  如接口降档，记录请求与实际档位；不修改用户配置。
- 预览离线回归：`python dev/selfcheck_platform_preview.py`，覆盖三平台低码率、请求头、
  横竖屏封面/简洁列表/收起头像、重复悬停、删除/禁用、切方向和取消线程后的关闭。
- 预览联网实测：`python dev/selfcheck_platform_preview_live.py huya:eslcs 15`，
  房间参数可换成 `douyu:36252` 或 `douyin:557481980778`，依次验证横屏封面、
  竖屏封面、竖屏列表和竖屏收起头像的静音持续播放与转流清理。
  不修改用户配置，截图位于 `work/<平台>-preview-live/`。
- 三平台离线回归：`python dev/selfcheck_live_platforms.py`，覆盖统一插件、链接校验、
  房间资料、图片、图标、原画取流、媒体校验、请求头、真实 Qt 添加/拖放与统一禁用恢复。
- 斗鱼/抖音联网实测：`python dev/selfcheck_huya_live.py douyu:36252 60` 或
  `python dev/selfcheck_huya_live.py douyin:557481980778 60`，截图位于 `work/<平台>-live/`。
- 离线回归：`python dev/selfcheck_huya_watch.py`，覆盖链接校验、CDN 备用线路、
  请求头、后台添加、真实 Qt 拖放事件、保存恢复、旧卡片迁移与插件禁用。
- 联网实测：`python dev/selfcheck_huya_live.py 660000`，实际创建软件格子、拖入卡片，
  检查视频显示/持续解码、音频 PCM 输出、音量/静音、头像封面，以及保存后恢复播放。
  `python dev/selfcheck_huya_live.py eslcs 120` 验证 ESLCS 连续两分钟不自动刷新。
  `python dev/selfcheck_stream_relay.py` 验证转封装参数、本机监听及进程清理。
  测试不修改用户配置；截图位于 `work/huya-live/`。需要该房间正在提供公开直播流。
- 人工检查：拖入空格子和已占用格子、暂停/继续、重载、音量/静音、全屏，
  关闭重启后确认关注和格子位置保留；未开播房间应保留格子并显示未开播。
  同时确认原 B 站房间的拖放与播放正常。
