# 虎牙观看 v0.1.0

虎牙第一阶段：在左侧关注栏保存房间卡片，点击卡片或右键选择“观看直播”，使用系统默认浏览器打开虎牙官方直播页。

在“设置 → 插件”启用“虎牙观看”，保存并重启。插件 ID 为 `huya_watch`；默认启用所有插件时无需单独配置。

通过左下角“添加直播间”输入 `huya:660000` 或完整虎牙房间链接，例如 `https://www.huya.com/660000`。也支持官方手机网页链接和字母房间标识；纯数字仍按 B 站房间解析。无效或不存在的房间由虎牙网页提示。

卡片显示平台及房间标识，标记为“网页观看”。本版不抓取主播昵称、封面或开播状态，不声称“未开播”；重启后卡片保留。禁用或删除插件后保留已有卡片，点击时提示重新启用插件。浏览器中的登录和观看由虎牙网页负责，插件不读取密码、Cookie 或直播流地址。

当前 QtWebEngine 运行库未提供 H.264 支持，因此本版选择系统浏览器观看。尚未实现画面墙内嵌播放、VLC 取流及软件弹幕面板。

## 人工测试

1. 运行仓库根目录的 `run.cmd`，在插件设置中确认“虎牙观看”已启用。
2. 添加你知道正在直播的虎牙房间链接，确认左侧出现“虎牙 · 房间标识”卡片和“网页观看”标记。
3. 点击卡片，确认默认浏览器打开对应官方房间，按虎牙页面要求操作并确认画面和声音正常；换一个未开播或不存在的房间，确认由官方页面提示。
4. 用同一房间的手机链接再添加一次，确认卡片不会重复。右键“观看直播”和“用默认浏览器打开直播间”都应打开正确房间。
5. 置顶或排序卡片，关闭软件再运行，确认房间、顺序及置顶状态保留。删除关注后重启，确认不会恢复。
6. 禁用插件并重启，确认已有卡片仍在，点击会提示启用插件；重新启用并重启后可再次打开。确认 B 站房间添加与画面墙播放仍正常。

自动化检查：`python dev/selfcheck_huya_watch.py`。该检查模拟浏览器打开，真实直播画面和声音须按上述步骤验收。
