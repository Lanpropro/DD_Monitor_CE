## 五、动效规范 [补齐]

**只为这五个目的动**：反馈 / 空间连续性 / 状态指示 / 避免跳变 / 解释。

**属性**：只用 `transform`（`translate3d` / `scale` / `rotate` / `rotateY`）和 `opacity`。
**不动** `width/height/top/left/margin`（触发 layout，掉帧）。

**曲线**：
- 入场 / 退场 → **`cubic-bezier(0.23, 1, 0.32, 1)`**（强 ease-out）
- 屏上位移 / 变形 → `cubic-bezier(0.77, 0, 0.175, 1)`
- 匀速（滚动 / 弹幕）→ `linear`
- **不用 `ease-in`**（起手慢，正卡在观众盯着的那一刻）

**时长**：

| 类型 | 时长 | 参考片依据 |
| --- | --- | --- |
| 元素飞入 / 填充 | 320–520ms | — |
| 布局切换（重排） | 480–720ms | — |
| 弹层弹出 | 180–260ms | — |
| **极快切（标题爆发）** | **250–500ms** | 15.33–17.08s 实测 0.42/0.50/0.83 |
| 光标移动 | 600–900ms | — |
| 镜头位移 / 推进 | 1200–2600ms | — |
| **开场氛围长镜头** | **6000ms 量级** | 0–6.58s 实测 6.58s |
| 收尾定格 | ≥3000ms | 60.00–63.37s 实测 3.37s |

**入场不用 `scale(0)`** —— 从 `scale(0.94~0.97) + opacity:0` 起。
**多元素入场错开 40–80ms**，不齐发。
