# 成片脚本 / 时间表（60 秒）

> ⚠️ **排轴以 `SCRIPT-v2.md` 为准**（用户 2026-09-21 重排：14 拍、一条连续流程、
> 结尾全部不要）。本文件第三节那张 15 拍主表**已作废**，保留作对照；
> 其余章节（先决条件、修改记录、声音点位、时长算法、待修缺陷）仍然适用。

剪片和拍摄都用这一份。四个口径合在一起：
**成片时间轴**（第几拍、几秒、屏幕上什么字、什么色场、怎么转）、
**分镜规格**（画面在演什么、动的是什么）、
**录屏素材取窗**（哪一段录屏喂给哪一拍）、**声音点位**。
另外把**历次修改记录**单列一节（第二节），改过的东西不再只在聊天里说。

- 画幅 / 帧率：**1920×1080 / 24fps**；总长 **60.0 秒**（排轴见 `SCRIPT-v2.md`）。
- **没有口播、没有配音、没有口播字幕**：屏幕上的字就是下表「文案」列。
- 色场与窗口法规见 `STYLE-CHECK.md`；录制约束与坐标口径见 `RECORDING-STATE.md`。

## 一、先决条件（不满足就别开拍）

1. **画面墙上每一格都必须真在播**：只挑当时**正在直播**的房间上墙
   （`tools/make-take-plan.py` 会拉一次直播状态再生成计划）。
   没开播的格子是黑的、也没声音 —— 上一版就是这么废掉一半素材的。
2. **10 / 11 两拍要真有声**：这两拍成片里要听到直播的人声/音乐，
   录制时软件的音频会话必须真的放开（按 **PID** 挑会话，不能按进程名）。
3. **窗口尺寸固定 2880×1620 物理**（逻辑 1920×1080，系统缩放 150%），
   菜单坐标全部基于这个尺寸；一变就得重量。
4. **窗口内坐标口径不许再改**：见 `RECORDING-STATE.md`「坐标口径」。
5. 录制期间别碰鼠标键盘（驱动会自己移光标）。

## 六、时长核算

```
01 6.0 + 02 4.5 + 03 3.5 + 04 3.5 + 05 3.5 + 06 3.5 + 07 5.5 + 08 3.5
+ 09 3.5 + 10 3.5 + 11 3.5 + 12 3.5 + 13 3.5 + 14 4.5 + 15 4.5 = 60.0 秒
```

**静止分配**：01（墙亮完停住）、07（转完停住）、14（整拍静止）三处刻意呼吸；
其余各拍"揭示完即停"；唯一持续运动是 06/08 的弹幕。
