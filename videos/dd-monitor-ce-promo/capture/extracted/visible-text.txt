DD监控室CE —— 专为 B 站直播设计的多窗口监控与观看工具

# 一句话

把多个直播间集中显示在同一个画面墙里，最多同时管理 16 路直播画面。

# 项目简介

基于 Python、PySide6 和 VLC 的 B 站多窗口直播监控工具。提供直播状态监控、
关注导入、弹幕显示、横竖屏两套布局和单路播放控制等功能。是「DD监控室」的
二次开发版本，在保留原项目取流与播放能力的基础上，重构了界面及部分交互功能。
Windows 桌面应用，LGPL-2.1 开源。

# 功能特性（原文）

- 最多同时管理 16 路直播画面
- 横屏两套布局（平分布局 / 大带小）与弹幕布局，外加一整套竖屏预设
- 竖屏模式：顶部横栏（搜索 + 图标 + 账号那一块）、主画面 16:9 占满宽度、小画面自动铺满下面
- 拖窗口换方向时，按「能放几路」自动切到最相似的另一套布局
- 自动刷新主播开播、下播及直播间状态
- 支持开播提醒
- 支持关注列表悬停预览
- 支持主播置顶及拖动排序
- 支持 B 站扫码登录（未登录时侧栏也会露出「登录」按钮）
- 支持从 B 站账号导入关注列表
- 每个播放格可以独立设置音量、静音、画质
- 每一路可以单独路由到左声道 / 右声道
- 支持断流重连和画面卡死检测
- 支持插件（plugins_user/<名字>/plugin.py）
- 自动保存布局（分横竖屏各记一套）、音量、画质和界面状态

# 布局系统（核心卖点）

菜单里只列当前窗口方向能用的布局，分成三栏。

普通布局（横屏）：平分布局（单画面、上下两分、左右两分、四分、六分、九分）；
大带小（主画面 + 2 小、2 小 + 主画面、主画面 + 3 小、主画面 + 4 小、
上主画面 + 下 2 小、主画面 + 5 小环绕、双主画面 + 4 小）。

弹幕布局（横屏）：主画面 + 弹幕；上 1 大 + 小 + 弹幕；主画面 + 1/2/3 小 + 弹幕；
弹幕在左 + 主画面 + 2 小。

竖屏布局：主画面按 16:9 占满整宽、小画面自动铺满下面
（主画面 + 2/4/6 小；主画面 + 2/4/6 小 + 弹幕）。

换方向时的对映：把窗口在横竖屏之间拖动时，程序会按「能放几路」找最相似的那一套
接上，而不是退回某个万能布局。

# 弹幕功能

粉丝牌和 B 站表情显示、字体与字号调整、屏蔽词过滤。

# 快捷键

F 将鼠标所在的直播画面设为主画面；Esc 恢复上一个布局；
M 静音/取消静音鼠标所在的那一路；Alt+M 只保留鼠标所在画面的声音。
