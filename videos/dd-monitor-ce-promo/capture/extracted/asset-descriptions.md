# 素材清单

本项目走 **no-capture 路径**：没有可抓的官网。产品是一个 Windows 桌面应用，
品牌令牌来自软件本体的 `ddm/theme.py`（见 `tokens.json`），画面素材来自
**软件真实运行的屏幕录制**和已有的真机截图。

## 一、真机截图（已就位，`capture/assets/`）

| 文件 | 分辨率 | 内容 | 在片子里怎么用 |
| --- | --- | --- | --- |
| `overview1_Landscape_mode.png` | 3840×2160 | 横屏平分布局：左主画面 + 右侧两小 + 下排三格，侧栏关注列表可见 | 全片主力 hero 画面；可大幅 punch-in 到单格、侧栏、底部控制条 |
| `overview2_Landscape_mode.png` | 3840×2160 | 横屏弹幕布局：主画面 + 弹幕面板（粉丝牌、表情、屏蔽词） | 弹幕段落的主画面；punch-in 到弹幕行看粉丝牌和表情 |
| `overview1_Portrait_Mode.png` | 1600×2559 | 竖屏布局：顶部横栏 + 16:9 主画面占满宽 + 下方小画面铺满 | 竖屏段落的静态参考；成片以真实录屏为主，这张用于补充特写 |
| `portrait-current.png` | 1620×2531 | 竖屏当前形态 | 竖屏长图，可做纵向滑动展示 |
| `portrait-bar.png` | 1620×374 | 竖屏顶部横栏特写（搜索 + 图标 + 账号） | 顶部横栏的特写镜头 |
| `portrait-mock.png` | 2227×811 | 竖屏布局原型图 | 备选，优先级最低 |

4K 分辨率意味着在 1080p 成片里可以推到 1:1 甚至更大而不糊。

## 二、屏幕录制（待录，Step 1 之后补进 `assets/`）

录制母版为**主显示器全屏 4K30**（3840×2160，NVENC），成片时按窗口区域裁切。
计划录到的镜头（对应分镜）：

| 镜头 | 录制方式 | 依赖 |
| --- | --- | --- |
| 画面墙逐格亮起 | 从空布局开始，逐个把主播拖进画面墙 | 需要多路在播 |
| 布局变形（1→4→9） | 程序切「布局预设」菜单 | 需要多路在播 |
| 大带小 | 程序切「主画面 + 5 小环绕」 | 需要多路在播 |
| 弹幕布局 | 程序切「主画面 + 弹幕」，让弹幕滚 | 需要多路在播 |
| 横屏拖成竖屏 | 程序改窗口尺寸（走 `resizeEvent`，与手动拖动同一条代码路径） | 需要多路在播 |
| 每格独立调节 | 打开某一格的音量/静音/画质菜单 | 需要多路在播 |
| 左右声道路由 | 音量菜单里切「左声道 / 右声道」 | 需要多路在播 |
