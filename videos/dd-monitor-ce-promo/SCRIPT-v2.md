## 二、逐拍细节（拍摄与剪辑要点）

**01 / 02（10.0s）** 开头要有**简单标题**，所以把标题压到开场：
01 是"墙已经在播 + 标题压上来"（黑场，极缓推近 1.00→1.03），
02 是标题落定的那一拍——第一行逐词、第二行**瞬时替换**，副标题最后淡入后完全静止。
墙压暗到 0.28 退成底。

**03（4.5s）** ★**点击动效**：光标移到布局按钮、按下（有按下态）、菜单弹出 → 选"左右两分"
→ 窗口内部**真的裂成左右两半**。用真实录屏里的光标，不画假光标。
这是全片"演示"的开始，动效要看清楚，不要抢。

**04（3.5s）/ 05（3.5s）** 四分是**先后两刀**；九分是 chip 4→6→9 **逐级**走。
到 05 结束时墙上九格全亮——后面所有布局都基于这九路真实在播的画面。

**06（4.0s）** 1+5：主画面就位后**一个像素不动**，五小依次归位（一声一格）。

**07（6.5s）** ★**给上聚焦**：换成同布局的弹幕版（主画面 + 1 小 + 弹幕）之后，
镜头**推近弹幕格**，让弹幕流成为画面主体；弹幕自下而上一直滚（全片唯一持续运动）。
推近幅度 ~1.15，落定后不再动，留出时间让观众看清弹幕在滚。

**08（6.5s）** 竖屏动态切换：窗框先变窄变高、内部重排（侧栏消失、顶部横栏出现、
主画面按 16:9 占满宽），自动接上对映预设。一镜到底，不许切——全片最长的一次连续运动。

**09（2.5s）** 竖屏窗口**横向滑出画面**，匀速干脆，走干净。

**10（1.0s）** 一记硬切回**横屏 1+5**（形态同 06，观众一眼认出"回来了"）。

**11（4.0s）** 镜头**推近左侧关注栏**某个在播直播间：真实悬停 → 封面预览卡弹出。
（置顶/拖动排序如果塞不进 4 秒，就只留"悬停出预览"这一个动作。）

**12（7.5s）** ★**两个不同的直播间**，不是一个房间的两路：
左边那路设成**只播左声道**、右边那路设成**只播右声道**，
中间一条竖线分开，两侧等大对称。
两侧声波左先右后各起一次（ping 音高不同），停在峰值**保形不动**。
**这一拍要听到声音**——而且要让人听得出"左耳只有左边那路、右耳只有右边那路"。
选房间的标准：两路画面**一眼能分辨**（主播 / 场景 / 标题明显不同），
录制时从在播房间里挑两路差异最大的。

**13（3.0s）** 顺着上一拍的分屏：其中一路黑掉、角标转琥珀「重连中…」，
短等后自己回来。**不真演断流**（已定案），用界面特写 + 字幕带过。

**14（3.5s）★宣言卡 —— "把多个窗口，收成一个"。**
近白场，只有这一行居中大字（`display-closing` 量级），落定后**完全静止**——
全片唯一"只有字、没有窗口"的一拍，给 15 拍的墙滚动留出呼吸。
和开场那句"十六路直播，不必开十六个窗口"构成首尾呼应（开头给结论，结尾收成一句）。
> 这一拍**不用录屏素材**（纯排版）。

**15（5.0s）★切回软件 + 直播墙纵向滚动。**
参考片结尾的实测（抽帧看的，`raw/ref/refsheet.png`）：
54s 白底 + **一叠彩色卡片扇形堆叠**（"内容很多"的观感）+ 左侧工作室 logo；
56–58s 一个窗口由实变白淡出；59s 收黑；60–63s 黑场只有 **logo + 网址**定格。

照这个思路 + 用户指定的方向，15 拍这么排：
1. 从 14 的宣言卡**硬切**回软件画面墙（真实录屏，不压暗）；
2. 墙做一次**纵向滚动（从下往上）**：把场景放大到比画幅**高**（约 1.35 倍高），
   用 5 秒从下往上平移，画框里始终露出 2–3 行正在播的格子；
   要点是让观众感觉**"墙还长着，不止眼前这一屏"**——对应参考片那叠卡片的"内容比画面多"；
3. 滚到尽头时整体**极缓压暗**（0.8s），接 16 拍的收黑。

> 素素材要求：一段**画面墙静置 8–10 秒的录屏**（九分或 1+5 都行，全部在播、别碰鼠标）。
> 纵向滚动需要画面**比画幅高**，两个办法（取其一或都用）：
> a) 用**竖屏那段**素材（1080×1920，天然够高，纵向滚最自然）；
> b) 横屏墙素材放大到 1.35 倍高，超出部分被裁——放大后画质仍有 4K 母版兜底。
> 滚动只用真实录屏，不许 DOM 重画；平移与缩放都在合成里做。

**16（5.5s）★logo 收尾。**
收黑后，官方 logo 拼装：三层错位圆角窗格**由外向内逐层描边走笔** →
两个 D 字标**从左往右扫出** → **CE 亮起** → 中间那条青→紫→粉**渐变缝合线合上**；
定格后下方淡入「DD监控室CE」。
logo 用 `assets/logo.svg`（官方资产，渐变按原样，不改）；**不上 GitHub 地址**
（用户此前明确不要）。
