# 多画面画中画

从「布局预设」旁的独立「画中画」按钮进入，收起侧栏时也可从账号菜单进入。勾选当前画面墙中的直播间，预览组合并选择自动、横向、纵向、两列或三列排列；至少选中一路才能打开。小窗的「组合」可重新选择，取消保留当前组合。

选中的画面在一个独立小窗中显示，不复制整套软件界面。参考二路插件的小窗样式，整个组合保留 10px 圆角，无标题栏、额外边框和独立工具栏，多路画面贴合排列。鼠标移入显示右上角的「组合／置顶／关闭返回」三个半透明圆形图标，移出后只留下画面；悬停有功能提示，置顶状态高亮。小窗获得焦点后可按 Tab 进入图标并用键盘操作。

默认置顶，可用悬浮图标关闭置顶；拖动画面移动整个小窗，拖动四边或四角自由调整大小、比例和所在屏幕。隐藏每格底部信息条、文字播放控件和状态浮标，保留原有右键菜单、弹幕与醒目留言。组合选择窗口打开时收起悬浮图标，避免遮挡；返回监控室后恢复每格样式与交互。

监控室原画面区域显示管理与返回入口。播放器、原生视频窗口、房间、录制及各路音频参数沿用原实例；未选中的画面按原设置在后台播放。画中画运行期间隐藏主窗口到托盘不暂停播放，最小化主窗口也不隐藏小窗。画中画结束后托盘设置恢复原有作用。

关闭小窗、点击「返回」或在小窗按 Esc，恢复原监控室布局与布局比例。选择监控室新布局、应用房间预设或进入单格全屏，会先返回监控室再执行对应操作。退出软件会关闭画中画并按原流程结束播放与录制。保存小窗的位置、大小、置顶、排列和选中位置；下次启动软件不会自动弹出小窗。

## 验证与验收

`python dev/run_checks.py --script selfcheck_picture_in_picture` 使用临时配置和示例房间离屏检查选择、取消、组合、无框圆角与贴边画面、图标透明背景与显隐、画面拖动、边角缩放及最小尺寸、置顶、主窗口隐藏、布局恢复与退出，不访问账号或直播。

根入口 `run.cmd --check-picture-in-picture` 依次执行 Windows 原生本地视频检查和离屏功能回归；不打开或重启用户客户端。

Windows 原生后端可用 `QT_QPA_PLATFORM=windows` 执行 `dev/checks/bootstrap.py dev/selfcheck_picture_in_picture.py --native`。检查两路本地 MP4、真实 libmpv 核心与视频 HWND 保持不变、播放进度继续、共享弹幕和醒目留言归属、托盘及清理；该检查不代替真实直播、音频听感或跨显示器人工验收。

人工从根 `run.cmd` 启动，在画面墙中准备两到四路直播：

1. 点击全局画中画入口，勾选任意组合，预览后打开；小窗只显示所选画面。
2. 确认只有组合画面与外圈圆角，没有标题栏或额外边框；鼠标移入后右上角出现三个圆形图标，移出后隐藏。拖动画面移动小窗，拖动边角缩放，点击图钉切换置顶；最小化主窗口、切到其他应用，小窗仍可观看。
3. 点右上角四格图标修改或取消组合；取消不改变当前内容，确认后切换组合。组合窗口不受悬浮图标遮挡；检查 Tab、Enter／空格及 Esc 操作。
4. 检查各路原有声音、自然收到的弹幕与醒目留言；测试不需要发送真实弹幕。
5. 关闭小窗或按 Esc，确认原房间顺序、布局比例和声音设置恢复。再次打开检查小窗偏好。
6. 检查深浅主题、横竖屏、侧栏收起入口及跨屏缩放；退出软件后无残留小窗。
