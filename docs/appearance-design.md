# 深浅色模式与文件夹图标设计

设计日期：2026-10-13。状态：设计完成，待实现。此次设计不改变当前软件设置。
范围对应 `docs/customization-plan.md` 第一阶段，并增加独立的文件夹图标设计；玻璃效果和动态背景属于后续皮肤讨论。

## 深浅色模式

### 入口与交互

设置新增独立「外观」页面，在页面最上方放置「深色 / 浅色 / 跟随系统」三选一控件，每项配小型界面缩略图。下方预览关注卡片、文件夹、菜单和顶部提示，方便比较可读性；后续皮肤选项放在同一页面。

主界面外置主题入口改为 22×22 纯图标按钮，放在真实关注栏上方的状态工具行，位于「排序」和刷新按钮之间。使用半明半暗圆形图标，悬停提示「切换外观（当前：深色/浅色/跟随系统）」。不在底部「布局预设 / 设置」行增加文字按钮，不增加侧栏宽度或额外工具行。

竖屏沿用现有排序、刷新工具移至顶部第一行的布局，外观图标与它们同组。横屏收起时放在窄栏展开键下方，保留 22×22 点击区域，不占用关注头像和底部账号位置；竖屏收起时保留顶部图标入口。实现时须对这两种收起状态另做空间验证。

点击弹出「深色 / 浅色 / 跟随系统」菜单，勾选当前项；底部「外观设置…」直达独立页面。外置按钮与设置页面共享同一选择，不各自保存状态。全屏观看不额外覆盖视频。

交付流程：先给用户查看深浅色方案截图，用户确认后再实装；预览图不代表运行软件已支持主题切换。

点击选项立即应用并保存，无需另点确认；首次升级保持深色，不擅自改变用户现有外观。跟随系统时展示「当前：深色」或「当前：浅色」。设置中的恢复默认回到深色。

切换只重绘界面：不创建新播放器，不重新绑定视频 HWND，不重连直播，不清空弹幕，也不改变录制、布局、音量和画质。菜单与新打开的窗口使用当前模式；已打开的弹幕窗口和设置同步更新。

### 视觉规格

深色完全沿用当前软件的 `ddm/theme.py` 配色、透明度、字体、圆角、间距、局部样式与自绘效果，不采用上一版手绘方案图的深色数值。浅色采用冷灰底、白色卡片，蓝色用于选择与操作，粉色用于直播提示。视频显示区始终维持黑色，避免黑边随主题变成白边；视频内的状态浮标、控制条和滚动弹幕继续使用适合视频的深色底。

预览必须使用真实 `Sidebar`、`WallGrid` 和 `SettingsDialog` 控件构建，不再手绘替代软件布局；房间和封面可使用虚构数据，不读取真实配置。主题按钮只在独立预览进程里插入，浅色配色也只用于预览。旧方案图作废，实际按钮坐标和点击区域以新截图对应的控件几何验证为准。

选中项同时使用蓝色细边框和背景变化；键盘焦点保留清晰轮廓，不单靠颜色区分状态。成功、警告、错误同时保留图标与文字。普通正文、次要文字和提示文字在对应背景上对比度至少 4.5:1；禁用态仍须可辨认。

顶部主提示按文案宽度收缩，继续使用紧凑圆角浮层；浅色模式改为白底、灰边、深色文字，成功/开播图标保留语义颜色。开播提醒的启动过滤规则不改变。

### 接入与验证

配置增加 `settings.appearance_mode`，取值 `dark`、`light`、`system`，缺失或非法值回退 `dark`。实际系统模式与用户选择分开，保存的是选择。

复用 `ddm/theme.py` 的令牌与 `qss()`；自绘控件、硬编码颜色、缓存图标与局部样式统一在模式变化时刷新，不另建一套窗口。视频浮层使用固定视频配色，避免跟随全局文字令牌后失去对比度。系统变化使用 Qt 的 `QGuiApplication.styleHints().colorSchemeChanged`；无法识别系统模式时回退深色。

实施前盘点 `ddm/widgets.py`、`ddm/dialogs.py`、`ddm/app.py`、账号窗口、弹幕与菜单的颜色入口。验证两种配色的正文对比度；测试选择持久化、旧配置升级、系统变化与非法值回退。原生 Windows 下验证多路播放、全屏、录制和弹幕持续运行，切换前后播放器对象与 HWND 保持一致。横竖屏和 100% / 175% 缩放检查文字、边框、菜单及浮层。

## 修改文件夹图标

### 入口与交互

普通文件夹和智能文件夹的右键菜单增加「修改图标…」，放在重命名或编辑规则之后。打开小型对话框：顶部显示当前图标与文件夹名称，中间是图标选择区，底部为「恢复默认」「取消」「保存」。

内置图标首版提供文件夹、星标、爱心、游戏、音乐、视频六种统一线性图标。选中时显示蓝色边框与勾选；颜色提供默认、蓝、粉、绿、橙、紫六种，默认色随主题变化。图标预览立即变化，点击保存才修改真实文件夹；取消不改变配置。

「选择本地图片…」支持 PNG、JPEG、ICO。导入时保持比例，居中缩放进正方形画布，不拉伸、不直接裁掉边缘。图片原色保持不变，不提供着色选项；透明图片在深浅两种背景上并列预览。

普通文件夹默认为文件夹图标，智能文件夹默认为现有智能文件夹图标。自定义后智能文件夹仍保留「智能」文字或规则提示，避免只凭图标判断类型。展开箭头独立于图标，修改图标不会改变展开、排序、拖放或关注归属。

### 尺寸与保存

列表中图标为 18×18 逻辑像素，选择区预览为 32×32，当前图标预览为 48×48。内置图标采用矢量路径，按主题与 DPI 绘制；本地图片导入为 256×256 PNG，运行时按实际 DPR 缩放，保留透明度。

文件夹记录增加可选字段 `icon`：内置图标保存类型、名称和颜色，本地图片保存相对文件名。图片复制到软件目录 `utils/folder-icons/`，以独立随机文件名存储；不保存原绝对路径，用户移动或删除原图片后图标仍可用。不修改用户源图片。

导入上限 5MB、4096×4096 像素，先检查尺寸再解码。无法读取、格式不支持或超限时保留当前选择，显示明确原因。保存失败保留旧图标并提示重试；缺失或损坏的已保存图片回退默认图标，避免影响软件启动。恢复默认在保存后生效；删除文件夹不额外扫描或清理其他用户文件。

### 接入与验证

复用 `FollowFolderButton` 当前图标入口和文件夹保存流程，新增选择对话框；配置规范化保留合法 `icon` 字段，旧文件夹无字段时保持默认。

实施测试覆盖普通/智能文件夹、选择/取消/保存/恢复、重启保持、源图片删除后的恢复、非法配置和缺失图片回退。验证透明图片、非正方形图片、175% 缩放、横竖屏标题旋转，以及修改图标后的展开、排序和拖入卡片功能。
