### 专业美化

分区选择改为可点击的界面缩略图，包含“主界面、设置页面、菜单与提示”三张示意预览。虚线亮框表示可编辑区域，实线亮框表示当前选择；点击后右侧显示该区域的参数。文件夹及底栏内的具体按钮也有各自的入口。空画面、顶部浮标和关注卡片没有编辑入口。主界面的外边框／格子间隙可选择整体背景。

### 本体编辑与优先级

1. 软件默认 → 美化包预设 → 个人修改。个人通用修改也可覆盖美化包中细分按钮的同名字段。
2. 在缩略图点击目标区域，再选通用／深色／浅色／悬停／按下／选中／禁用／静音／暂停。静音、暂停图标分别针对音量和暂停按钮；菜单及设置导航的选中字段作用于条目。
3. 勾选想覆盖的字段，输入颜色、边框、圆角或导入图片，缩略图立即同步。切换区域／状态时保留有效草稿；点击“应用并保存”统一保存这些修改，关闭则丢弃尚未应用的草稿。无效颜色等输入保留上次有效预览，不能保存。整体背景仍沿用原有的选择后即时应用行为。
4. 不勾选的字段继承美化包或默认。“本分区跟随美化包／默认”清除该分区所有个人状态配置，不影响其他分区。“本分区使用软件默认”跳过该分区的包内样式，也可以继续在软件默认基础上编辑。
5. 文件夹原有的单独图标设置优先于统一文件夹图标；现有右键两个功能保留。清除单个文件夹的自定义图标后才跟随统一图标。
6. 美化包停用后，个人修改仍保留，其余区域恢复默认；再次启用后继续套用同一组个人覆盖。布局菜单的页签、保存、重置、删除确认及“管理”按钮跟随通用按钮样式；布局／组合缩略图保留各自图示，不会被通用按钮图标替换。
7. 新版美化包的背景、遮罩和是否覆盖关注栏可分别修改，点击“跟随美化包背景”恢复这三项继承关系。旧版背景插件继续保留锁定行为。

颜色支持 `#RRGGBB`、`#AARRGGBB`，其中前两位 `AA` 是不透明度，`00` 全透明、`FF` 完全不透明。圆角 0–32、边框宽度 0–4，单位为逻辑像素。背景图片拉伸铺满该分区，图标保留原始颜色和比例；第一版不提供字体、控件位置、按钮大小、窗口标题栏或独立文件夹展开箭头的替换。

分区素材支持 PNG/JPEG/WebP/BMP，单文件不超过 8MB、单边不超过 8192 像素。透明图标建议 PNG。个人素材复制到 `utils/skins/`，不修改源文件；恢复配置不删除素材。SVG、GIF 和分区视频暂不支持，整体背景仍支持原有视频格式。

### 普通插件包格式

```text
my_skin/
  plugin.json
  plugin.py
  background.png
  pause.png
  play.png
```

`plugin.py` 只需原有普通插件入口：

```python
from ddm.plugins import Plugin
plugin = Plugin()
```

`plugin.json` 示例：

```json
{
  "id": "my_skin",
  "name": "我的美化包",
  "description": "图标和分区背景",
  "version": "1.0.0",
  "skin": {
    "version": 2,
    "background": "background.png",
    "mask": 25,
    "parts": {
      "controls": {"background": "#D0142D35", "radius": 9},
      "folders": {"background": "#AA2D465C", "foreground": "#E7F1F8"},
      "buttons.pause": {"icon": "pause.png", "paused": {"icon": "play.png"}},
      "buttons": {
        "radius": 8,
        "hover": {"background": "#48738C"},
        "pressed": {"background": "#294357"}
      }
    }
  }
}
```

`skin.version` 为接口版本，与插件自身的 `version` 区分。整体背景可省略，支持只带图标／局部分区的包。`parts` 只接受上述已开放的接口键，字段为 `background`、`foreground`、`border_color`、`border_width`、`radius`、`image`、`icon`；`dark`、`light` 和状态字段内可填写同一组样式字段，第一版不允许进一步嵌套。顶层 `builtin: true` 清除该分区在更低优先级的样式，用于单独恢复软件默认。图标只对文件夹和按钮生效。资源路径相对于插件目录，禁止绝对路径、越界路径、原始 QSS 和不支持的区域；不要求插件自行修改本体控件。

多个美化插件同时启用时沿用现有规则：按插件 ID 排序的最后一个优先，不将多个包混合。建议只启用一个。个人覆盖仍在其上应用。

### 逐项测试顺序

测试包由 `dev/selfcheck_skins.py --make-demo` 生成到 `work/appearance-delivery/skin_parts_demo.zip`，所有素材均为测试生成，不使用真实账号或用户背景。它是普通插件，不能在旧版本软件上使用新版分区接口。

| 顺序 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 插件页导入测试 ZIP，启用并按提示重启 | 背景呈蓝色渐变，关注栏、文件夹、底栏和设置变成对应蓝灰色 |
| 2 | 查看空画面、关注卡片和顶部浮标 | 保留原有样式；只有原来的透明空格底透出背景 |
| 3 | 打开设置、切换导航、打开右键菜单和普通对话框 | 对应区域显示包内底色，选中和悬停正常 |
| 4 | 在分区美化中给“文件夹”勾选底色，填 `#905A486E` 并应用 | 统一文件夹底色变化；其他分区不变 |
| 5 | 给某个文件夹用原来的右键菜单设置独立图标 | 该文件夹保留自己的图标，其他文件夹继续用包内图标 |
| 6 | 点击暂停／继续、静音／取消静音；选择左／右声道 | 图标随状态切换，L／R 保留，功能正常 |
| 7 | 给“播放底部控制条”选择“浅色”，设置不同底色并应用，再切换深浅模式 | 浅色使用个人底色，深色继续继承美化包 |
| 8 | 为任一按钮导入个人 PNG 图标并应用 | 图标替换，点击区域和功能不变；停用包后个人图标仍在 |
| 9 | 分别点击“本分区使用软件默认”和“本分区跟随美化包／默认” | 前者跳过当前分区的包内样式，后者恢复包内预设；其他分区不变 |
| 10 | 修改整体背景或遮罩，再点击“跟随美化包背景” | 可单独修改，再回到包内背景和遮罩 |
| 11 | 有直播播放时启停包、改分区、切换主题 | 不重连直播、不变音量声道、不停止录制，不重建视频窗口 |
| 12 | 重启软件 | 已安装包、个人分区覆盖及文件夹单独设置继续保留 |

自动验证扩展在原有 `dev/selfcheck_skins.py`，`--parts-only` 只运行分区用例；完整运行继续验证旧版皮肤、视频循环、隐藏暂停及真实 VLC 播放连续性。
缩略图交互回归另覆盖所有分区和按钮的点击命中、保护区域不可点击、参数变化的实际预览像素、草稿不改动真实界面、切换区域保留草稿、无效输入拦截，以及统一应用保存。

## 原有背景功能及旧版插件兼容

设置 → 外观 → 背景皮肤可导入图片或视频，并调整背景遮罩浓度（0–100%）。选择后立即应用并保存；设置窗口取消不撤销已经生效的背景选择。恢复默认背景移除当前选择，不删除用户素材。

深浅色模式均让背景透过空格子的半透明底色显示。2026-10-15 修正浅色画面墙底色覆盖背景的问题，沿用深色的透明分层规则；未启用皮肤时仍保留原有纯色格子。回归通过切换红、蓝背景检查格子下方的实际颜色变化，并覆盖连续切换深浅色。

皮肤的深浅色透明样式同时安装，切换时仅改变主题属性，避免逐次重设画面墙、格子及关注栏的样式表。延迟回归覆盖默认背景、自定义背景和背景覆盖关注栏三种情况，并检查透明面板样式保持不变、视频几何不变和样式重设次数。

启用自定义图片或视频后，外观页显示“背景覆盖左侧关注栏”开关，默认关闭。开启后背景延伸到关注栏，保留半透明主题底色保护文字；关闭后关注栏恢复纯色。切换立即生效并保存。恢复默认背景或皮肤插件接管时隐藏该开关；插件背景覆盖关注栏，停用后恢复用户选择。

支持 PNG、JPEG、WebP、BMP 图片及 MP4、WebM、MKV、MOV 视频，视频解码能力取决于随软件分发的 Qt 多媒体组件。单文件上限 512MB，图片任一边不超过 8192 像素。文件异步复制到软件目录 `utils/skins/`，配置只保存相对路径；不会修改源文件，移动或删除源文件不影响已导入背景。导入期间关闭页面会取消尚未完成的复制。

图片保持比例，居中裁切铺满软件背景。视频静音循环，窗口隐藏或最小化时暂停，再次显示时恢复；背景播放器与直播 VLC 播放器独立。无自定义背景时不创建背景视频播放器。媒体读取或解码失败时显示原因，使用主题底色，用户可以重新导入或恢复默认。

遮罩达到 100% 时背景完全被主题底色遮住，视频自动暂停，并跳过帧转换和图片绘制；降低遮罩后恢复播放。后台帧不转成图片。当前最多每秒处理 30 帧，但这不降低源视频的解码帧率；使用较低分辨率和帧率的素材可进一步降低解码负担。当前为 Qt 图片合成路径，尚未实现全程 GPU 纹理合成，也不检测其他应用是否遮住本窗口。

分层设计参考 [dsh-wallpaper-engine](https://github.com/elysia395/dsh-wallpaper-engine)：最下层背景媒体、随深浅色模式变化的主题色遮罩、半透明面板、文字及控件。关注栏与格子面板保留浓度较高的主题底色，让花纹不会压过文字；底部功能栏沿用相同材质和分隔线。这里使用 Qt 自绘与半透明底色，没有后台模糊引擎，也不接入 Wallpaper Engine、工坊或其 API。直播视频内容及原生黑边保持原样，背景不参与录制。

## 皮肤插件包

沿用现有插件 ZIP 安装入口及目录规范。`plugin.json` 增加可选 `skin` 字段，包内仍需存在 `plugin.py`，例如：

```text
my_skin/
  plugin.json
  plugin.py
  assets/background.jpg
```

```json
{
  "id": "my_skin",
  "name": "我的皮肤",
  "description": "图片或视频背景皮肤",
  "version": "1.0",
  "skin": {"background": "assets/background.jpg", "mask": 35}
}
```

```python
from ddm.plugins import Plugin

plugin = Plugin()
```

`background` 必须是插件目录内的相对媒体路径，不能越界或引用软件外部文件；`mask` 为 0–100 的整数，缺省 35。背景也可以是 MP4 等支持的视频文件。代码插件可通过 `Plugin.skin` 提供相同字典。插件 ZIP 仍受原有 100MB 解压总大小限制。

安装遵循已有插件流程：导入后重启才装载，不当场执行新代码。有效皮肤插件装载并启用后，强制覆盖用户背景与遮罩，并锁定外观页的自定义控件，页面显示当前接管插件名称。用户原有选择保留，停用并保存或卸载后立即恢复。多个已装载皮肤插件同时启用时，按插件 ID 排序的最后一个优先；建议只启用一个。文件缺失或解码失败时显示插件背景错误，不偷偷改回用户背景。

插件仅接管背景皮肤，深色、浅色、跟随系统仍由颜色模式入口控制。关闭软件会停止背景解码并取消剩余导入任务。验证脚本：`dev/selfcheck_skins.py`，覆盖素材复制、异步导入、持久化、透出背景、插件安装与接管/恢复、路径校验、视频循环与暂停、直播连续播放及原生窗口保持。
