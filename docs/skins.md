# 皮肤与美化包

> 类型：参考 ｜ 状态：维护中 ｜ 适用版本：0.7.x ｜ 更新：2026-11-15 ｜ 读者：插件作者、用户

本页说明当前外观入口、分区美化包协议和背景媒体行为。首版界面调整、已撤下的专业编辑器及历史测试步骤保存在[2026 年 10 月实施记录](archive/skins-implementation-202610.md)；主题与文件夹图标见[外观设计](appearance-design.md)。

## 当前外观入口

设置 → 外观可修改软件整体背景、设置页背景、布局预设背景和已开放按钮的图标。整体背景可选图片或视频，并可调整遮罩；设置与布局背景以及按钮图标只接受静态图片。背景选择即时生效，其他分区由设置自动保存协调器提交，关闭设置前等待保存完成。外观页滚轮仍待修复，见[BUG-072](bug-cases.md#2026-11-15-外观页滚轮反馈)。

专业美化编辑器当前没有用户入口。已有个人配置和皮肤包协议继续保留；插件作者可通过普通插件 ZIP 声明分区外观。

## 分区美化包协议

`skin.version` 为 2 时，下表列出顶层背景字段和 `parts` 可用键。整体背景由 `skin.background` 和 `skin.mask` 声明；空格子底、顶部视频浮标和关注卡片没有单独的分区键。

| 接口键 | 分区 |
| --- | --- |
| 原有 `background` / `mask` | 软件整体图片／视频背景和主题遮罩 |
| `sidebar` | 关注栏底板；不允许改文字颜色，避免影响卡片 |
| `folders` | 文件夹标题条、底色、边框、圆角及统一图标 |
| `controls` | 播放格子的底部控制条 |
| `settings` | 设置窗口底板 |
| `settings.navigation` | 设置左侧导航及悬停／选中效果 |
| `settings.content` | 设置右侧内容区 |
| `menus` | 右键菜单、账号菜单、布局预设／直播间组合弹层底板；普通菜单的悬停／选中条目效果 |
| `layout_menu` | 布局预设／直播间组合弹层；未单独配置时继承菜单基础样式 |
| `dialogs` | 添加直播间、导入关注等普通对话框 |
| `notices` | 顶部操作结果、更新等提示条 |
| `buttons` | 开放区域中的通用按钮；不涉及顶部浮标及关注卡片 |
| `buttons.pause` / `buttons.volume` | 暂停播放、音量静音；换图后仍显示 L／R 声道标记 |
| `buttons.danmaku` / `buttons.danmaku_settings` | 弹幕开关及弹幕设置按钮 |
| `buttons.recording` / `buttons.fullscreen` | 录制、全屏按钮 |
| `buttons.sort` / `buttons.refresh` / `buttons.appearance` / `buttons.sidebar_toggle` | 关注排序、刷新、深浅色、展开收起按钮 |
| `buttons.settings` / `buttons.layout` / `buttons.import` / `buttons.add` | 主界面设置、布局、导入关注、添加直播间 |

### 覆盖规则

样式按软件默认、美化包、个人设置的顺序叠加；文件夹的单独图标优先于包内统一图标。美化包重新启用时会重新接管其声明的整体、设置页和布局背景；普通重启保留之后做出的个人调整。多个包同时启用时，按插件 ID 排序的最后一个生效，不混合不同包。

颜色支持 `#RRGGBB` 和 `#AARRGGBB`；圆角为 0–32、边框宽度为 0–4 逻辑像素。分区图片支持 PNG、JPEG、WebP、BMP，单文件不超过 8MB、单边不超过 8192 像素；整体背景另支持视频。个人素材复制到数据目录的 `utils/skins/`，不会修改源文件。

### 普通插件包格式

```text
my_skin/
  plugin.json
  plugin.py
  background.png
  pause.png
  play.png
```

`plugin.py` 只需原有普通插件入口：

```python
from ddm.plugins import Plugin
plugin = Plugin()
```

`plugin.json` 示例：

```json
{
  "id": "my_skin",
  "name": "我的美化包",
  "description": "图标和分区背景",
  "version": "1.0.0",
  "skin": {
    "version": 2,
    "background": "background.png",
    "mask": 25,
    "parts": {
      "controls": {"background": "#D0142D35", "radius": 9},
      "folders": {"background": "#AA2D465C", "foreground": "#E7F1F8"},
      "buttons.pause": {"icon": "pause.png", "paused": {"icon": "play.png"}},
      "buttons": {
        "radius": 8,
        "hover": {"background": "#48738C"},
        "pressed": {"background": "#294357"}
      }
    }
  }
}
```

`skin.version` 为接口版本，与插件自身的 `version` 区分。整体背景可省略，支持只带图标／局部分区的包。`parts` 只接受上述已开放的接口键，字段为 `background`、`foreground`、`border_color`、`border_width`、`radius`、`image`、`icon`；`dark`、`light` 和状态字段内可填写同一组样式字段，第一版不允许进一步嵌套。顶层 `builtin: true` 清除该分区在更低优先级的样式，用于单独恢复软件默认。图标只对文件夹和按钮生效。资源路径相对于插件目录，禁止绝对路径、越界路径、原始 QSS 和不支持的区域；不要求插件自行修改本体控件。

多个美化插件同时启用时沿用现有规则：按插件 ID 排序的最后一个优先，不将多个包混合。建议只启用一个。个人覆盖仍在其上应用。

## 背景媒体与旧版插件兼容

设置 → 外观 → 分区美化 → 软件整体背景可导入图片或视频，并调整背景遮罩浓度（0–100%）。选择后立即应用并保存；设置窗口取消不撤销已经生效的背景选择。恢复默认背景移除当前选择，不删除用户素材。

深浅色模式均让背景透过空格子的半透明底色显示。2026-10-15 修正浅色画面墙底色覆盖背景的问题，沿用深色的透明分层规则；未启用皮肤时仍保留原有纯色格子。回归通过切换红、蓝背景检查格子下方的实际颜色变化，并覆盖连续切换深浅色。

皮肤的深浅色透明样式同时安装，切换时仅改变主题属性，避免逐次重设画面墙、格子及关注栏的样式表。延迟回归覆盖默认背景、自定义背景和背景覆盖关注栏三种情况，并检查透明面板样式保持不变、视频几何不变和样式重设次数。

启用自定义图片或视频后，背景默认延伸到关注栏，保留半透明主题底色保护文字；不再提供覆盖关注栏的开关。恢复默认背景时关注栏恢复原有纯色。

支持 PNG、JPEG、WebP、BMP 图片及 MP4、WebM、MKV、MOV 视频，视频解码能力取决于随软件分发的 Qt 多媒体组件。单文件上限 512MB，图片任一边不超过 8192 像素。文件异步复制到软件目录 `utils/skins/`，配置只保存相对路径；不会修改源文件，移动或删除源文件不影响已导入背景。导入期间关闭页面会取消尚未完成的复制。

图片保持比例，居中裁切铺满软件背景。视频静音循环，窗口隐藏或最小化时暂停，再次显示时恢复；Qt 背景播放器与直播 libmpv 播放器独立。无自定义背景时不创建背景视频播放器。媒体读取或解码失败时显示原因，使用主题底色，用户可以重新导入或恢复默认。

选择视频后显示“启用视频”，默认开启。关闭后从视频起点重新解码并保留首个有效帧，播放器暂停；后续帧不再更新，预览和主界面同步使用该静态图。保留原视频路径并持久化 `skin_video_enabled`，重启后可再次从开头取帧；重新开启恢复动态播放。新导入的视频重新默认开启，不另存静态图片，也不影响直播播放。

更换视频或切换静态模式时更换背景视频接收端，忽略旧接收端排队中的帧，避免旧画面被误用作新视频首帧；背景播放器仍复用原有实例。旧 Qt 环境的回归记录见[历史实施记录](archive/skins-implementation-202610.md)，现行依赖以根目录 `requirements.txt` 为准。

遮罩达到 100% 时背景完全被主题底色遮住，视频自动暂停，并跳过帧转换和图片绘制；降低遮罩后恢复播放。后台帧不转成图片。当前最多每秒处理 30 帧，但这不降低源视频的解码帧率；使用较低分辨率和帧率的素材可进一步降低解码负担。当前为 Qt 图片合成路径，尚未实现全程 GPU 纹理合成，也不检测其他应用是否遮住本窗口。

分层设计参考 [dsh-wallpaper-engine](https://github.com/elysia395/dsh-wallpaper-engine)：最下层背景媒体、随深浅色模式变化的主题色遮罩、半透明面板、文字及控件。关注栏与格子面板保留浓度较高的主题底色，让花纹不会压过文字；底部功能栏沿用相同材质和分隔线。这里使用 Qt 自绘与半透明底色，没有后台模糊引擎，也不接入 Wallpaper Engine、工坊或其 API。直播视频内容及原生黑边保持原样，背景不参与录制。

## 旧版背景皮肤插件包

沿用现有插件 ZIP 安装入口及目录规范。`plugin.json` 增加可选 `skin` 字段，包内仍需存在 `plugin.py`，例如：

```text
my_skin/
  plugin.json
  plugin.py
  assets/background.jpg
```

```json
{
  "id": "my_skin",
  "name": "我的皮肤",
  "description": "图片或视频背景皮肤",
  "version": "1.0",
  "skin": {"background": "assets/background.jpg", "mask": 35}
}
```

```python
from ddm.plugins import Plugin

plugin = Plugin()
```

`background` 必须是插件目录内的相对媒体路径，不能越界或引用软件外部文件；`mask` 为 0–100 的整数，缺省 35。背景也可以是 MP4 等支持的视频文件。代码插件可通过 `Plugin.skin` 提供相同字典。插件 ZIP 仍受原有 100MB 解压总大小限制。

安装遵循已有插件流程：导入后重启才装载，不当场执行新代码。有效皮肤插件装载并启用后，强制覆盖用户背景与遮罩，并锁定外观页的自定义控件，页面显示当前接管插件名称。用户原有选择保留，停用并保存或卸载后立即恢复。多个已装载皮肤插件同时启用时，按插件 ID 排序的最后一个优先；建议只启用一个。文件缺失或解码失败时显示插件背景错误，不偷偷改回用户背景。

插件仅接管背景皮肤，深色、浅色、跟随系统仍由颜色模式入口控制。关闭软件会停止背景解码并取消剩余导入任务。验证脚本：`dev/selfcheck_skins.py`，覆盖素材复制、异步导入、持久化、透出背景、插件安装与接管/恢复、路径校验、视频循环与暂停、直播连续播放及原生窗口保持。
