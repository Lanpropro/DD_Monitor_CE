# DD监控室CE v0.8-hotfix.1 更新说明

0.8 热修复1补齐「B站稍后再看」插件1.0所需的本体能力。请先升级本体，再安装插件；插件独立下载，不内置于本体安装包。

## 稍后再看插件支持

- 视频卡片复用关注卡片的拖影，保留鼠标抓取位置；取消拖动、隐藏来源或卸载插件时释放鼠标和键盘。
- 修复切换横竖屏后，观看顺序内容占到关注栏上方工具区域的问题，只替换下方卡片内容。
- 视频格不再作为本体直播弹幕栏的获取来源。直播格、尚未开播的直播间仍可选择，视频自身的历史弹幕不受影响。
- 将此前仅在本机验收工作区中的相关接口纳入正式发布源码，修正本机验收版与公开版本能力不一致的问题。

## 插件商城

- 修复检查具有旧组合包替换声明的独立插件时，因缺少设置上下文而无法正确显示可安装版本的问题。

## 更新通知

- 精简单项更新浮层，版本号只显示一次，下载与设置按钮并排。下载时单独显示进度、文件大小与速率。

## 升级

- 已安装用户可在设置中检查更新，或使用新版安装包升级；保留个人配置和已安装插件。
- 本版保留0.8已有功能，使用相同的PySide6 6.11.2运行依赖。稍后再看插件要求0.8热修复1或具备相同接口的后续版本。
