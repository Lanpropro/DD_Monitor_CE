## 设置首次打开与切页优化（待人工复测）

- 增加根 `run.cmd --diagnose-settings-performance` 按需入口，关联主进程与设置子进程的页面创建、切换、嵌入、首次绘制及 GUI 停顿调用位置；不记录设置内容，普通启动不开启。
- 用户真实复现后，减少创建设置控件时的重复工作：缓存下拉项宽度并按模型／字体变化刷新；添加卡片不再反复重排已有卡片；主题及设置焦点过滤器复用事件类型。保留现有外观、动效、懒加载及滚轮转交。
- 第一批人工复测反馈基本没有变化。第二批将外观图库缩略图解码移到后台，刷新或销毁后取消旧结果，列表和当前选择可先显示；普通性能采集默认关闭详细剖析并后台写盘，避免取证开销影响体感判断。
- 第二批人工反馈略有减轻。第三批省去隐藏宿主中重复的常规编辑器，只保留旧插件扩展锚点，常规设置仍由worker编辑并按原协议保存；保留插件Show扩展和accepted接线。
- 第三批人工反馈仍略有缩短。第四批滚轮桥接复用已有原生父窗口，不再显式创建额外容器HWND；普通分区美化只创建素材字段，保存图片时保留已有颜色、圆角、边框和状态样式，专业模式保持完整。
- 第四批复测反馈仍差不多、滚轮正常。补充窗口显示／置前／激活及外观内部编辑区的轻量子阶段计时，继续定位剩余首次等待，不将新增采集计为性能改善。
- 细分现场采集显示仍有控件构造、布局与窗口显示成本。本批将共享下拉框的定制列表、代理和样式延后到首次展开或显式访问，保留模型、选中值、尺寸及外部自定义view，首次展开前的定制UI工作得以省去。
- 功能回归覆盖缓存失效、字体选择、键盘提交取消、宽窄布局、主题跟随、图库异步生命周期、宿主快照、插件保存／取消及带父级偏移的嵌入滚轮；本批实际改善待复测，首次可见窗口、原生嵌入及各页首次创建仍有成本。

## 托盘行为与预览调整（待人工验收）

- 画面右键菜单与托盘菜单上下分为两块，分别保存显隐和顺序；托盘可配置布局示意、显示/隐藏窗口、画中画、退出，打开设置不触发保存，恢复默认分别作用于各自菜单，整页重置恢复两份配置。
- 菜单拖动复用关注栏的150ms OutCubic行位移与GUI时钟，拖影跟手、其他行让位，松手才保存；Esc、隐藏或丢失捕获取消时保持原顺序，系统关闭动画时立即让位。

- 托盘菜单增加画中画入口和最小化前的布局示意，区分视频格、弹幕格、空格及有内容的位置；只保存内存几何/标签，不截图、不取视频帧、不持续刷新。点击示意恢复监控室，退出与原窗口恢复入口保留，未增加其他托盘功能。隐藏暂停时仅恢复画中画选中路，原手动暂停保留，关闭小窗后重新暂停隐藏播放，录制不受影响。
- 托盘行为页将关闭与播放、画面右键菜单分卡；使用共享下拉与开关，恢复接近实际菜单宽度的预览（260–300逻辑像素），包含音量轨道、分组和子菜单箭头；与功能列表共享顺序/显隐，宽屏并排、窄屏堆叠，只有外层滚动；保留按钮排序、插件扩展入口和恢复默认，排序及恢复默认接入自动保存。
- 录制锁画质文案明确为“录制时锁定可用最高分辨率”，沿用原取流与结束恢复行为；通知背景预览靠右加宽，窄屏可收缩。

## 退出时联动隐藏设置窗口（已人工验收）

- 退出前先停止独立设置窗口，再隐藏主窗口和等待后台任务；按真实工作进程 PID 核对 HWND 后异步隐藏设置窗口，避免仅依赖退出消息与主进程事件循环。
- 设置工作进程收到退出请求先隐藏并停止自动保存观察，再解绑宿主页和退出；主进程关闭期间不再因设置遮挡状态变化重新显示 Quick 弹幕窗口。
- 根 `run.cmd --check-settings-shutdown` 验证含嵌入外观页的关闭顺序、主进程不处理事件时的隐藏和最终工作进程收尾；2026-11-17 维护者确认设置已与主窗口一起消失。此项不等同于已修复全部内存访问异常。

## 持续播放失败的居中反馈（待人工验收）

- 连续两次重连失败后，在画面中央将重连等待／连接状态与原因提示一起展示；反复停帧刷新也展示当前判断。明确解码异常触发 CPU 回退时立即提示，恢复播放、换台或下播后清除。
- 根据取流连接错误、直播源 HTTP 状态、传输中断及解码错误区分提示；证据不足时显示原因暂未确定，不仅凭缓冲次数认定为解码或本地网络故障。提示不展示原始异常、地址或凭据。
- 沿用现有加载浮层和重试时序，支持小格子缩放；隔离回归及 Windows 屏外浮层验证通过，实际失败直播间仍待根 `run.cmd` 人工确认。
