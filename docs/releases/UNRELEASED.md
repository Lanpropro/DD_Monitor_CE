## 内置布局预设编辑与快捷键（编辑功能验收通过）

- 在「布局预设」点右下角的「修改布局」，再选内置预设卡片。也可以从卡片右键菜单进入。拖动画面墙预览中的分隔线，保存后该预设的卡片和快捷键都会应用新比例。
- `c6d67e87` 的对齐、拖动及保存功能已通过人工验收。编辑蒙版提供恢复默认和逐步撤回，保存后应用最终预览。

## 自定义网格与弹幕布局（待人工验收）

- 「自定义九格」和「自定义十六格」使用隐藏底网格。直播间拖到空白处自动吸附。将鼠标放在直播格上按住 Ctrl 滚动滚轮，可按 `1×1`、`2×2` 等档位缩放。右键空白处可添加独立弹幕格，位置和尺寸随布局保存。
- 拖动时显示底格虚线与吸附范围。拖动已放大的直播格，会按抓取的位置对齐。自定义画面墙使用切片工作台同款背景蒙版，跟随外观里的背景遮罩设置。
- 独立弹幕格可以拖过画面格，继续拖到空位吸附。点击开播通知的「替换」后，可点空位放入直播，也可点已有画面进行替换。
- 自定义十六格优先将竖屏直播放入连续三行，空间不足时用两行。自定义九格默认用两行。鼠标悬停竖屏格时，Alt＋滚轮上滚切到 1×3、下滚切回 1×2，Ctrl＋滚轮按当前占位比例缩放。操作说明位于「设置 → 快捷键 → 滚轮设置」。
- 弹幕布局和竖屏布局可直接通过底栏「修改布局」选中卡片编辑。「主画面 + 弹幕」默认以 80:20 分配画面与弹幕栏宽度。

## 普通直播格透明控制栏（样式及直播格自动隐藏已验收）

- 在「设置 → 常规 → 播放与声音」开启「普通直播格使用透明控制栏」，底栏会覆盖画面下沿，使用与全屏一致的渐变。开关默认关闭，可随时切换。
- 空格的底栏也使用透明渐变，背景延伸至格子下沿，保留居中的「添加直播间」按钮。
- 闲置自动隐藏同样适用于空格。鼠标静止约 3 秒后收起底栏，移动鼠标只唤回所在格。选中的 L/R 声道以主题蓝显示。

## 关注栏工具按钮（人工验收通过）

- 多选与刷新放回关注工具栏，卡片／列表切换移到左侧关注栏的「⋯」菜单。收起和展开使用带箭头的分栏图标。
- 多选与刷新使用同排按钮的透明底和细线样式。实机验收提交 `312ddb83`。

## 分段指示器（人工验收通过）

- 布局预设与其他共享分段控件统一跟随「外观 → 滑动分段指示器」。关闭开关、使用键盘选择或系统禁用动画时，选中底片直接到位。

## 启动公告与首次须知（待人工验收）

- 启动时后台检查一次独立的官方公告。新公告在启动时显示提醒并进入现有通知中心，点击可查看详情，同一公告不会重复提示。详情跟随设置页的毛玻璃开关和底色不透明度，附带链接时可从标题栏图标打开原文。
- 首次用户须知采用圆角窗、品牌标题、滚动正文和固定的确认按钮。默认尺寸为 640 × 620，关闭流程和已显示状态沿用原逻辑。

## 主播监控与通知菜单（待人工验收）

- 左侧功能栏底部新增「监控」菜单，合并展示自动录制监控名单和手动录制中的主播，打开时更新录制状态。
- 监控菜单显示头像、平台标识、主播 ID（缺少时显示房间号）和录制会话时长，提供直达主播监控设置的入口，浮层的四个圆角外保持透明。
- 「监控中」使用蓝色徽标，录制中的头像沿用关注栏录制波纹，主播监控设置按钮铺满菜单底部内容区。
- 自选主播可保存播放画质、录制画质和音量。连续移除配置可逐个撤回或一并撤回，提示复用设置材质。集成提交 `c368a37f`、`1bcfdeff`、`0230632c`。
- 「主播监控」原为「主播独立设置」。每位主播可开启自动录制，遵循录制总开关和该主播的录制画质。已启用的主播头像外侧显示主题色圆环，开始录制时变红并持续向外扩散两道波纹。已开播的主播在首次检测时也可开录，确认下播后保存。
- Windows 通知须同时开启通知页总开关和该主播的 Windows 通知开关，只同步自动开录和下播停止两条状态。受主播监控管理的录制在画面墙同步显示 REC，由主播监控启停。
- DDCut 可用时，可在每位主播的卡片中指定自动录制方式，选择普通录制或 DDCut 切片录制。已有配置默认沿用全局录制方式，选项只影响新开的自动录制。
- 主播卡片将画质和音量与自动录制设置分栏显示，收起后显示自动录制、Windows 通知及录制方式的标识。通知页关闭 Windows 通知时，该主播的开关暂不可编辑。整组没有共同平台档位时，仍可使用「继承」和「最高可用」。
- 主播监控提示同平台的直播间也可能提供不同档位。直播格和画质菜单统一分辨率与帧率的显示，B 站原画可以在播放后按实际分辨率更新。
- 通知菜单重排通知类型、时间与动作，接入外观的毛玻璃。清空和关闭共用图标按钮样式。集成提交 `07913f3d`、`3514887e`、`043e2b4c`。
- 通知菜单开启毛玻璃时提高底色的不透明度，减少直播画面透出。底色仍可调，四角按面板轮廓裁切。
- 删除单条通知时，卡片淡出，下方卡片平滑补位。清空时，可见卡片一起淡出，最后一张卡片退出后面板立即收起。清空期间到达的新通知会保留。
- 设置导航、通知菜单及共享控件专项已通过，Windows 桌面合成效果和真实直播录制待人工验收。

## 画中画与主窗口同时播放（Issue #228，人工验收通过）

- 组合画中画新增“与主窗口同时播放”开关，点打开或应用后生效，记住上次应用的模式。开启后主墙继续按原布局播放，墙上和关注列表中的直播间都可用独立小窗播放，小窗新选的直播间默认静音，关闭小窗只收尾小窗播放。
- 选择页使用连续圆角与内置标题，预选画面墙上实际有视频的直播间。画中画只显示所选视频，一路即可打开；可以继续从关注列表加入主播。返回监控室后恢复主墙的独立弹幕格及其历史。
- 每次启动软件后，首次打开选择页以当前画面墙为预选。本次从下方勾选的主播同步显示在顶部，应用的选择在本次运行中可继续编辑。自定义入口始终排在布局选项最右侧。
- 从功能栏打开时，紧凑选择页贴着入口展开。点击面板外、再次点击入口或按 Esc 都能收起。可拖标题移动或拖边缘和四角缩放，面板始终留在主窗口可见范围内。手动调整的尺寸跨启动记忆，主窗口临时变小只影响本次显示尺寸。
- 保留自动与预设。自动排列按视频原始比例安排大小相近的画面，末行居中；也可选择并排、上下、均分、一主多辅等预设。自定义模式可拖动独立画面，靠近相邻画面时贴边或对齐，切换到小窗后保留位置；重新加入的主播可占用本次编辑腾出的位置。
- 从根 `run.cmd` 启动，打开有两路正在播放的预设，分别添加一位墙上主播和一位墙外主播到小窗。检查主墙持续播放、两边音量独立、关闭小窗时主墙保留原位置与播放。关闭开关再打开画中画，检查原有的组合与返回行为。
- 双路播放小窗沿等比对角线连续缩放，松手取最终鼠标位置，并短暂保留最后一帧完整画面。人工复测确认尺寸跳变和松手闪烁均已消失，松手时仍有轻微的画面变化，验收通过。
