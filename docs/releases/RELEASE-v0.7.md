# DD监控室CE v0.7 更新说明

## 新增与调整

- 常规设置新增音量均衡开关，减少不同直播间音量差异。
- 新增“托盘行为”设置，集中管理关闭窗口行为与托盘播放；默认进入托盘后暂停观看，恢复主界面时重新加载，录制继续进行。
- 正式版仅运行一个实例，重复启动时唤回已有窗口；源码开发版允许多开测试。
- 默认关注文件夹可改名、拖动和排序，普通文件夹可设为新的默认文件夹；新用户初始名称为“默认关注”，已有自定义名称保留。
- 格子右键新增“直播流信息”，展示实时编码、分辨率、帧率、解码方式、音频、缓冲、丢帧及下载速率等信息。
- 画面墙满员时，开播提醒改为“替换”，点击后选择目标画面完成替换，Esc 取消。
- 非全屏画面内鼠标静置约 3 秒后隐藏上方悬浮条与光标，移动后恢复；操作菜单或底栏时保持正常交互。

## 弹幕与醒目留言

- 修复高刷新率或关闭垂直同步时，滚动弹幕速度超出设置上限的问题；Shift＋滚轮每次调整音量 10。
- SC 固定在弹幕栏独立区域，不再跟随普通弹幕滚动；每条独立自动收起、展开和关闭。
- 多条 SC 纵向排列，移除三张卡片叠放与前后切换；保留手动关闭收拢动画，调整官方配色与正文留白。
- 设置提供画面／弹幕栏两种 SC 布局预览，可拖动位置、缩放大小并同步不透明度；预览按实际区域比例映射。
- 弹幕连接状态改为 Wi-Fi 风格图标，未连接为灰色，连接后为粉色。
- 修复全屏输入弹幕时控制条闪烁、错位及隐藏后重新唤起的动效问题；修复浅色主题切换后弹幕输入框文字仍使用旧颜色的问题。

## 录制与即时回放

- 修复长时间录制自动分段后，后续片段无法继续取流录制的问题；分段与失败重试独立刷新录制源。
- 手动停止即时回放缓存时自动保存最近设定时长；不足时保存已有内容，导出失败保留原分段。
- 仅开启即时回放缓存显示蓝色“● REC”，完整录制显示红色“● REC”。

## 性能与稳定性

- 全屏改为独立呈现现有播放格子，保留原画面墙尺寸与布局，减少进出全屏时的重排与冻结画面过渡。
- 弹幕尺寸变化复用纹理并在后台重绘最终尺寸，限制每条缓存数量，过滤过期绘制结果。
- 优化文件夹收展、侧栏切换、窗口缩放与跨屏 DPI 变化的布局处理；仅为可见范围的文件夹卡片执行位移动画。
- 预览播放器按需初始化视频输出，头像缓存移出界面线程，减少重复恢复请求和中转停止时的等待。
- 关闭设置不再等待插件目录网络请求，迟到结果安全回收；临时菜单与背景主题订阅在结束后释放。
- 斗鱼播放失败和 EOF 接入已有恢复流程，保留专项诊断工具；部分线路视频缺口、卡顿问题仍待定位，不保证已经根治。

## 已知限制与升级

- 文件夹卡片偶发遮挡、部分 Windows 环境拖放／原生崩溃的后续诊断继续保留；自动回归不能替代所有设备与线路的实际播放验收。
- Windows 10／11 64 位；安装版与便携版均无需 Python，内置 FFmpeg 和独立诊断工具。
- 覆盖升级保留个人配置与已安装插件；平台和互动插件继续独立更新，不内置本机安装副本。
