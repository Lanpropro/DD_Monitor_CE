# DD监控室CE v0.7.3 更新说明

本次版本在 v0.7.2 热修复基础上，集中完成设置界面、弹幕管理、画面墙交互、更新器和诊断能力的整理，并保持本体与独立插件的发布边界。

## 设置与外观

- 设置页按功能职责拆分，统一卡片、控件、滚动、快捷键、保存与恢复默认行为。
- 增加深浅主题、可选材质、背景缩略图库、玻璃层次和字号/主题偏好，保持独立设置进程与宿主页同步。
- 快捷键页按首页、常规、滚轮与画中画分组，补充滚轮音量和画中画音量操作。
- 输入框、选择器、分段控件、曲线编辑器和嵌入页面统一使用共享控件样式；普通输入框透明绘制以继承所在表面颜色。

## 弹幕、画面墙与播放

- 支持跨平台弹幕词条和用户屏蔽，覆盖历史消息、排队消息、SC 及插件派发，并提供设置页管理和自动保存。
- 完善画面墙拖动、关注栏预览滚动、侧栏固定入口、画面弹幕缩放、SC 位置与大小同步，以及画中画和全屏控制栏行为。
- 增加音量均衡响应曲线、独立声道路由、播放状态恢复和多路画面切换的边界检查。

## 更新、插件与诊断

- 将应用更新、插件目录、下载校验、安装覆盖和保留数据边界拆分为独立职责模块。
- 独立设置、录制/回放、原生窗口和播放诊断增加阶段记录、现场证据和退出收尾检查。
- 保留插件独立仓库与版本兼容检查，本体发布包不包含本机账号、缓存、日志或安装副本。

## 验证与限制

- 发布源码通过仓库结构、编译、差异检查、设置/组件、全屏和发布元数据专项验证。
- 自动检查使用合成数据、隔离配置和本地媒体，不读取真实账号、不发送真实弹幕；真实直播、DPI、拖动手感和长时间播放仍需人工验收。
- 本版本不宣称解决历史原生崩溃或所有平台取流问题；相关诊断入口继续保留。
