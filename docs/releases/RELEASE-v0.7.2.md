# DD监控室CE v0.7.2 更新说明

本次集中更新多画面画中画、弹幕格布局、SC 醒目留言和图片缓存，并整理全屏控制、批量移除及诊断入口。

## 0.7.2 热修复（修订 1）

- 更新前确认独立设置进程退出，减少程序仍被自身占用时替换 EXE 失败的问题；更新助手增加目标文件检查和有限重试，兼容旧版发起的更新。
- 安装包覆盖前检查已有程序文件的占用、只读属性和访问权限，遇到问题时提前停止并显示具体文件，处理后可重试，无需先删除旧安装目录。持续的文件权限或安全软件限制仍需按提示处理。
- 手动升级成功后，不再把已被新版取代的在线更新失败记录显示为当前状态；原记录保留用于诊断。
- 修复诊断采集在 Qt 退出阶段未及时停止的问题；其他历史通知异常和原生崩溃仍分别跟进。

已安装 0.7.2 的用户可在“设置 → 软件更新”检查并下载本次热修复；开启启动检查的用户会收到提醒。版本号仍为 0.7.2，内部修订号为 1。下方保留 0.7.2 及 0.7.1 Hotfix 的累计更新内容。

## 包含 0.7.1 Hotfix 累计修复

- 修复进入或退出全屏时整面画面墙短暂闪空的问题，切换期间保留画面、播放器状态和 SC 归属。
- 修复后台播放与滚动弹幕场景中，Qt 字体回退日志可能引发锁等待、导致软件无响应的问题；其他历史卡死和原生崩溃仍需分别定位。
- 新增弹幕 RGB、HEX 选色及预览，支持按格独立调整颜色、字号、速度等参数；关闭独立调整后跟随最新全局设置，格子菜单中的 SC 设置统一移至“设置 → 弹幕”。
- 内置诊断工具支持已有日志打包和事后现场采集，无需重启客户端，不自动上传。新增采集能力不代表通知残留、关注列表错位或弹幕回退已全部修复。

## 功能更新

- 尝试优化了整个左侧关注栏的UI与设计。
- 现在可以用监控室的视角查看画中画了，将多个直播挂载在旁边一起观看吧。
- 增加了独立设置 SC 位置的选项，你可以将画面中与弹幕栏的 SC 分别放在不同位置；大小与透明度仍然共用。
- 增加“SC 随画面缩放”功能。
- 增加了一键清空画面墙直播的功能，你可以根据是否在播来快捷选择。
- 我们现在可以将任何的直播画面格子更改成弹幕格了，靠在一起的同主播弹幕格还会自动合并。考虑是否在后续删除独立的弹幕布局

## 功能优化

- 调整了滚动弹幕随画面缩放的缩放曲线，如果您仍然觉得曲线不太对，后续大概会更新让您自由调整
- 限制了主播头像与直播间封面的大小，大幅缩减了多关注用户的存储占用。已有头像和封面在后台正常读取时本地压缩，无需清缓存或重新下载；保留人脸裁切信息和每个房间的最新快照，未开播时仍可回填。

## 功能修复

- 调整全屏底栏首次显示、闲置收起和鼠标唤回；首次按 Enter 可聚焦弹幕输入框，点击视频后释放输入焦点。
- 进出全屏时提前准备底栏的最终位置与绘制，减少首帧闪烁；保留播放器和各格输入草稿。
- 标题栏交回 Windows 原生移动，保留系统吸附、最大化与还原。
- 关注栏通知控件与可重排图标分组，保持通知入口位置稳定。
- 插件商店和已安装列表调整展示；平台、互动和比赛二路插件继续独立更新。
- 更新器支持同版本内部修订识别，现在能够读取我的hotfix更新了
