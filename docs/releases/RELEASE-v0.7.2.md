# DD监控室CE v0.7.2 更新说明

本次集中更新多画面画中画、弹幕格布局、SC 醒目留言和图片缓存，并整理全屏控制、批量移除及诊断入口。当前为待发布候选，最终发布状态以 GitHub Release 为准。

本版已整合 0.7.1 Hotfix 的更新，未安装 Hotfix 的用户可以直接升级到 0.7.2，无需先补装旧版。

## 包含 0.7.1 Hotfix 累计修复

- 修复进入或退出全屏时整面画面墙短暂闪空的问题，切换期间保留画面、播放器状态和 SC 归属。
- 修复后台播放与滚动弹幕场景中，Qt 字体回退日志可能引发锁等待、导致软件无响应的问题；其他历史卡死和原生崩溃仍需分别定位。
- 新增弹幕 RGB、HEX 选色及预览，支持按格独立调整颜色、字号、速度等参数；关闭独立调整后跟随最新全局设置，格子菜单中的 SC 设置统一移至“设置 → 弹幕”。
- 内置诊断工具补充已有日志打包和高级专项采集，不自动上传。新增采集能力不代表通知残留、关注列表错位或弹幕回退已全部修复。

## 画中画与画面布局

- 画中画组合选择器按关注文件夹分块，顶部保留已入墙画面；上下重复入口及智能文件夹副本同步勾选，同一主播只加入一次。
- 搜索与关注栏一致，支持中文、拼音全拼、首字母、房间号、文件夹名和多个关键词；搜索不会清空已有选择。
- 支持在预览中拖动调整组合，头像网格可选择墙外正在开播的关注；画中画继续保留各路音量、静音和暂停状态。
- 可以直接把画面格转换为关联主播的弹幕格，通过头像条选择来源；同源且能组成矩形的相邻弹幕格合并显示，共用底部发送框。
- 调整“主画面＋5 小环绕”默认布局的上下列对齐，以及轻微错位后的同源弹幕合并。重新选择布局预设恢复默认格子类型，保存的直播间组合仍可恢复。
- 支持批量选择并移除画面、预览待移除范围和撤回上一批操作；清空全部保留独立确认。

## SC 与弹幕

- 画面内 SC 与弹幕栏 SC 可以分别保存位置，提供位置同步开关，默认开启；关闭后可分别拖动，大小与透明度继续共用。
- 增加“SC 随画面缩放”，默认关闭；开启后卡片、头像和文字随画面一起等比缩放，手动大小调整仍然生效。
- 调整滚动弹幕的小画面缩放曲线，小格子中的字号更易读；大画面及关闭自动缩放时保留原有行为。
- 保留 SC 展开时先收起、收起后再关闭的两阶段操作，以及普通画面和独立全屏中的位置跟随。
- 调整等分格子的音量控件样式和宽度变化后的刷新，保留原有滚轮和快捷键操作。

## 图片缓存

- 主播头像长边限制为 256 像素，直播间封面长边限制为 640 像素，小图不放大；不透明图片选取较小的 JPEG85 或 PNG 编码，透明图片保留 PNG。
- 已有头像和封面在后台正常读取时本地压缩，无需清缓存或重新下载；保留人脸裁切信息和每个房间的最新快照，未开播时仍可回填。
- 保留新图成功后清理无引用旧图、共享图片保护和下载失败时保留旧图的机制；不新增容量淘汰，不批量处理未读取的历史文件。
- 已转存图片避免重复有损编码。真实大图样本显示明显节省空间，具体降幅取决于原图，不能将抽样比例当作整个缓存的缩减比例。

## 全屏、交互与诊断

- 调整全屏底栏首次显示、闲置收起和鼠标唤回；首次按 Enter 可聚焦弹幕输入框，点击视频后释放输入焦点。
- 进出全屏时提前准备底栏的最终位置与绘制，减少首帧闪烁；保留播放器和各格输入草稿。
- 标题栏交回 Windows 原生移动，保留系统吸附、最大化与还原。
- 关注栏通知控件与可重排图标分组，保持通知入口位置稳定。
- 插件商店和已安装列表调整展示；平台、互动和比赛二路插件继续独立更新。
- 更新器支持同版本内部修订识别，正式版本升级仍按版本号比较。
- 独立诊断工具支持事后采集文件夹布局和接下来一次拖放操作的现场，默认不持续采样、不自动上传。

## 已知问题与升级说明

- 部分自动检查仍出现 Qt 原生退出或超时，尚未确认所有触发原因；单项通过不能证明这些异常已解决。
- 久用后的通知残留、偶发滚动弹幕回退、部分环境卡顿及斗鱼线路视频缺口仍需真实现场证据，不列为已全部修复。
- 最新画中画选择器、SC 自动缩放和图片压缩仍需使用本次新构建完成实际观看、高 DPI 和跨屏验收。
- 支持 Windows 10／11 64 位。安装版与便携版无需 Python，内置 FFmpeg 和独立诊断工具；源码包使用与开发版一致的 Qt 6.11.2。
- 升级保留个人配置和已安装插件；发布包不包含本机账号、配置、缓存、日志、录制和插件安装副本。
