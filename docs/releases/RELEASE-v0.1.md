# DD监控室CE v0.1

第一个公开发布版。多路 B 站直播间监控画面墙，横竖屏两套排布，自带弹幕与音频路由。

## 和原版有什么差别

**新增竖屏布局**
- 顶部横栏两行：logo + 搜索 + 多选/排序/刷新 + 展开键；下面一行是横向卡片条
- 卡片条右侧独立一块：账号 / 布局预设 / 设置（宽度等高、下沿与缩略图齐平）
- 点「多选」时多选条顶掉搜索那一行，横栏高度不变（画面墙不抖）
- 收起键在竖屏显示上下箭头，横屏是左右箭头

**播放与音频**
- 每格独立 libVLC 播放器，共享一个 libvlc 实例；主/次画质分级
- 每格可单独设音量，并把该格音频独立路由到左/右声道（PortAudio）
- 悬浮预览、暂停、画质切换、关掉某一路留空位

**关注列表与弹幕**
- 关注列表横向/纵向两套样式，支持置顶、排序、多选删除、搜索
- 拖头像进画面墙换画布；点顶排头像高亮选中
- 弹幕面板（blivedm）：贴底整宽、字号可调

**其它**
- 插件体系（`plugins_user/<名字>/plugin.py`）
- 深色主题、圆角、自绘图标；窗口状态与布局按横/竖屏分别记住

### 更现代化的 UI

- **界面形态换了一套**：原版是顶部菜单 + 一堆各自独立的播放窗口；这版改成**一整块画面墙 + 侧栏**——一格一路、圆角画面，控制按钮鼠标移上去才浮出来，平时画面干干净净。
- **多了整套竖屏**（原版没有）：屏幕竖过来（或竖屏副屏）时，顶上一栏就是关注列表、可以左右滑；主画面按 16:9 占满整行宽度，小画面自动铺满下面。
- **关注列表做成卡片**：头像 + 主播名 + 直播标题 + 开播角标一体，置顶的带角标；换布局也从文字菜单改成**缩略图**，一眼看出是几路、怎么排。
- **外观统一**：配色、圆角、字号是一套设计令牌，图标全部手绘，不会出现系统字体里缺符号那种方块字。

### 更自定义的设置

- **每一路单独调音量、静音、画质**（原版也有），**新增：可以把某一路的声音单独送到左耳或右耳** —— 想同时听两三路、又不想混在一起时特别有用。
- **菜单只列当前方向能用的布局**，不会出现「选了不对方向的布局、画面被压扁」；把窗口拖成另一个方向时还会**自动切到最接近的那一套**，不用重新选。
- **横屏、竖屏各记一套布局**换过头再换回来不会被覆盖。
- **关注列表更能折腾**：置顶、拖动排序、三种自动排序（自定义 / 开播优先 / 导入顺序）、多选删除、搜索、悬停预览开关。
- **快捷键可以在设置里改**：默认 `F` 设主画面、`Esc` 还原布局、`M` 只听这一路。
- **插件写起来有章可循**：这版提供 4 类扩展点（本体事件 / 平台 / 格子右键菜单 / 发弹幕）+ 一份接口文档

### 更流畅的体验

- **开十几路更省内存、起播更快**：原版每个画面各起一套播放内核，这版所有画面共用一套。
- **断流自己恢复**：网络抖动断流会自动重连（5 秒起、逐次翻倍、最多 60 秒），画面卡死也会自动刷新。
- **换布局、换方向不打断**：切换布局或把窗口拖成竖屏时，正在播的画面不会重连、不闪。
- **列表再长也顺**：头像、封面、表情都在后台加载并缓存在本地，关注列表拉很长也不顿。

## 运行

- **exe 便携版（推荐）**：下载 `DDMonitorCE-v0.1-exe.zip`，**解压后直接双击里面的
  `DD监控室CE-v0.1-exe.exe`** 就能用（不需要装 Python）。配置 / 缓存 / 日志都在解压出来的
  那个目录下（`utils\config.json`、`cache\`、`logs\`），删掉 `utils\config.json` 等于恢复出厂。
  里面的 `_internal\`（含 `libvlc.dll` 和 `plugins\`）是运行库，别删。
  不想解压也行：本地 `results\DD监控室CE-v0.1-exe\` 就是同一个目录。
