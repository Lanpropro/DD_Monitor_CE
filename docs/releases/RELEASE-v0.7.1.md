# DD监控室CE v0.7.1 更新说明

本次在 0.7 基础上，集中修复全屏控制栏、格子交换、SC 显示和启动布局，并增加头像与封面缓存管理。

## 全屏与画面控制

- 修复全屏底部控制栏消失后无法唤回、静置后不隐藏的问题，恢复自动隐藏与鼠标移动唤回。
- 修复弹幕布局主格进入全屏时缺少弹幕输入框，以及切换格子、进出全屏时输入框短暂闪现、黑块和残影的问题；保留各格输入草稿。
- 修复交换格子时音量条、数值和暂停图标短暂跳变或重影，继续使用原播放器，不中断媒体交换流程。
- 修复普通画面墙中弹幕盖住独立设置窗口的问题，遮挡区域随设置窗口移动、缩放、隐藏与恢复同步更新。
- 修复全屏右键打开“直播流信息”后，信息窗口落到全屏画面后方的问题；进出全屏时保留窗口和刷新。
- 修复画面墙满员时，点击开播提醒“替换”后无法通过点击播放格子完成替换的问题，Esc 仍可取消。

## SC 醒目留言

- 修复 SC 放在画面左侧时出现黑块、重复 LIVE 或标题串入的问题，保留原有颜色、拖动、缩放和独立全屏跟随。
- 调整“×”按钮：展开时点击先收起该条，收起后再点击才关闭；点击正文可重新展开，其他留言不受影响。
- 修复恢复已开启弹幕的格子时，SC 过早访问尚未创建的控制按钮所引发的启动异常。

## 图片缓存管理

- 设置 → 软件更新 → 数据与存储新增图片缓存管理，饼图展示主播头像和直播间封面的占用大小、数量与比例。
- 支持点击饼图或复选框选择类别，清理所选或全部清理图片缓存；统计和清理在后台完成。
- 头像或封面更新成功后清理其旧图片；下载、解码或保存失败时保留旧图，共享图片等最后一个引用更新后再清理。
- 饼图分别适配深浅主题，复用软件已有彩色配色。这里只统计头像与封面，不代表整个软件或磁盘的占用；不清理账号、设置、录制和插件。

## 启动、交互与稳定性

- 修复启动时侧栏控件短暂成为独立小窗口，以及窗口已最大化、格子仍停留在小尺寸布局后再铺满的问题。
- 新滚动弹幕与已加载表情沿用后台绘制任务，减少界面线程绘制工作；旧房间和过期任务结果不能重新插入当前画面。
- 弹幕操作菜单改为异步展示，减少嵌套模态循环对播放界面与交互的影响，保留复制和重复发送的原有入口。
- 修正 Windows 标题栏拖动的消息句柄读取、拖放目标在交换后失效，以及鼠标已经松开后仍尝试开始拖动的问题。
- 统一整理可复用的界面组件入口，方便后续界面沿用已有组件与主题。

## 已知问题与升级说明

- 用户新反馈的偶发滚动弹幕回退，本次未复现，仍待定位；历史关闭垂直同步时的超速修复保留，不据此宣称所有回退问题已解决。
- 部分环境的偶发卡死、原生崩溃和斗鱼线路视频缺口仍需分别采集证据，不保证本版已全部排除。
- Windows 10／11 64 位，安装版和便携版均无需 Python，内置 FFmpeg 和独立诊断工具。
- 升级保留个人配置和已安装插件；平台、互动与比赛二路插件继续独立更新，不打包本机账号、缓存、日志或插件安装副本。
