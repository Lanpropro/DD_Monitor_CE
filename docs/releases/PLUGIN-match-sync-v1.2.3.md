# 比赛二路同步 v1.2.3

1. 移除副路加入时延后主画面的路径。首次确认、中途确认及缓冲后恢复都保持主画面的播放基准，确认只记录偏移，不跳转播放进度。
2. 副路加入只检查当前同步位置是否处于连续可播放缓存内，不再为了补足安全余量延后整组画面。副路晚到或缺少内容时只静音该路，收到对应内容后自动恢复；持续晚于主画面的源可能无法加入同步。
3. 删除「延后主画面并加入」操作及提示。缺少同步内容时显示「确认当前偏移」，中途确认仍为可选，不点击也继续播放。
4. 明确缓存含义：历史缓存是保留内容的时间跨度，包含已经播放的部分；前方可播放是当前播放位置之后尚可连续播放的部分。旧缓存不能补造未收到的后续内容或时间戳空档。
