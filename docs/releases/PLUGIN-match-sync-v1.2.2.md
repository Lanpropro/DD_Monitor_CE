# 比赛二路同步 v1.2.2

1. 将需要增加播放延迟的加入按钮明确改为「延后主画面约 X 秒并加入」，说明该操作会延后主画面及已同步各路，不再混称为仅确认对齐。
2. 首次待加入且已找到偏移、但同步目标超出当前缓存的副路，使用有效缓存连续预览并保持静音，明确显示尚未同步；不再一直向尚不可播放的位置取帧。
3. 独立缓存预览不作为当前同步画面的误差依据，避免将预览与主画面不同步的差值显示为已应用校正后的实际误差。
4. 中途「确认当前偏移（可选）」仍不改变播放进度；真实晚到需要增加延迟时，由用户主动选择加入。
5. 超过 15 秒的大偏差候选需连续两次精校验一致才触发隔离，不再因单个粗匹配或单次异常候选立即跳走静音；已确认直播间在明确时间轴重置后，允许可靠结果重建偏移，仍需通过缓存范围与加入检查。
6. 断流后重新获取偏移至少收集四秒连续画面，拒绝对应内容早于副路缓存的加入请求，防止短片段重复场景被误判为已恢复同步。
