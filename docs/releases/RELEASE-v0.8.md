## 添加直播间与管理关注

- 主窗口内可以一次输入多个房间号或分享链接。系统逐条识别平台、查找房间并去重，失败项保留在面板里，方便修改后重试。
- 可直接识别 B 站个人主页及指向主页的分享链接。
- 增加了空格的增加直播间按钮，可以更快的选择你想要的主播上墙
- 重新设计并优化了导入关注窗口，支持切换平台、刷新账号、按直播状态或拼音排序、隐藏已添加主播，并实时显示新增和移除数量。宽窗口可双列显示，窄窗口自动改为单列。
- 关注文件夹支持一键展开与收起，保留当前搜索和直播筛选。可在常规设置中选择全部收起或恢复展开前的状态，也可用快捷键操作。

## 画面墙、画中画与弹幕浮窗

- 从功能栏的画面墙全局设置统一调整音量、画质和弹幕。各路依平台可用档位从高到低尝试，遇到权限限制或取流失败会继续降档。候选档位全部失败时，正在播放的画面会保留原流。
- 画中画新增「与主窗口同时播放」。开启后，主墙继续按原布局播放，小窗可选择墙上或关注列表中的房间，独立调音，关闭小窗只结束小窗播放。
- 画中画功能布局预设更新，支持单路播放、自动排列、布局预设和可贴边对齐的自定义布局。
- 弹幕栏可浮出为独立窗口，支持拖动、缩放和从全局菜单批量浮出。可按设置将画面拖入弹幕栏完成关联、换台或换位，也可从合并弹幕栏单独恢复一个直播格。
- 布局预设面板显示当前布局，区分均分与大带小，可调整面板尺寸并记忆。直播间组合可直接重命名和确认删除。
- 增加「设置 → 常规」可选择换位时让声音跟随直播间。

## 主播独立设置与录制

- 「设置 → 观看与互动 → 主播独立设置」可从按文件夹排列的关注列表添加主播，再按对应平台可用档位设置默认播放画质、录制画质和音量。未设置的项目继承默认值。主播从墙下上墙时应用预设，墙上的临时调整只影响当次观看。
- 录制可按主播指定的档位开始，结束后恢复录制前的观看画质。录制设置将录制、编码和即时回放各自成区，方便分别调整目录、格式和回放参数。
- 配置卡可单独收起，收起时仍可移除。可开启「合并相同配置」将相同设置的主播叠放显示。直接调整合并卡会更新整组，选中头像后仅编辑该主播。连续移除多位主播的设置后，可展开提示逐个撤回，也可一次恢复剩余配置。
- 继续完成了设置页面的重设计与优化

## 通知、互动与窗口操作

- 通知菜单重排类型、时间和操作，点击清空图标后自动收起。清空和关闭使用同一套图标控件。通知菜单和主播配置撤回提示跟随外观的毛玻璃设置。通知背景图可在通知设置中独立关闭，通知停留方式可选自动收起或手动关闭。
- 画面弹幕悬停时，同轨后续弹幕可从背后经过，移开鼠标后拉开间距。弹幕字体支持搜索。屏蔽用户详情可查看已有记录中的来源房间、时间和触发文本。小画面中的醒目留言先显示紧凑标题，展开后可滚动正文。
- 快捷键支持搜索操作名和当前按键，可独立设置画中画的音量、静音、单路声音和退出。悬停滚轮与 Shift 加滚轮的音量步长可分别设置，悬停直接调音量默认关闭。
- 竖屏把关注、布局、画中画、通知和设置等常用入口集中到顶部。设置页可选自动、单列或双列，自动模式会考虑主窗口方向。启动时恢复上次窗口位置、尺寸和最大化状态，退出时联动隐藏独立设置窗口。
- 托盘可显示最小化前的布局示意，并直接打开画中画或恢复主窗口。托盘菜单和画面右键菜单可分别调整项目顺序与显隐。格子全屏切换改为优先显示目标画面，再恢复控制栏，跨屏切换也调整了画面与控件的布局时序。

## 播放恢复、软件更新与诊断

- 取流和重连开始时，按钮会即时显示加载反馈。持续播放失败时，画面中央会提示重连状态及可判断的取流、传输或解码原因。
- 软件和插件更新可从通知或设置页开始。两处显示同一次下载的进度、已下载大小和速度，失败时显示原因并提供重试。关闭设置后插件下载可继续，安装或更新完成后由用户确认何时重启。软件更新继续校验附件大小及 SHA-256。
- 数据与存储可分项查看和清理图片、表情、插件目录索引、网页登录缓存及历史日志。清理网页登录缓存时保留登录状态。诊断与反馈页可选择收集范围和保存位置、导出本地诊断包，并打开问题反馈入口。崩溃记录补充故障进程、线程及图片加载信息，便于关联现场证据。
