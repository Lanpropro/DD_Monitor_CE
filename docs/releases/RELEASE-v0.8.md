# DD监控室CE v0.8 更新说明

本次更新集中完善直播间添加、画中画、画面墙全局控制和主播独立设置，并改进通知菜单、软件更新与故障取证。

## 直播间与画面墙

- 添加直播间支持一次输入多个房间号或分享链接，也可以从关注文件夹选取主播。支持识别 B 站个人主页并查找对应直播间。
- 画面墙新增全局音量、画质和弹幕入口。全局画质支持 2K 和 4K 上限，各路按平台可用档位尝试，取流失败或遇到权限限制时向下回退。
- 可为指定主播保存默认播放画质、录制画质和音量。主播从墙下上墙时应用预设，墙上的临时调整只影响本次观看。清理多位主播的配置后，可逐个撤回或一次撤回剩余全部。
- 画中画可与主窗口同时播放。支持独立选房、自动和预设布局、自定义排列，以及保存上次应用的播放模式。
- 弹幕栏可独立浮出、拖动和缩放，也可从画面墙全局菜单批量浮出。弹幕浮窗和格子之间可按设置关联或换位。

## 界面与操作

- 通知菜单重排通知类型、时间和操作按钮，支持点击清空图标后收起。通知菜单和主播配置撤回提示随外观设置使用毛玻璃。
- 快捷键补充独立的画中画操作和滚轮音量步进。关注文件夹可一键展开或折叠，保留现有搜索与直播筛选。
- 调整横竖屏下的功能入口、布局预设选择器和托盘预览。启动时恢复上次窗口状态，关闭主程序时联动隐藏独立设置窗口。
- 改进跨屏缩放时的布局结算及画面窗口的全屏切换过程，补充持续播放失败的原因与重连提示。

## 更新、插件与诊断

- 软件和插件更新显示下载速度、进度和失败原因。插件可在关闭设置后继续下载，软件更新校验使用附件大小及 SHA-256。
- 诊断页补充故障现场、日志及本地保存入口。缓存管理可按类别查看和清理，登录浏览器缓存清理保留登录状态。
- 配套平台扩展与翻译插件由独立插件仓库分发。本体补充平台替代迁移、插件字幕覆盖层及 CHZZK 公开直播支持所需的宿主能力。

## 兼容与验收

- 提供 Windows 10／11 64 位的安装版和便携版。本体使用 PySide6 6.11.2，安装包随附播放、录制和诊断所需运行组件。
- 真实直播的高画质取流、毛玻璃桌面合成、跨屏缩放及长时间播放仍需实机确认。诊断改进用于定位现场故障。
