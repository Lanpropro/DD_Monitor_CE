# 比赛二路同步 v1.2.7

1. 借鉴浏览器融合插件维持目标延迟的思路，将已确认副路的平滑校正范围从 0.2 秒扩大到 0.8 秒。0.2 秒以上的小幅漂移通过最多约 ±4% 的相对播放速度逐渐修正，较小误差继续使用原有 ±2% 调节和约 0.1 秒容忍区，减少反复跳转。
2. 平滑校正仅用于已经确认、处于已同步状态、距离本次匹配开始至少 10 秒且校正路径处于同一段连续缓存内的副路。首次对齐、重连恢复、重新匹配及其初期、独立预览、超过 0.8 秒的校正或缓存缺口继续采用原有定位与恢复规则，避免缓慢追赶已失效的进度。
3. 校正期间显示剩余误差、目标播放偏移和当前播放偏移；用户不点击可选确认也会继续校正和播放。主画面基准与其他路的偏移保持固定，画面、声音与弹幕沿用同一副路播放进度。
4. 已有人工确认的副路点击重新对齐时，先精校验当前偏移；验证失败后继续扩大到全局搜索。明确发生解码时间戳重置的源继续重新搜索，人工辅助估计仍优先使用用户提供的范围，减少丢弃有效基准后重复猜测。

本次依据浏览器插件的行为思路独立实现，没有复制其主画面延后控制。已验证正负 0.6 秒漂移的连续推进、速度上限、缓存缺口和首次/重连绕过规则；实际直播效果仍需实播确认。
