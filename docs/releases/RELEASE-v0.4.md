# DD监控室CE v0.4 更新说明

## 外观与背景美化

- 增加深色、浅色和跟随系统模式，关注栏可快速切换；鼠标切换支持可打断的圆形扩散过渡，保持直播连续播放。
- 支持本地图片和静音循环视频背景、背景遮罩；关闭视频播放后使用开头帧静态显示，隐藏或最小化时暂停背景解码。
- 设置 → 外观直接提供可点击界面预览，可修改软件整体、设置页面、布局预设的背景及限定按钮图标。
- 三个背景编辑区统一支持点击或拖放文件、显示当前背景和恢复默认；分区图片沿用设置窗口保存／取消，整体背景仍立即生效。
- 美化包通过普通插件安装。新版美化包启用时自动接管所提供的背景，之后可手动修改；重启保留个人选择，重新启用包时再次接管。
- 修复预览串页、图例重叠、标签底条和素材失效时预览空白等问题。

## 布局与直播间组合

- 支持直接拖动内置布局的可调边框，并通过角落等比例缩放；拖动时显示虚线，松手应用，Esc 取消。
- 各套布局分别保存比例，支持横竖屏、全屏退出和重启恢复；双击边框或再次选择当前布局可恢复默认比例。
- 增加“布局预设 → 直播间组合”：保存、命名、更新、重命名和删除多套观看组合。
- 组合保存布局比例、主播格位、空格子及每格音量、静音和声道；恢复时保留未开播主播的位置，并沿用录制收尾规则。

## 文件夹、弹幕与操作

- 文件夹支持自定义图标、颜色、本地图片及行内重命名；添加直播间和导入关注时可直接新建文件夹并自动选中。
- 默认 B 键控制鼠标所在格子的画面弹幕；软件激活时无需先点击格子，输入框打字时不会误触，空格子也可预设弹幕和静音状态。
- 优化画面弹幕的位置计算、刷新率适配和重绘开销，修复下播清理及圆角视频区域裁切。
- 补齐 B 站文字内嵌表情、单张图片表情和 Unicode emoji 的列表及画面弹幕显示；图片加载失败时保留文字回退。

## 稳定性修复

- 修复静音巡检将 VLC 静音标志误当作实际音频状态，导致重复下发静音的问题；补齐 PCM 输出状态和音量巡检。
- 优化关注栏收缩时的卡片排版与原生视频尺寸更新，减少多路播放时的额外开销。
- 避免 Windows 启动期间 WMI 元数据查询阻塞。
- 修复默认音量初始化、空格子音量恢复、原生视频窗口尺寸变化后的圆角，以及背景切换时旧帧污染。
- 增加明确的登录过期提示，改善软件更新按钮状态和错误反馈。

## 升级说明

- 主程序仍为 `DD监控室CE/DD监控室CE.exe`，请保留整个便携目录。已安装 0.3.1 的用户可从软件更新页升级，也可解压覆盖原目录。
- 更新保留关注、文件夹、登录、用户插件和录制数据。源码包与 EXE 包均不附带开发机配置、背景素材、缓存或用户插件。
- 自由创建行列／跨格的布局编辑器、发送弹幕及全局音量／画质总控不包含在本版。
