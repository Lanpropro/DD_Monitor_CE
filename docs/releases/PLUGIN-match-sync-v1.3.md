# 比赛二路同步 v1.3

- 新增 2/5/8 秒抗波动缓存档位，默认 5 秒；副路仍在播放但余量不足时，也会通过轻微降速逐步补充，尽量保持主画面连续播放。更高档位需要数分钟积累，不能弥补持续断流。
- 改善缓冲、重连后的持续搜索及多路匹配调度；保留已确认偏移，防止不可靠候选导致大幅跳动。中途确认偏移为可选，不点击不会反复撤销已有同步。
- 自动匹配始终使用完整画面。「选择对照区域」仅用于放大计时器、人工微调；不会清空匹配样本、触发重新对齐或改变自动/手动模式。移除「辅助自动对齐」入口，未引入 OCR。
- 对照区支持最多四路横向展示；各路状态改为图标与简短文字，悬停仅显示对应项说明，适配高 DPI。「对照微调」保持紧邻自动对齐开关。
- 恢复二路模式相关快捷键；新增房间默认音量沿用主程序设置，已保存的房间音量优先。播放栏「更多弹幕设置」可打开主程序弹幕设置并应用修改。
- 声道路由由插件内部实现，兼容移除旧音频接口的 libmpv 主程序，避免旧 v1.2 插件在 v0.5 主程序中加载失败。

已有插件时，完全退出对应程序，将 ZIP 中的 `match_sync` 文件夹覆盖到该程序的 `plugins_user/match_sync/`，保留配置和其他插件，再重启。插件仍依赖宿主接口及 PyAV、NumPy、Qt、FFmpeg 等运行组件。
