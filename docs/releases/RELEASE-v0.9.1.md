# DD监控室CE v0.9.1 更新说明

## 0.9.1 hotfix.1

本体版本为 0.9.1，内部修订号为 1。可在「设置 → 软件更新」检查更新，也可从原发布页下载新版安装包覆盖安装。

- Windows 开播通知显示圆形主播头像和直播间标题。自动录制通知沿用这两项信息，开录时更新原开播提醒。
- 修复关注栏收起时新增主播的头像插入错位和重叠。
- 打开或关闭独立工具窗口时，保留正在显示的中央功能页和导航选中状态。
- 支持接收直播间的中央功能页可接收关注卡片和应用内开播通知选中的直播间，通知操作按钮会随当前页面更新。
- 修复点击主窗口时可能误触发弹幕浮窗拖动的问题。
- 弹幕栏批量追加消息，表情加载完成后只刷新包含该表情的消息，减少整栏重排。

## 自定义布局与弹幕浮窗

- 自定义九格和十六格补全直接拖动已有直播格换位，目标位置使用与软件现有换位操作一致的提示。移动或互换格子时，只按新占位处理受影响直播格的画质。
- 自定义布局中，补全相邻且来源相同的弹幕格合并行为，补全delete移除已有的弹幕格行为。
- 独立弹幕浮窗支持多标签、置顶和相互吸附对齐。吸附后可整组拖动，也可用最左上角的位置单独移开窗口。按住向下箭头可把弹幕拖进画面墙或替换现有弹幕格。
- 增加弹幕浮窗的文字区域猫玻璃支持，修复全屏时不可以=切换弹幕来源的问题。修复弹幕栏粉丝牌与昵称对不齐、跨屏后字号不一致的问题。

## 主播监控与录制

- 「设置 → 主播监控」将开播状态监控和开播时自动录制分开配置。可分别选择是否为开播和自动录制状态发送 Windows 通知。

## 醒目留言

- 醒目留言默认在首次展示 3 秒后收起，已有的首次收起时长设置照常生效。第一次手动点开后，卡片在 5 秒后再次收起。第二次点开后，卡片保持展开，点击头像、用户名、金额所在的顶部区域即可收起。

## 播放与设置

- 修复全屏切换时部分控制栏残影和侧栏位置偏移的问题。
- 从功能栏、主播监控和更新通知打开设置时复用同一个窗口，并跳转到对应页面。
- 改善本地背景图片的加载和切换，修复 Windows 启动时继承测试环境变量或加载到错误 OpenSSL 组件的问题。

## 安装与兼容

- 提供 Windows 10／11 64 位安装版和免安装便携版。已有用户可在「设置 → 软件更新」检查新版。
