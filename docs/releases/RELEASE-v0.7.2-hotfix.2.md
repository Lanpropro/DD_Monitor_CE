# DD监控室CE v0.7.2 更新说明

## 0.7.2 hotfix.2

- 修复默认带弹幕布局的主画面为空时，启动或关闭主画面后因缺少 `room_id` 而报错退出的问题；空主画面保持未关联状态，仍可手动选择其他画面作为弹幕来源。
- 修复在设置窗口安装插件后，成功提示读取设置时发生异常的问题；插件安装完成后正常提示保存并重启。
- 修复卸载时保留个人数据后，安装器因原目录非空而拒绝重新安装的问题；识别已有数据位置记录并确认没有程序文件冲突后，允许原目录重装，继续保留个人数据和其他文件。

## 0.7.2 hotfix.1

上一版发布页补充说明：
- 尝试修复了更新时报告WinError 5的问题

- 更新前确认独立设置进程退出，减少程序仍被自身占用时替换 EXE 失败的问题；更新助手增加目标文件检查和有限重试，兼容旧版发起的更新。
- 在线更新和安装包覆盖保留内容相同的程序文件，避免为未变化的字体或运行库重复写入、因文件仍被占用而中断升级。
- 安装包覆盖前检查已有程序文件的占用、只读属性和访问权限，遇到问题时提前停止并显示具体文件，处理后可重试，无需先删除旧安装目录。持续的文件权限或安全软件限制仍需按提示处理。
- 手动升级成功后，不再把已被新版取代的在线更新失败记录显示为当前状态；原记录保留用于诊断。
- 修复诊断采集在 Qt 退出阶段未及时停止的问题；其他历史通知异常和原生崩溃仍分别跟进。
