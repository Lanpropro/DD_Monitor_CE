# DD监控室CE v0.3.1 更新说明

> 更新提示：旧版在下载本体更新或插件更新时，第一次可能报错，需要再次点击下载更新（即点击两次）。该问题已在 0.3.1 修复。

## 本地待发布改动（2026-10-15）

计划归入 **0.4（未发布）**，不属于已发布的 0.3.1 内容。须完成直播间组合预设（保存并恢复布局、主播及所在位置）及皮肤／美化功能并通过验证后，才统一更新；目前软件版本号仍为 0.3.1，暂不发布、合并远端 PR 或上传源码。

- 增加内置布局的边框拖动缩放、角落等比例缩放、虚线预览，以及各套布局比例的自动保存和恢复。
- 增加直播间组合预设本地首版：入口位于“布局预设 → 直播间组合”，保存并恢复布局比例、主播位置、空格子及每格音量／静音／声道；支持命名、重命名、更新和删除，待用户验收。
- 保存直播间组合时，在组合页面内展开名称输入、保存和取消按钮；空名称提示及同名覆盖确认均在当前页面完成，不再单独弹出名称输入窗口。
- 删除直播间组合时，确认删除与取消按钮留在对应组合卡片内，不再弹出独立确认窗口；当前播放和声音保持不变。
- 提高布局菜单可读性：增强深浅色模式下的缩略图轮廓、卡片背景和文字对比，放大布局图标；组合卡片使用独立底色和清楚的“管理”按钮，当前项保留蓝色边框，恢复默认比例按钮改为实线边框。
- 分区美化恢复验收：布局预设／直播间组合弹层接入菜单底板，页内按钮及管理图标接入通用按钮分区；保留布局缩略图内容。
- 美化入口恢复可点击界面预览，保留专业参数与已有配置；用户要求通过减少可修改项目、增加预设简化操作，具体范围待逐项确认。
- 去除格子之间独立的灰色分隔条，直接拖动格子边框调整大小；再次点击当前布局缩略图恢复默认比例，保留底部重置按钮。
- 适配当前版本的背景皮肤、默认音量初始化和关注栏收缩逻辑，修复旧布局最小尺寸阻碍横竖屏切换的问题。
- 关注栏、添加直播间和导入关注中的“新建文件夹”统一使用图标编辑样式，可同时填写名称、选择内置图标、颜色或自定义图片；保留新建后自动选中。修复新建／修改图标窗口四角露出矩形背景和无法拖动的问题，支持拖动标题栏及顶部空白处。
- 软件更新按钮明确区分尚未检查、正在检查、没有新版、可下载和可重启安装；不可用时改为灰色并解释原因，下载失败后仍可重试。
- 比赛二路插件本地兼容修复：已发布本体缺少新版动画常量时，入口按钮使用 Qt 标准缓动，避免插件加载失败；本体与插件版本号及远端安装包暂不变更。

感谢原贡献者 [Milkyway-66](https://github.com/Milkyway-66) 提供布局拖动功能的 [PR #6](https://github.com/Lanpropro/DD_Monitor_CE/pull/6) 和 [PR #7](https://github.com/Lanpropro/DD_Monitor_CE/pull/7)。上述功能已在其贡献基础上完成本地适配和交互调整，最终提交到仓库的将是我们修改后的版本。当前仅保留本地，远端 PR 合并和源码上传随本次版本更新完成后统一进行。

## 本体更新

- 增加普通文件夹和智能文件夹，支持跨平台手动分类、独立排序、文件夹及卡片拖动、空白处右键新建；添加和导入直播间时可选择文件夹。
- 智能文件夹支持开播状态、平台组合条件，来源可多选普通文件夹和未分类，也可选择全部关注。可选择匹配时移入显示，或保留原处同时显示；原文件夹归属保留，不匹配时回到原处。
- 增加滚动画面弹幕，多格子和全屏均可使用，右下角调整字号、速度、透明度、显示范围与缩放。
- 增加全屏闲置光标隐藏。
- 增加单独启动的即时重放功能。
- 防止本体过于臃肿，完善插件功能，增加插件商店，可以从[官方仓库](https://github.com/Lanpropro/DD_Monitor_Plugins)下载和校验插件。
- 增加独立的软件更新页，支持检查版本、查看说明、后台下载、重启安装与替换失败回滚。自动更新开关开启后启动时检查新版，显示可点击跳转、十秒自动消失的悬浮提醒；没有新版时展示当前版本说明。保留关注、文件夹、登录及用户插件数据。
- 首次启动显示用户须知，确认或关闭后正常使用，后续不再弹出；提供项目、反馈及维护者链接。
- 增加窗口、设置页、关注卡片、文件夹、菜单和拖动反馈动效，支持系统动画开关与操作打断；窗口滑入保持不透明。
- 增加操作结果提示，添加与导入显示主播头像，三秒后自动收起。

- 增加声音轮询按键，默认为 E，按鼠标所在格子依次切换静音、双声道、左声道、右声道；可在快捷键设置中修改。
- 增加本体及插件更新红点，放在对应入口右侧；启动时上方居中提示新版，十秒后自动消失，点击进入更新页面。查看后清除该版本红点，更高版本重新提醒。
- 插件支持同时下载多个安装包，每个插件独立显示进度；已安装页面可查看新版更新日志并直接更新。
- 精简常规设置选项并调整顺序，保留原有画质和卡片显示配置。
- 导入关注支持名称搜索、已导入主播取消选择及调整文件夹；支持恢复抖音关注账号并单独识别房间。
- 导出包的主程序及进程名固定为 DD监控室CE，版本号由软件更新页面及文件版本信息显示。

## 在线更新发布要求

0.3 是第一个包含更新入口的版本，旧 v0.2 首次需手动升级。后续本体发布上传 EXE ZIP 和 `app-update.json`；插件发布上传各插件 ZIP 和 `plugin-catalog.json`。版本、校验值及流程见 `docs/online-updates.md`。

0.3.1 额外保留一次带版本号的兼容入口，让 0.3 用户可以在线升级；平时请启动 `DD监控室CE.exe`，后续版本不再附带带版本号的入口。

EXE 包内程序目录及日常启动文件固定为 `DD监控室CE/DD监控室CE.exe`，在线更新保留原安装目录，避免按路径设置的白名单因版本号变化而失效。手动更新请解压覆盖原目录。
