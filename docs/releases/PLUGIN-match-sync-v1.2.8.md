# 比赛二路同步 v1.2.8

1. 调整主路策略：正常情况下继续由各副路对齐主画面；只有已验证的副路持续晚到至少 5 秒时，才尝试平滑增加共同缓冲。通过已有音频播放时钟以最多约 2% 的轻微降速积累延迟，不暂停、不跳转主画面，不更换主直播间，画面、声音与弹幕继续共用同一播放进度。
2. 自动建立缓冲最长尝试 2 分钟，并预留约 0.5 秒余量。缺口太大、主路连续缓存容量不足、晚到程度继续增长或到期仍未跟上时停止尝试；在「对照微调」右侧显示「某某路过慢，请更换主画面」，列出受影响的直播间。约 16 秒的缺口无法在此平滑调整幅度和时间内补足，会提示更换主画面。
3. 建立缓冲时，在同一位置提示具体哪一路持续晚到；完成后保留已经积累的额外缓冲，避免主路加速追回直播端后再次失配。正常副路保持播放，缺少同步内容的副路仍单独静音，缓存覆盖并复核后恢复。
4. 未验证候选、时间戳重置后尚未重新验证或已经断流的源不会触发主路缓冲调整。重连源重新通过精校验后可参与晚到判断。手动模式、停止观看和切换主画面会清理该策略与提示。
5. 修复切换框选区域时的并发污染：旧区域正在计算的特征可能在清空缓存后重新写入，造成新旧区域或不同特征尺寸混用、精校正持续失败。区域版本校验会丢弃过期特征，原始视频帧继续接收。

验证包含持续播放时吸收约 1 秒晚到、主路与正常副路连续推进、16 秒缺口提示位置、缓存容量不足及缩小、三路中单路持续变慢、超时、候选未确认及取流过期等情形。真实解码并发检查已复现旧版框选污染并验证修复。轻微降速建立延迟需要时间，每积累 1 秒约需 50 秒；真实网络断流或设备资源不足仍可能中断播放。
