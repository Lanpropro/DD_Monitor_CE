# DD监控室CE v0.5 更新说明

本次以已合入 develop 并完成验收的功能为范围，提供 Windows x64 便携包；解压后运行 `DD监控室CE.exe`，无需安装 Python。

## 新增与调整

- 通知中心：收集历史通知，支持未读状态、删除与通知设置；顶部通知卡片支持持续显示、主播头像和开播点击操作。
- 发送弹幕：增加 B 站原生弹幕功能，来自 [reon-nynes](https://github.com/reon-nynes)。
- 音量控制：为了在更小的空间下放下弹幕输入框，格子会将音量条切换为竖向方式，采用紧凑半透明悬停面板，保留原有音频输出和音量控制能力。
- 录制支持按时长自动分段；导出成功后清理临时日志和拼接清单，并提供打开位置、复制路径和较短文件名通知。
- 关注栏悬停预览等待缩至 500ms，排序入口整合到文件夹右键菜单。
- 支持 `Del` 关闭鼠标所在格子；优化弹幕黑色描边、遮罩与控件显示。
- 优化关注栏滚动、窗口拖动、预览资源释放及播放器生命周期。
- 增加软件安装包与卸载包。
- 设置页面性能：切页使用快照合成，缩短过渡时间；录制设置支持页面内部滚动。
- 视频背景性能：将视频帧转换移到后台，减少界面线程负担，并丢弃切换素材后的过期结果。
- 格子边框绘制性能：复用透明边框绘制结果，减少重复上传和重绘。
- 导出成功后遗留日志文件：录制和即时回放成功后清理对应导出日志，保留原有拼接清单清理；失败时仍保留恢复材料。
- 增加偏好观看排序：常看的直播间会在开播后优先置于关注栏上方
- 新增软件首页：[DDMonitor](https://ddmonitor.top/)。

## 修复

- 支持手机复制的带中文标题分享文本，自动提取直播链接并在后台展开 B 站 `b23.tv` 短链接；非直播链接和失败请求不会误识别为数字房间号。
- 增加弹幕表情包缓存，更快的发送图片为你推打call。
- 修复主屏最大化后拖到副屏、再次最大化时，播放区域画面黑屏、只有弹幕而关注栏完好的问题；保留已验收的跨屏弹幕窗口修复。
- 修复音频输出释放过程中播放器线程退出异常，以及拖动、关闭格子时的原生窗口生命周期问题。
- 修复明暗主题字体显示不清的问题。

## 安装包

- 新用户可使用 `DDMonitorSetup.exe`，默认安装到当前用户目录，支持快捷方式及卸载；卸载仅移除安装器登记的文件，保留账号、配置、插件、录制与额外文件。
- EXE 默认弹幕绘制方式与日常启动脚本一致，包含已验收的跨屏最大化修复；显式设置的兼容模式仍保留。

## 升级与后续

- 老用户仍然可以通过软件内的更新页面完成该次更新，新用户可以无需下载软件压缩包，转而使用 `DDMonitorSetup.exe` 来完成文件的首次安装。
