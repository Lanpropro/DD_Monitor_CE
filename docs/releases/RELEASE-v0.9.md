# DD监控室CE v0.9 更新说明

## 主播监控与录制

- 在「设置 → 主播监控」选择要监控的主播。开启自动录制后，软件会在检测到主播开播时录制，即使该直播间未加入画面墙。可为主播设置录制画质和 Windows 通知。安装兼容的 DDCut 插件后，也可按主播选择切片录制。
- 主窗口左侧新增「监控」菜单，可查看监控与录制状态、平台、主播 ID 和录制时长，并直接进入主播监控设置。录制中的头像沿用关注栏的波纹效果。
- 在「设置 → 托盘行为」可开启托盘的主播监控区。托盘分开显示正在录制和监控中的主播，同类主播用叠放头像显示。
- 后台自动录制遇到断流时，续录前先核对房间状态。确认下播后保存已有录像，并防止迟到的开播状态为同一场直播重新开录。

## 画面墙与播放

- 「布局预设」支持调整内置预设的画面比例，预览后可保存、撤回或恢复默认。新增自定义九格和十六格，直播画面与独立弹幕格可拖到空位自动对齐，直播格的比例和高度可用可配置的滚轮快捷键调整。
- 常规设置新增画面墙无缝布局和普通直播格透明控制栏选项。控制栏可以随闲置收起，移动鼠标唤回所在格。未开播或已下播的格子可以直接选择其他主播替换。
- Windows 单格全屏留在原主窗口里，OBS 同一个窗口捕获源可以跟随进出单格全屏。画中画滚轮调音量时显示对应主播名及当前音量。
- B 站 App FLV 遇到特定 CDN 错误时会尝试 AVC HLS 线路。直播格和画质菜单统一显示分辨率与帧率。

## B 站互动、通知与诊断

- 本体提供 B 站直播弹幕输入、表情、站内关注和礼物入口。互动可用性取决于 B 站登录状态、直播间权限和平台规则。
- 启动时可以查看官方公告。通知菜单删除单条通知时其余卡片随之补位，清空后自动收起。
- 诊断工具可导出设置滚轮、性能和窗口消失等专项记录。定位功能栏悬停异常时，可在设置中或通过独立诊断工具按需开始采集。

## 安装与兼容

- 提供 Windows 10／11 64 位安装版和免安装便携版。已有用户可通过「设置 → 软件更新」检查更新。安装包和便携版均随附播放器与录制所需的运行组件，Qt 版本为 PySide6 6.11.2。
- 平台扩展等插件独立安装和更新。本体为兼容的原生直播工作台提供缓存进度定位能力，具体用法以插件的版本说明为准。
