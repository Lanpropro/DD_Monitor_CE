## 主播监控与录制

- 「主播独立设置」升级为「主播监控」。可为每位主播设置播放画质、录制画质、音量及自动录制。开启录制总开关和该主播的自动录制后，软件检测到主播在播即开始录制，主播未上墙也可在后台录制。我们的监控室终于变成监控室啦
- 录制卡片将画质和音量与自动录制分区显示，收起后仍可看到自动录制、Windows 通知和录制方式。兼容的 DDCut 插件可按主播选择普通录制或切片录制，从下一次自动录制起生效。
- 可在通知设置和主播卡片同时开启 Windows 通知，用于提醒自动录制开始和确认下播停止。关注卡片以主题色圆环标出监控状态，录制时头像显示持续扩散的波纹。
- 左侧功能栏新增「监控」菜单，集中显示监控及手动或自动录制中的主播。可查看头像、平台标识、录制状态和时长，并从底部直达主播监控设置。
- 托盘菜单中的「主播监控」可在「设置 → 托盘行为」开启并调整位置，默认关闭。开启后直接显示只读的「录制」和「监控」区。同类型、同一配置组的多位主播用叠放头像显示，录制组显示最长时长，悬停可查看已显示主播各自的时长。
- 自动录制断流后先单独查询房间状态。确认下播即保存已有录像，迟到的开播状态也不会为同一场重新开录。房间仍在线或暂时查不到状态时，继续按原有间隔重试。

## 画面墙与布局预设

- 你现在可以自定义修改我们的布局预设了，在布局预设菜单的右下角就可以创建属于你的内容
- 新增「自定义九格」和「自定义十六格」。这是参考 直播水族馆 项目实现的伪自定义布局功能，我不是很喜欢但是功能上实现还算简单。默认用 `Ctrl` 加滚轮等比缩放直播格，用 `Alt` 加滚轮逐行调整直播格高度。
- 未开播和已下播的格子在状态文字旁提供替换入口，可从关注列表或用房间号、链接选房。
- 「设置 → 常规 → 播放与声音」新增「无边界布局」，开启后移除画面格之间的间距。

## 播放、全屏与画中画

- 普通直播格可在「设置 → 常规 → 播放与声音」启用透明渐变控制栏，也可单独开启闲置自动隐藏。空格同样支持透明控制栏，移动鼠标只唤回所在格。画面上方的按钮统一悬停和按下反馈，已选 L/R 声道以主题蓝显示。
- 修复了obs窗口捕获无法捕获到我们全屏页面的问题
- 画中画使用滚轮快捷键调音量时，浮层显示鼠标所在直播格的主播名和当前音量百分比。
- 优化了「直播流信息」窗口的UI，并且规定出现位置默认在对应格子的左上
- B 站 App FLV 遇到特定 CDN 错误时会尝试 AVC HLS 线路，画质列表会跟随实际取流线路更新。

## B 站互动、弹幕与醒目留言

- 将Bililive插件功能内置到了软件之中，我们这下终于原生支持B站了。
- B 站直播弹幕输入、表情、站内关注和礼物入口已由本体提供，旧的 B 站直播互动插件升级后会跳过加载。互动可用性取决于 B 站登录状态、直播间权限和平台规则。
- 放大 B 站表情选择面板和弹幕栏里的表情。弹幕栏在默认字号下使用 48 像素高的表情。
- 弹幕菜单统一复制、复读、屏蔽内容和屏蔽用户。误屏蔽时可从操作提示立即撤回；撤回后，仍符合其他屏蔽条件的弹幕继续保持隐藏。
- 设置页的醒目留言预览在弹幕栏空间较小时改用扁宽双色卡片，可在右侧整列拖动，也可从右下角调整大小。

## 关注栏、竖屏与外观

- 多选与刷新回到关注工具栏，卡片／列表切换移至关注栏的「⋯」菜单。关注列表的收起与展开使用分栏箭头。添加面板打开和关闭时，入口加号随之旋转和复位。导入关注时会优先复用侧栏已有的头像。
- 竖屏顶部入口重新排布，通知、主题切换和清空画面等常用操作保持易达。关注列表的展开、收起和工具按钮随横竖屏切换调整位置。
- 修复部分插件入口偶尔缺少悬停高亮的问题。鼠标实际指向入口时，图标和按钮底色会更新。
- 主题色与文件夹颜色选择器更新，平台登录栏、布局标签和主题色板等控件沿用「外观 → 滑动分段指示器」的设置。可在「设置 → 快捷键 → 滚轮设置」将设置页每格滚轮的移动距离调为 1× 至 4×。
- 「数据与存储」刷新统计时显示加载反馈，完成后显示合计占用和统计耗时。

## 安装与兼容

- 提供 Windows 10／11 64 位安装版和免安装便携版。已有用户可通过「设置 → 软件更新」检查更新。两个发行包均随附播放器与录制所需的运行组件，使用 PySide6 6.11.2。
- 本体为兼容的原生直播工作台提供缓存进度定位。需要平台扩展、DDCut 切片等功能时，可安装对应的兼容插件，具体能力以插件说明为准。
