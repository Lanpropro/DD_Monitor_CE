# 比赛二路同步 v1.2.6

1. 增加「辅助自动对齐」：在副路对照卡片上打开，比较两张定格画面，填写副路比主画面快或慢约多少秒。软件将实际展示帧的时间戳与人工判断换算成搜索范围，在估计附近约 ±4 秒内验证连续画面，保持自动对齐开启。错误估计或静止画面不会直接被当作可靠偏移。
2. 修正普通匹配超过 15 秒就被拒绝的问题。大偏差需要多次、随时间推进的精校正；已确认偏移出现大幅跳变时保留原进度，并提示使用人工辅助复核。重连继续使用恢复验证及三路一致性检查。
3. 区分目标早于已保留缓存、目标内容尚未收到、目标位置存在断流缺口。历史缓存长度与同步目标处的前方可播放时长分别显示；增加历史保留不能补充尚未收到的内容。
4. 主画面播放基准继续固定，副路校正与确认不会延后主路；中途校正后确认仍为可选。
5. 配套主程序优化：插件页和软件更新页改为首次访问时创建，普通设置保存不再无条件刷新皮肤。增加窗口准备、首次绘制、页面创建、保存阶段及二路音频供给间隔的本地耗时记录。
6. 二路混音与音频设备供给移至独立线程。界面只提供音量、偏移、同步状态快照；打开设置短暂阻塞界面时，音频继续读取已有缓存。停止、切换输出设备和重新开始时释放并重建音频线程。

设置窗口优化涉及主程序源码，仅替换插件 ZIP 不包含这部分修改。独立音频线程可以避开设置构建造成的界面阻塞；源内容尚未收到、实际断流或系统资源不足仍可能中断播放。真实直播、动态背景下仍需实播确认。

验证：通过人工辅助、大偏差保护、缓存缺口、固定主路、重连、快捷键、设置与外观等回归；双路、三路实际本地媒体接收及四路对照通过。独立音频线程在两次各 550 毫秒的界面阻塞中持续供给非静音 PCM，真实默认音频设备的启动、切换与释放检查通过。
