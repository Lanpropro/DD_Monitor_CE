# B 站醒目留言显示

## 功能

- SC 卡片新增圆形用户头像、14px 正文和用户名右侧倒计时，金额无独立底色；圆角与头像边缘使用抗锯齿。

- 弹幕格消息区右上角浮动显示醒目留言，不占满整行；一至两条分别展示，三条及以上折叠并显示总条数，默认金额高的在最上方。点击下层卡片可切换，“共 N 条”可轮换更多留言。
- 弹幕布局下主画面 SC 移至弹幕栏，小画面各自保留；主画面全屏时显示在视频内。无弹幕栏时，SC 显示在画面右上角。
- 收到实时留言时即时更新，并进行房间内 ID 去重、删除与到期处理。
- 进入房间时通过 B 站只读接口补充当前活动留言，失败不影响普通弹幕连接。
- 画面弹幕菜单和全局弹幕设置提供独立 SC 显示开关与不透明度；无弹幕栏时，画面弹幕主开关同时控制画面 SC；弹幕布局中该按钮只控制滚动弹幕。
- 右上角“×”使用与通知相同的 240ms 收拢动效（遵循系统动画设置），可在本机隐藏当前 SC，面板与画面同步；其他活动留言继续显示，不发送服务器删除请求。
- 关闭弹幕格或移除对应画面后，房间留言状态随之清理。

## 兼容与范围

- 只处理 B 站数字房间；其他平台继续使用现有弹幕接口。
- 不保存留言内容，不新增账号、Cookie 或配置项。
- 普通弹幕、礼物和上舰消息的现有路由不变；醒目留言不再混入普通弹幕时间线。
