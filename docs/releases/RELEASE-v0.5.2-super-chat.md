# B 站醒目留言显示

## 功能

- 弹幕格顶部固定显示当前活动的醒目留言；空间不足时最多显示三张，其余条数合并提示。
- 直播画面右上角同步显示醒目留言；窄画面只显示当前能容纳的卡片。
- 收到实时留言时即时更新，并进行房间内 ID 去重、删除与到期处理。
- 进入房间时通过 B 站只读接口补充当前活动留言，失败不影响普通弹幕连接。
- 醒目留言沿用画面弹幕的透明度和开关状态；关闭弹幕时只隐藏，重新开启后恢复。
- 关闭弹幕格或移除对应画面后，房间留言状态随之清理。

## 兼容与范围

- 只处理 B 站数字房间；其他平台继续使用现有弹幕接口。
- 不保存留言内容，不新增账号、Cookie 或配置项。
- 普通弹幕、礼物和上舰消息的现有路由不变；醒目留言不再混入普通弹幕时间线。

## 验证

- `repository`、`offline` 套件及 `selfcheck_super_chat` 专项通过。
- Windows 原生 Quick 弹幕检查通过，覆盖卡片遮罩和普通弹幕共存。
- 真实 WebSocket 推送、不同窗口尺寸、高 DPI 和实际直播画面仍需人工验收。
