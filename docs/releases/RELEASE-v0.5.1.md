# DD监控室CE v0.5.1 更新说明

## 修复版，请更新这版非常感谢

## 播放与弹幕

- 修正移动格子后弹幕停留在原位置、悬浮栏文字残留和开启弹幕后黑底加粗的问题；移动时仍可能存在轻微跟随延迟。
- 修正弹幕遮挡通知、对话框的问题，以及格子左上角的小遮挡。
- 补充弹幕层退出时的对象有效性检查。
- 适配 B 站实际提供的 4K 清晰度与取流；可用画质仍取决于直播间和登录权限。
- 全屏时，增加键盘 ↑ 增加音量 10，↓ 减少音量 10，范围为 0–100。

## 关注与设置

- 包含日常开发入口已有的标题栏主题配色；开发和发布统一使用 PySide6 6.11.2。
- 修复了常规设置关注栏平台 Logo 显示开关消失的问题。
- 关注栏和导入关注支持主播名的全拼、拼音首字母及连续重复首字母省略，例如“大东彦”可搜 ddy，“大橙橙橙子”可搜 dcz。
- 优化了超多关注用户的导入关注状况；完整读取大账号的 B 站关注分页，避免默认分页上限截断。
- 修正紧凑关注栏漏高亮及连续滚轮预览残留，复用共用预览播放器核心，减少反复初始化造成的停顿。

## 升级后的旧程序文件清理

- 再次尝试优化了软件内升级版本后的过时文件清理
