# DD监控室CE v0.5.1 更新说明

## 播放与弹幕

- 修正移动格子后弹幕停留在原位置、悬浮栏文字残留和开启弹幕后黑底加粗的问题；移动时仍可能存在轻微跟随延迟。
- 修正弹幕遮挡通知、对话框的问题，以及格子左上角的小遮挡。
- 补充弹幕层退出时的对象有效性检查。
- 适配 B 站实际提供的 4K 清晰度与取流；可用画质仍取决于直播间和登录权限。
- 全屏时，键盘 ↑ 增加音量 10，↓ 减少音量 10，范围为 0–100。

## 关注与设置

- 包含日常开发入口已有的标题栏主题配色；开发和发布统一使用 PySide6 6.9.3。
- 常规设置增加关注栏平台 Logo 显示开关。
- 关注栏和导入关注支持主播名的全拼、拼音首字母及连续重复首字母省略，例如“大东彦”可搜 ddy，“大橙橙橙子”可搜 dcz；不搜索直播标题。
- 分批导入关注，优化头像回填和侧栏头像复用；完整读取大账号的 B 站关注分页，避免默认分页上限截断。
- 修正紧凑关注栏漏高亮及连续滚轮预览残留，复用共用预览播放器核心，减少反复初始化造成的停顿。
- EXE 默认启用已验收的独立设置进程，减少打开通用设置对播放界面的影响；可通过 DDM_SETTINGS_PROCESS=0 使用原设置窗口。

## 升级后的旧程序文件清理

- Windows EXE 在升级到此版本后，正常启动会在后台核对历史发行包的程序文件。
- 只将不属于当前版本、且大小与 SHA256 均匹配历史发行包的文件移入 work/legacy-program-backup-*；备份目录包含 cleanup-report.json。
- 配置、登录信息、用户插件、缓存、日志、录制及未知或被修改的文件保留。被占用或路径含链接的文件跳过，后续启动可重试。
- 备份不自动删除，因此本功能整理程序目录，但不会立即释放备份占用的磁盘空间。确认新版运行正常后，可在退出软件时自行删除对应备份；需要恢复时按报告还原。
- 软件内更新使用 EXE ZIP；安装版首次安装和便携版均包含当前程序文件清单。

## 验证与待观察

- 3000 关注、750 主播的隔离压力测试通过；真实大账号人工验收按维护者安排，在发布后交用户完成。
- 滚轮预览残留、悬停高亮继续观察；概率漏人及导入窗口遮挡尚未在用户环境复现。
- 正式 0.5 的长期播放卡顿、崩溃和 NVIDIA 信息浮窗识别问题尚未定位完成，本版不将其列为已解决。
