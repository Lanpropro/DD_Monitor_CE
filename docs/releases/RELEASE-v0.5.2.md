# DD监控室CE v0.5.2 更新说明

本版汇总正式版 0.5.1 之后的更新与修复。

## 关注导入

- 修复导入单个新主播并选择文件夹时，原有关注也被一起移动的问题。默认勾选的已有关注保留原文件夹，仅新增或本次主动勾选的主播进入目标文件夹。
- 已有关注需要重新归类时，可取消后重新勾选，或搜索后点击「全选」明确选择当前结果。取消勾选并确认导入仍会移除本地关注，不会取消平台上的关注。
- 导入完成提示只显示本次新增数量和新增主播头像，不再混入默认勾选的已有关注。

## 设置与插件

- 保留独立设置进程，切换页面时复用设置窗口，减少高负载播放对设置操作的影响。
- 修复插件安装或删除后「保存并重启」可能留下无响应设置页的问题；保存后等待设置窗口退出并解除嵌入，再执行重启或更新。
- 软件更新下载期间可关闭设置，后台继续下载，重新打开保留进度；完成后保留「重启并更新」，不再重新下载。退出软件仍会停止未完成下载。
- 更新说明优先读取对应版本的 GitHub Release 正文，支持发布后修改；网络失败时显示备用说明。
- 完善独立设置中的平台 Logo 开关、主题背景和默认窗口高度，以及软件更新页的安装请求传递。
- 插件商店合并多个正式 Release 中的插件版本，首次打开后台刷新；插件更新过程中保留滚动位置，删除确认使用中文名称和主题样式。
- 插件商店增加作者署名，感谢 [reon-nynes](https://github.com/reon-nynes) 的 [PR #33](https://github.com/Lanpropro/DD_Monitor_CE/pull/33)。
- 新增插件通知与登录请求接口，支持后台线程调用；插件卸载或窗口关闭后停止处理过期请求。平台和互动插件继续独立安装，不内置本机插件副本。

## 全屏显示

- 修复开播时间与底部控制条重叠的问题，时间显示随控制条显隐调整位置。

## 下载与升级

- 新用户：[安装版](https://github.com/Lanpropro/DD_Monitor_CE/releases/download/v0.5.2/DDMonitorSetup.exe)。
- 便携版：[EXE ZIP](https://github.com/Lanpropro/DD_Monitor_CE/releases/download/v0.5.2/DDMonitorCE-v0.5.2-exe.zip)。
- 已有用户可在设置中检查更新，下载后点击「重启并更新」；覆盖升级保留个人配置和已安装插件。
- 本版包含发布时根目录已提交的完整开发功能，开发与发布统一使用 PySide6 / Qt 6.11.2。
- 保留 0.5.1 已有的自定义布局创建、编辑、命名、保存、删除、跨行跨列及横竖屏预览等功能。

## 验证范围

- 使用合成数据覆盖「32/33 位原关注＋1 位新增」、原归属保留、明确重新归类、取消勾选、保存及提示；在根目录 `run.cmd` 隔离离屏复测。
- 覆盖下载中关闭/重开设置、后台完成、程序退出、线上发布说明刷新及失败回退；执行仓库、离线、冒烟、独立设置进程、屏幕外原生嵌入及重启回归。
- 已在维护者指定的 0.5 解压目录完成软件内更新，重启后版本、EXE、元数据及说明文件均核实为正式 0.5.1。另有用户首次更新显示旧版本的原因仍待确认，不将其列为已修复问题。
- 本轮未使用真实账号或向直播间发送测试消息；真实直播、音频听感及跨屏体验未重新验收。
