# DD监控室CE v0.5.2 更新说明

## 关注导入

- 修复导入单个新主播并选择文件夹时，原有关注也被一起移动的问题。默认勾选的已有关注保留原文件夹，仅新增或本次主动勾选的主播进入目标文件夹。
- 已有关注需要重新归类时，可取消后重新勾选，或搜索后点击「全选」明确选择当前结果。取消勾选并确认导入仍会移除本地关注，不会取消平台上的关注。
- 导入完成提示只显示本次新增数量和新增主播头像，不再混入默认勾选的已有关注。
- 保留现有自定义布局的创建、编辑、命名、保存、删除、跨行跨列及横竖屏预览功能。

## 设置与插件

- 保留独立设置进程，切换页面时复用设置窗口，减少高负载播放对设置操作的影响。
- 修复插件安装或删除后「保存并重启」可能留下无响应设置页的问题；保存后等待设置窗口退出并解除嵌入，再执行重启或更新。
- 完善独立设置中的平台 Logo 开关、主题背景和默认窗口高度，以及软件更新页的安装请求传递。
- 插件商店合并多个正式 Release 中的插件版本，首次打开后台刷新；插件更新过程中保留滚动位置，删除确认使用中文名称和主题样式。
- 集成插件格子接口及商店作者署名，感谢 [reon-nynes](https://github.com/reon-nynes) 的 [PR #33](https://github.com/Lanpropro/DD_Monitor_CE/pull/33)。平台和互动插件继续独立安装，不内置本机插件副本。

## 下载与升级

- 新用户：[安装版](https://github.com/Lanpropro/DD_Monitor_CE/releases/download/v0.5.2/DDMonitorSetup.exe)。
- 便携版：[EXE ZIP](https://github.com/Lanpropro/DD_Monitor_CE/releases/download/v0.5.2/DDMonitorCE-v0.5.2-exe.zip)。
- 已有用户可在设置中检查更新，下载后点击「重启并更新」；覆盖升级保留个人配置和已安装插件。
- 本版包含发布时根目录已提交的完整开发功能，开发与发布统一使用 PySide6 / Qt 6.11.2。

## 验证范围

- 使用合成数据覆盖「32 位原关注＋1 位新增」、原归属保留、明确重新归类、取消勾选及保存；在根目录 `run.cmd` 进行隔离离屏复测。
- 执行仓库、离线、冒烟、统一账号导入、独立设置进程及更新链路回归。真实账号、直播播放和人工重启体验未在本轮重新验收。
