# DD监控室CE v0.6 更新说明

2026-10-30：已通过 Windows 10 虚拟机最终验收。安装包和便携版均包含诊断工具 1.2。

## 弹幕与醒目留言

- 弹幕布局的发送栏移到弹幕栏底部，补齐浅色模式；右下角增加回到底部按钮。
- 普通弹幕支持左键打开横向悬浮操作栏，提供复制和“+1”发送；滚动弹幕悬停暂停，弹幕栏增加选中反馈。
- B 站 SC 支持活动留言快照、实时更新、去重、删除及倒计时。卡片显示头像、用户名、同排剩余时间、金额和放大的正文。
- 带弹幕栏时，主画面 SC 显示在弹幕栏右上角，小画面各自保留；主画面全屏时回到视频内。
- 一至两条 SC 分开展示，三条起折叠；默认金额高的在最上方，点击下层切换，点击总条数轮换查看更多。
- SC 可单独开关和调节透明度，关闭使用通知相同的收拢动效；修复边缘串色、关闭露黑和遮挡。
- 修复 Qt 插件画面中滚动弹幕不显示的问题。

## 通知与音量

- 通知 Banner 增加可调模糊强度和预览，文字与头像保持清晰。
- 缩短录制文件的历史通知路径，避免重复通知。
- 音量按钮图标居中，默认立体声时 L/R 同时高亮；非零音量调整可解除静音。

## 安装与数据

- 安装版使用独立用户数据目录，便携版继续使用程序旁数据；设置中提供目录迁移，数据与存储选项并入软件更新页。
- 安装时可选择当前用户或所有用户权限及目标目录；卸载默认保留个人信息，可选择清理实际数据目录与已登记的插件文件，录制及未登记文件保留。
- 支持系统托盘及首次关闭时记住用户选择。

## 日志与诊断

- 统一早期启动日志、凭据脱敏和轮转，保留崩溃与卡死调用栈。
- 附带从同一源码提交重新构建的独立诊断工具 1.2，包含原生 DLL/函数入口、平台请求与播放日志、安装版数据位置等检测。
- 固定打包 Vulkan 加载器与许可，补齐此前仅在测试包中手工加入的 Win10 依赖。

## 平台与测试范围

- 本体保留已验收的抖音直播间资料读取、验证窗口提示及原画支持。
- 平台插件仍独立分发，不将个人已安装插件或账号带入安装包。抖音弹幕发送仍未完成，不列为本版完成项。
- SC、安装、日志和本地播放已通过相应自动检查；用户已确认 Win10 最终验收通过。
