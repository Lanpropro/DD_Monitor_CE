# DD监控室CE v1.0 更新说明

## 画面墙与播放

- **单格直播回放。** 在侧栏打开「直播回放」，点选要缓存的直播格。各路可以共用缓存时长，也可以按主播单独设置，确认前可查看预计磁盘占用。开启后，每路会额外拉取一路直播流。播放时可在格内拖动时间轴预览，松手跳到对应时刻，查看当时的弹幕，或点「回到最新」返回直播。取消勾选或将该路移出画面墙会清理缓存。
- **B 站直播自动追帧。** 在画面墙或画中画中右键点击直播格，可以为这一路开关自动追帧。落后直播进度时，播放器会短暂加速。刷新直播或将该路移入、移出画中画时会保留选择。
- 满墙切换布局、将窗口拖到竖屏再最大化时，减少重复调整格子和控制栏的次数。切到较小布局时，仍按新布局容量清除超出的直播间。
- 改进鼠标快速划过相邻直播格时的底栏唤醒。窄格若放不下左上角的主播信息，会自动隐藏文字，给画面留出空间。

## 组合画中画与托盘

- 「组合画中画」支持与主窗口同时播放，小窗默认静音。也可以勾选「已上墙的直播移到画中画」，把选中的直播移出主墙并继续接收弹幕。关闭小窗时，只将直播放回仍然空着的原格。
- 组合预览可以直接拖动视频格换位，也可以拖入弹幕栏并调整位置。开启「显示弹幕栏」后，小窗内即可查看主画面的弹幕和醒目留言。修正三路自动排列时底行铺不满、布局留空处边缘出现锯齿的问题。
- 打开组合选择面板时按需绘制房间卡片。打开小窗时减少整墙短暂露出，返回主窗时合并多次布局调整。
- 托盘菜单可显示当前画面墙的布局和主播头像、按相同布局打开画中画。在托盘设置中开启分路音量后，可以直接对某一格调音量或静音。

## 主播监控与录制

- **自动录制计划。** 在「主播监控」中可为主播设置录制时段，支持每周重复、指定日期、跨午夜和录至下播。也可以按直播标题中的关键词开录。同时填写时段和关键词时，仅在时段内匹配到任一关键词才开录。
- **直播周表识别。** 在录制计划编辑器中打开「周表识别」，拖入本地或网页上的周表图片，也可点击选择文件。Windows 在本机识别场次；可以对照原图核对日期和时间，改好后再加入计划。只有星期的场次可指定参考周。
- 主播监控页可直接打开专属设置。同样设置的主播可以合并显示，选择头像后可单独修改，也可以编辑整组。关注栏头像和托盘分组更清楚地标出监控与录制状态。

## 关注栏与房间管理

- 平台关注导入只添加新选中的主播，已有主播显示「已添加」，保留原有关注和归类。导入窗口调整了文件夹选择和账号信息的显示，方便核对导入目标。
- 添加直播间时可取消正在进行的查询，查询超时会结束等待。直播格确认下播后会显示「未开播」和替换入口。
- 修正按直播状态筛选时文件夹标题的计数，以及右键点击关注列边缘空白处无法新建文件夹的问题。竖屏窄窗口中，搜索和相邻按钮各有独立的点击区域，收起关注栏后仍可添加房间。

## 弹幕、醒目留言与窗口

- 拖动视频中的单条 SC 醒目留言卡时，复用卡片布局与裁剪结果，减少每次鼠标移动时的重绘。弹幕粉丝牌的名称和等级分开排版。
- 修正浮动弹幕四角露出矩形底色、右下角残留方点的问题，保留拖动窗口和拖动边角缩放。通知中心、账号登录窗口也调整了圆角边缘的绘制。
- 关闭主窗口时，询问隐藏到托盘还是退出程序的提示移到标题位置。主窗口保留原生标题栏，文件选择仍使用系统窗口。

## 设置与交互

- 减少从主播监控打开设置、切换设置菜单，以及打开插件独立窗口或切到插件页面时的重复工作。设置窗口已打开时，直接复用并定位到对应页。
- 兼容插件可接管录制参数的编辑。本体录制设置页会显示当前参数和管理它的插件名称，点「打开插件录制设置」即可前往修改。
- 文件夹图标、插件页签等控件补齐圆角的悬停、按下和选中反馈。切换深浅色时复用每格播放按钮的样式。同机 4×4 空墙对照中，每次重设样式表从 116 次降到 4 次，四次侧栏切换的同步耗时中位数从约 196 毫秒降到 146 毫秒。
- 空墙启动时按需加载播放器和音频组件，设置继续预热。同机开发版三轮 4×4 空墙对照中，主进程私有内存中位数从 315.0 MiB 降到 275.1 MiB。
- 「设置 → 外观 → 应用图标」提供三种图标，切换后窗口和系统托盘立即更新。软件更新页新增「接收插件 Preview 更新」开关，默认关闭。插件安装包可拖入插件页，删除确认框会标明插件名称；主动关闭某一版本的更新提醒后，软件会记住这个选择。

## 本体 MCP 与诊断

- 本体提供本地 MCP 服务，可连接正在运行的实例，读取格子和布局状态、切换布局、开关画中画、成组移除并撤销移除，也可打开指定设置页并查询当前页面。
- 可按格采集实际播放缓冲，记录关注卡片拖动、滚动和画中画选择面板打开时的响应。需要启动阶段的数据时，可通过 MCP 为下一次启动指定专项采集。

本次更新适用于 Windows 64 位桌面本体。独立插件沿用各自的版本和更新说明。
