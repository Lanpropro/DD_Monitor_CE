# DD监控室CE v1.0 更新说明

## 画面墙与播放

- B 站直播支持自动追帧。可在画面墙和画中画的右键菜单开关，缓冲积压时播放器会暂时加速追赶直播进度。
- 新增单格直播回看，可沿时间轴预览、回看和返回直播。画中画支持分区布局和窗内弹幕面板，单格移入、移出时减少整墙重排。
- 调整满墙跨屏、横竖屏切换和快速移动指针时的控制栏显示。缩小布局时仍按原规则清除超出容量的房间。
- 空画面墙启动时按需加载播放器和音频组件。设置继续在后台预热，以便首次打开。

## 主播监控与录制

- 支持自动录制计划、标题关键词和从周表图片识别排期。主播监控页可直接打开该页的专属设置。
- 关注列表的导入支持只添加新房间。添加房间时可取消查询，超时会结束等待。
- 托盘布局示意支持按格调节音量和静音，可按当前画面墙布局打开画中画。

## 设置与交互

- 设置复用已打开的窗口，并减少打开主播监控设置和切换插件页面时的同步界面工作。
- 调整浮动弹幕的圆角、缩放手柄和部分独立窗口的边缘。主窗口保留原生标题栏，系统文件选择器沿用 Windows 样式。
- 优化画面中单条醒目留言卡的拖动，补齐文件夹图标、插件页等控件的悬停、按下和选中反馈。深色和浅色主题都使用圆角样式。

开发者可通过本体 MCP 按格采样播放缓冲、观察页面和侧栏响应，以及成组移除和恢复画面。独立插件的安装包及更新说明由各插件另行提供。
