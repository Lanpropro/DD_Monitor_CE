## 实际使用方式

- 普通网格、大带小、镜像、弹幕和竖屏等多画面预设均可拖动内部边界；单画面没有内部可调边界。
- 相邻画面的边界按中线区分所属格子，悬停高亮对应格子的可调边缘。
- 同时有横、纵可调边的角落支持等比例缩放，比例以开始拖动时的格子宽高为准；只有一个可调方向时仍是单方向调整。外沿固定。
- 拖动时视频保持原尺寸，只更新移动边界的浅灰虚线；约每 32 毫秒合并一次拖动更新。松手后统一调整几何并保存，按 Esc 取消。
- 双击边框恢复相邻区域的默认比例；双击可调角落恢复两个方向。布局菜单中的“恢复默认比例”重置当前预设，其他预设不变。
- 每个预设分别保存比例，切换预设、缩放窗口、退出全屏和重启后恢复。配置无效时回落默认值。
- 这是内置预设的比例调整，尚不提供新增布局、任意挪格子、命名或删除自定义布局。

## 建议逐项手动测试

从当前源码目录运行 `run.cmd`；已经运行的进程需要重新启动才能载入本次代码。原先打包的 EXE 不会随源码修改自动更新。

1. **一大五小**：拖主画面右边、下边、右下角；再拖右侧两格和底部三格之间的边界，检查相邻格子铺满、没有重叠。
2. **拖动预览**：快速左右往返拖动，视频应保持原尺寸，只有移动边界出现虚线；松手、回原点和按 Esc 后均不应留下残影。
3. **角落与限制**：拖到相邻区域最小尺寸，检查角落宽高同步停止，单向边框不误触角落缩放。
4. **重置与保存**：分别调整两套预设，来回切换；双击局部边框，再使用布局菜单整体重置，确认其他预设的比例没有被改动；重启后检查保存结果。
5. **真实播放**：六路播放时拖动、切全屏并退出、交换直播间，检查画面持续播放，不因调比例重连，音量和声道没有被改变。
6. **横竖屏与弹幕**：测试普通网格、带弹幕、镜像及竖屏，检查主次画面、弹幕和窗口方向正常，格子中心与底部按钮仍可操作。
7. **现有功能**：深浅色及背景皮肤下检查边框与虚线可见性；收起关注栏再展开；悬停不同格子使用 B、M 等快捷键。
