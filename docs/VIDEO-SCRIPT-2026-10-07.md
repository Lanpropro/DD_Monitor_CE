# DD监控室CE｜跨平台直播与比赛二路宣传片

日期：2026-10-07（Asia/Hong_Kong）。状态：样片 04 修复 23–24 秒附近标题/视频交接和断音，其余段落保持样片 03，60 秒、1920×1080、30fps；保留用户字幕与国内/海外顺序，使用真实录屏且标注待替换素材。

本片让观看比赛的人看到：关注的直播可以放在同一页，同一场比赛也可以对齐时间、结合不同解说和弹幕一起看。

## 已确定的制作方向

- 目标时长 60 秒；采用 HTML / HyperFrames 动效，接入真实录屏，制作虚拟指针。沿用旧片的大字号中文、深灰、近白和青蓝强调色。
- 跨平台作为一项能力展示，包含国内平台、Twitch 与 YouTube；不拆成两个插件广告。
- 顺序为国内关注栏遍历 → 拉回全景 → 九格依次亮起 → 转场到海外九格 → 比赛二路 → 独立双解说试听（原声待补） → 本体更新总结与片尾。用户因海外素材质量再次交换国内/海外展示位置。
- 配乐已由用户选定：**Future Bass Tech Corporate — PaulYudin**。试听及来源：https://pixabay.com/music/beats-future-bass-tech-corporate-317806/ 。现已下载并接入独立样片工程，以检测拍网安排动作和音量包络。
- 用户授权人为截断、静音音乐制造突变。下表时间是剪辑结构预算，不是已经测出的音乐节拍；正式制作按音频重拍微调段落边界，维持约一分钟。
- 无旁白；当前素材没有直播原声，用户将补双解说原声。样片现阶段只有配乐，不制造解说声音。
- 用户已确认比赛二路基本开发完成；功能表现以最终录屏和验证结果为准，不沿用早期“尚未完成”的状态。

## 音乐断点的具体处理

样片 04 取消了 23.939–24.545 秒的二路断音，片中音乐连续。原平台切换的静音也已取消；开头 0.65 秒淡入，片尾淡出。

样片使用音乐源起点 0.706 秒，以 CLI 检测拍点安排动作；自动速度估计为 198 BPM，可能是双倍拍，尚未听辨确认主速度。静音采用音量包络，切口加 10ms 淡化；保持原拍点间距，通过静音后恢复原位置制造反差。正式精修仍需结合听感确认重拍和乐句。

关注栏拍摄要有九次可辨认的停留与连续滚动；不捏造未录到的点击。制作虚拟指针前处理录屏中的原指针，避免同时出现两个指针。九格“亮起”是剪辑揭示效果，不表示实测加载速度。

二路演示使用可实证的手动微调、同秒计时器与合并弹幕，不写“零延迟”“逐帧精准”“全自动无误差”。用户已确认基本开发完成，不等于这些性能指标已经验收；无声录屏不展示伪造音频波形或声道听感。

用户已指定本体更新总结为关注管理、画面弹幕、插件管理。对应本体更新记录见 `RELEASE-v0.3.md`；样片先用软件全景配准确文字，等待对应本体操作录屏替换，不把插件功能列入本体总结。
