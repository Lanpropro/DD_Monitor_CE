# DD监控室CE｜跨平台直播与比赛二路宣传片

日期：2026-10-07（Asia/Hong_Kong）。状态：完整脚本初稿，供用户修改；尚未制作或渲染新片。

本片让观看比赛的人看到：关注的直播可以放在同一页，同一场比赛也可以对齐时间、结合不同解说和弹幕一起看。

## 已确定的制作方向

- 目标时长 60 秒；采用 HTML / HyperFrames 动效，接入真实录屏，制作虚拟指针。沿用旧片的大字号中文、深灰、近白和青蓝强调色。
- 跨平台作为一项能力展示，包含国内平台、Twitch 与 YouTube；不拆成两个插件广告。
- 顺序为海外关注栏遍历 → 拉回全景 → 九格依次亮起 → 转场到国内九格 → 比赛二路 → 更新总结与片尾。
- 配乐已由用户选定：**Future Bass Tech Corporate — PaulYudin**。试听及来源：https://pixabay.com/music/beats-future-bass-tech-corporate-317806/ 。本次只写脚本，没有下载、试听分析或剪辑这首音乐。
- 用户授权人为截断、静音音乐制造突变。下表时间是剪辑结构预算，不是已经测出的音乐节拍；正式制作按音频重拍微调段落边界，维持约一分钟。
- 默认无旁白，无直播原声，以音乐、简短字幕和少量动作音效叙事。音效不能冒充素材中实际录到的声音。
- 用户已确认比赛二路基本开发完成；功能表现以最终录屏和验证结果为准，不沿用早期“尚未完成”的状态。

## 音乐断点的具体处理

只安排两个主要断点，避免全片频繁停顿。九格亮起使用音乐本身的拍点，不再另切一次音乐。

1. **海外切国内（21–24 秒段内）**：先试半拍左右的静音；面板开始掠过时收声，国内画面完成揭示时接回重拍。
2. **二路登场（27–31 秒段内）**：先试一拍左右的静音，比前一次长。音乐收住时出现“同一场比赛”，接回重拍时揭示两个解说来源。

正式制作先确定音频截取范围、重拍和乐句，再给出精确时间。静音采用短音量包络，切口加约 5–15ms 的淡化避免爆音；优先保持原拍点间距，通过静音后恢复原位置制造反差。需要重排乐句时只在可衔接的乐句边界剪接，不任意错开半个鼓点。半拍/一拍不换算成固定秒数，因为本轮尚未实测 BPM。

二路演示使用可实证的手动微调、同秒计时器与合并弹幕，不写“零延迟”“逐帧精准”“全自动无误差”。用户已确认基本开发完成，不等于这些性能指标已经验收；无声录屏不展示伪造音频波形或声道听感。

## 制作前后验收

- 分镜时间从 0 连续覆盖至 60 秒；音乐卡点微调后仍约一分钟，关键文字可读。
- 关注栏遍历与虚拟指针轨迹对应真实录屏，海外→国内顺序正确，两次转场前后布局对位。
- 新增素材核验后再定源范围；国内素材未齐时只能做注明缺素材的预览，不交付冒充完整实录的成片。
- 计时器、偏移值、来源标签与真实软件内容一致，合并弹幕有持续运动。
- 配乐来源与下载授权凭证随制作素材保存；本轮只完成脚本，尚无已剪音乐、HTML 成片或新视频输出。
