## 已确定的制作方向

- 目标时长 60 秒；采用 HTML / HyperFrames 动效，接入真实录屏，制作虚拟指针。沿用旧片的大字号中文、深灰、近白和青蓝强调色。
- 跨平台作为一项能力展示，包含国内平台、Twitch 与 YouTube；不拆成两个插件广告。
- 顺序为国内关注栏遍历 → 拉回全景 → 1+5 六窗依次亮起 → 转场到海外九格 → 比赛二路 → 独立双解说试听（原声待补） → 本体更新总结与片尾。用户因海外素材质量再次交换国内/海外展示位置。
- 配乐已由用户选定：**Future Bass Tech Corporate — PaulYudin**。试听及来源：https://pixabay.com/music/beats-future-bass-tech-corporate-317806/ 。现已下载并接入独立样片工程，以检测拍网安排动作和音量包络。
- 用户授权人为截断、静音音乐制造突变。下表时间是剪辑结构预算，不是已经测出的音乐节拍；正式制作按音频重拍微调段落边界，维持约一分钟。
- 无旁白；当前素材没有直播原声，用户将补双解说原声。样片现阶段只有配乐，不制造解说声音。
- 用户已确认比赛二路基本开发完成；功能表现以最终录屏和验证结果为准，不沿用早期“尚未完成”的状态。
