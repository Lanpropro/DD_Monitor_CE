# 架构文档

本目录说明系统如何组成，以及修改时边界在哪里。它不替代代码、文件清单和单功能设计文档。

| 文档 | 内容 | 何时读 |
| --- | --- | --- |
| [架构总览](overview.md) | 进程、分层、启动关闭、职责域、状态所有权、关键数据流 | 第一次参与本体开发；跨模块改动前 |
| [仓库文件分类清单](../repository-map.md) | 全部已跟踪文件与目录归属 | 找文件、判断是否该提交 |
| [插件接口](../plugins.md) | 宿主与插件的公开契约 | 改插件接口或写插件 |
| [开发文档规范](../standards/documentation.md) | 文档分层、元信息、写作与校验规则 | 新增或整理文档 |

## 维护约定

- 架构变化（新增进程、改变依赖方向、迁移状态所有权）与代码同批更新本目录。
- 不在这里复制完整文件清单；文件归属以[仓库文件分类清单](../repository-map.md)为准。
- 单功能的交互与验收写在对应设计文档（如[画中画](../picture-in-picture.md)、[直播间组合](../room-presets-design.md)），
  架构页只保留结构与边界。
- 修改后运行 `python dev/selfcheck_documents.py` 与 `python dev/run_checks.py --suite repository`。
