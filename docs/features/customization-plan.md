# 自由布局编辑器计划

> 类型：设计 ｜ 状态：草案 ｜ 适用版本：0.7.x ｜ 更新：2026-11-15 ｜ 读者：维护者、布局开发者

本页只记录尚未实现的自由布局编辑器。2026-10 的深浅色、皮肤和直播间组合预设实施过程见[历史计划](../archive/customization-plan-202610.md)；现行外观功能见[皮肤与美化包](skins.md)，早期设计见[深浅色与文件夹图标设计](appearance-design.md)。

## 与已有布局功能的区别

- 内置布局预设提供固定格子排布和比例调整。
- [直播间组合预设](room-presets-design.md)保存当前主播、格子位置与大小的快照，供之后恢复；它不创建新的行列或跨格结构。
- 自由布局编辑器拟允许用户创建、命名、修改和删除新的格子结构，目前尚未实现。

## 拟实现范围

- 编辑行列、格子位置、跨行跨列和主次画面比例，实时预览结果；自定义布局与内置预设一起显示在布局入口。
- 分别保存横屏与竖屏布局，先定义两种方向之间的对应关系，避免切换方向时任意替换。
- 沿用最多 16 路的限制，拒绝越界、重叠和无效结构；保留内置布局。
- 切换时保留新布局能容纳的现有直播，新增格子为空；缩减格子沿用现有播放和录制收尾规则。
- 首版以网格编辑为边界，自由悬浮窗口和布局共享不在本计划范围。

## 实现前需明确

- 布局数据结构与旧配置迁移；横竖屏对应和格子索引稳定性。
- 缩减格子时直播与录制的处理，以及用户可见的确认方式。
- 与直播间组合快照的关系：快照引用自定义布局时，布局被编辑或删除后的恢复规则。

验收应覆盖创建、修改、命名、删除、重启恢复、横竖屏切换、扩容空格、缩减时录制收尾、拖放换房间及全屏；非法布局不得破坏已有配置。实施前按当前源码重新核对模块职责和状态所有者，不沿用历史计划中的旧文件入口清单。
