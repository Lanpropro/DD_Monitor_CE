本页记录当前主题与文件夹图标的交互和维护边界。2026 年 10 月的实施过程、当时的性能测量及旧 Qt／VLC 环境说明已移入[历史外观实施记录](../archive/appearance-implementation-202610.md)。背景媒体、分区美化和皮肤包格式见[皮肤与美化包](skins.md)。

## 深浅色模式

设置 → 外观可选择深色、浅色或跟随系统。配置保存用户的选择；缺失或非法值回退深色。跟随系统时响应 Qt 的系统配色变化，无法识别时使用深色。颜色令牌、主题应用和系统模式监听以 `ddm/theme.py` 为准，页面不自行维护另一套配色表。

浅色模式使用冷灰色窗口与侧栏、白色卡片、蓝色操作色和粉色直播强调色；深色模式沿用现行主题。文字、悬停、选中和焦点状态均需保持可辨认。原生视频画面不随主题重新着色；切换主题时保留播放器、录制和弹幕会话。

主窗口和设置页的按钮触发主题扩散过渡；键盘操作、启动恢复及系统关闭动画时立即切换。过渡只处理界面快照，视频区域保持透明，移动、缩放、隐藏或关闭窗口时清理快照。动效由 `ddm/theme_transition.py` 和 `ddm/motion.py` 维护。

当前打包与开发依赖均以根目录 `requirements.txt` 和发布构建脚本为准；历史记录中的 Qt 6.9 与 VLC 描述不作为现行运行环境说明。

「设置 → 外观」的毛玻璃开关和底色不透明度同时用于这些界面：

| 界面 | 材质 |
| --- | --- |
| 设置窗口、公告详情、直播流信息 | Windows 系统模糊，平台不支持时使用纯色。 |
| 通知菜单、播放格弹幕设置、画质菜单、B 站礼物与表情面板 | 圆角半透明底色。底色保留最低不透明度，以便在明暗变化的画面上读清内容。 |

画面右上角的画质、重连和关闭按钮使用深色直播标题同款的固定底色 `#15171C`。

## 应用图标

在「设置 → 外观 → 应用图标」切换「A · DD娘1」「B · DD娘2」或「C · 经典DDCE」。默认选中 A。选项自动保存并立即应用到运行中的窗口和系统托盘，重启后恢复选择。A 和 B 的小尺寸图案使用更窄的留边，并同步用于窗口、任务栏和系统托盘。Windows 从 EXE 或安装器读取的文件图标使用 A。

图标资源由 `dev/tools/build_brand_assets.py` 生成。D 和 B 的图稿位于 `design/icon-concepts/`，F 沿用 `assets/logo.svg`。侧栏品牌图继续使用 `assets/logo.png`。

## 文件夹图标

普通和智能文件夹可从右键菜单打开「修改图标…」。内置图标包括文件夹、星标、爱心、游戏、音乐和视频，可选择默认或预设颜色；也可导入 PNG、JPEG、ICO。预览只修改草稿，保存后应用，取消保留原配置，恢复默认在保存后生效。

导入图片保持比例并保留透明度，保存为数据目录 `utils/folder-icons/` 下的独立 PNG；配置只保存相对文件名。源图片之后移动或删除不影响已保存图标。缺失或损坏的已保存图片回退默认图标；输入上限与格式校验由 `ddm/folder_icons.py` 负责。

修改图标不改变文件夹的展开、排序、拖放或关注归属。智能文件夹保留类型提示，选中与键盘焦点也不能只靠颜色区分。

## 维护与验收

- 主题变更检查 `ddm/theme.py`、`ddm/theme_transition.py`、自绘控件与局部样式；文件夹图标变更检查 `ddm/folder_icons.py` 和关注栏保存流程。
- 运行 `python dev/run_checks.py --script selfcheck_theme_palette`、`python dev/run_checks.py --script selfcheck_theme_wave` 与 `python dev/run_checks.py --script selfcheck_folder_icons`，核对配色、过渡和图标保存回归。
- 从根目录 `run.cmd` 人工检查深浅切换、系统模式、横竖屏、文件夹图标保存与重启恢复，以及多路播放时的音画连续性。外观页滚轮仍待修复，见[BUG-072](../bug-cases.md#2026-11-15-外观页滚轮反馈)。
