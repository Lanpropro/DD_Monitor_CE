## 现有控件盘点

以 [共用界面组件](../development/ui-components.md)和 [`ddm.ui` 公开入口](../../ddm/ui/__init__.py)为边界，共 36 个导出，包含控件、组合及绘制辅助函数。每项有独立的深浅主题示例，采用本次候选样式。独立插件专属界面与私有页面控件另有各自的用途和生命周期。

| 范围 | 已有出口 | 评审关注 |
| --- | --- | --- |
| 基础与承载 | `ActionButton`、`TitleLabel`、`HintLabel`、`page_header`、`ElidedLabel`、`SettingsSurface`、`continuous_path`、`Avatar`、`RoomStrip`、`PinnedArc`、`circular_pixmap` | 字号层级、圆角、分组和头像标识；长标题的降级表现 |
| 筛选与表单 | `ToggleSwitch`、`SegmentedControl`、`SelectControl`、`FontSelectControl`、`step_button`、`StepperControl`、`SettingsSlider`、`SettingsValueLabel`、`ColorDialog`、`ScaleCurveControl` | 标签与控件对齐、数值反馈、键盘焦点、禁用状态 |
| 导航与反馈 | `SettingsProgressBar`、`DisclosureButton`、`AnimatedDialog`、`AnimatedMenu`、`SlidingTabs`、`SettingsStack`、`BarIconButton`、`NavigationButton` | 层级、当前项、进度与弹层出现后的可操作性 |
| 播放控件 | `TileButton`、`VolumeButton`、`RecordingButton`、`SidebarToggleButton`、`PauseButton`、`RefreshButton`、`DanmakuToggleButton` | 鲜亮与复杂视频背景下的可读性，开启与暂停的语义 |

## 视频的十一项落实在哪里

| 视频主题 | 本稿可检查的决定 |
| --- | --- |
| 可供性与操作提示 | 图鉴以分段选择为首个示例。共同底板表示同一组选项，选中块表示当前选择，变淡表示禁用。组外的「刷新」具有独立反馈。 |
| 视觉层级 | 设置页从页头、分组到行；播放格先看视频，再扫状态和控制栏。 |
| 网格、布局与间距 | 设置行固定左右关系，组间留白大于组内间距；窄幅浏览时两主题纵向排列。 |
| 字体与字号 | 页标题、组标题、行标签、说明四层；音量和分辨率采用等宽数字。 |
| 色彩理论 | 蓝色用于交互与焦点，绿色用于已保存和直播，红色用于失败与危险；状态同时有文字或形状。 |
| 深色模式 | 深色靠表面明度差分层，浅色靠边框和轻阴影区分浮层，两者共享交互层级。 |
| 阴影 | 窗口与弹层有轻投影；组内靠边框和留白。 |
| 图标与按钮 | 图标尺寸、文字、命中区分别设定；按钮状态图并排比较主、次、危险和图标样式。 |
| 反馈与状态 | 按钮图有七种状态；播放格可切换播放、连接和失败并演示重连。 |
| 微交互 | 按下收缩、开关滑块与重试状态转换提供短反馈；浏览器减少动态效果设置生效。 |
| 遮罩／覆盖层 | 在视频顶部和底部渐变衰减，仅控制区域多一层局部底板，中央画面保留。 |

思路来自[《10分钟讲解所有UI/UX概念》](https://www.bilibili.com/video/BV17vXGBaEhR/)和 [Kole Jain 原版](https://www.youtube.com/watch?v=EcbgbKtOELY)。播放格取自项目[已公开截图](../assets/screenshots/overview1_Landscape_mode.png)，作为叠层静帧示例。样板使用现有「常规」选项中的代表项，并排展示同一组值。

## 请确认的设计决定

1. 冷蓝主色与灰蓝面板是否适合 DD 监控室。分别检查深浅主题里的层级和强调程度。
2. 「常规」页面的分组密度、窗口导航和控件大小是否合适。改变音量、开关和刷新间隔可观察两边同时变化。
3. 播放格上下遮罩是否影响画面观感。切到「播放失败」，点击「重新连接」观察等待和恢复。
4. 从按钮状态图确认主、次、危险、图标样式，以及哪个焦点或禁用状态需要加强。选中样张用于比较色彩，实际只有具备持续选中语义的控件采用该状态。
5. 对七个设计候选确定首批范围。确认后的实际验收采用根 `run.cmd` 与相关专项，分别检查键盘、深浅色、DPI、原生视频叠层和多画面场景。
