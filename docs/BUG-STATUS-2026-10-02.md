## 本轮人工测试：全屏指针

1. 关闭旧程序，用项目根目录的 `run.cmd` 启动，播放任意直播。
2. 点击音量条右侧全屏按钮，鼠标停在画面中央约 3 秒，指针、右上按钮、人数/标题/时长浮层及底部控制栏应一起隐藏，视频占用底部空间。
3. 移动鼠标，指针和控件应一起恢复；移到音量条或右上角操作按钮上，静止 3 秒仍应可见并能操作。
4. 画面右键打开菜单，指针应保持可见；关闭菜单后移回中央，应再次正常隐藏。
5. 用 Alt+Tab 切到其他窗口，指针应恢复；回到软件继续检查。
6. 按 Esc 退出全屏，指针应恢复；重复进入、退出，并在全屏时关闭软件，其他窗口指针应正常。
7. 用户常用的 Windows 175% 缩放下，在横屏、竖屏分别重复上述操作。

自动验证：`dev/selfcheck_fullscreen_cursor.py` 实际 VLC 视频播放、Windows 原生光标隐藏与恢复、控件、菜单、模态对话框及退出/关闭清理；另回归格子全屏快捷键和全屏声音状态。

## 2026-10-03 人工测试：弹幕连接状态

1. 用 `run.cmd` 启动，切换到弹幕布局，选择一个正在开播的 B 站房间。
2. 右上角应先显示“连接中”，鉴权成功后显示“已连接”；收到消息后旁边不再出现弹幕数量。
3. 若已连接但暂时无新消息，内容区应显示“等待弹幕”，不再显示“正在连接”。
4. 临时断开网络，等待程序检测到连接断开，观察准备重连/重连中的状态；恢复网络后成功鉴权才显示已连接。断线检测不是即时发生的，不用直播画面本身的缓冲状态判断弹幕连接。
5. 切换主画面对应房间，检查旧连接状态不会覆盖新房间；重连时旧弹幕内容应保留。
