## 本轮人工测试：全屏指针

1. 关闭旧程序，用项目根目录的 `run.cmd` 启动，播放任意直播。
2. 点击音量条右侧全屏按钮，鼠标停在画面中央约 3 秒，应隐藏。
3. 移动鼠标，应重新出现；移到音量条或右上角操作按钮上，静止 3 秒仍应可见并能操作。
4. 画面右键打开菜单，指针应保持可见；关闭菜单后移回中央，应再次正常隐藏。
5. 用 Alt+Tab 切到其他窗口，指针应恢复；回到软件继续检查。
6. 按 Esc 退出全屏，指针应恢复；重复进入、退出，并在全屏时关闭软件，其他窗口指针应正常。
7. 用户常用的 Windows 175% 缩放下，在横屏、竖屏分别重复上述操作。

自动验证：`dev/selfcheck_fullscreen_cursor.py` 实际 VLC 视频播放、Windows 原生光标隐藏与恢复、控件、菜单、模态对话框及退出/关闭清理；另回归格子全屏快捷键和全屏声音状态。
