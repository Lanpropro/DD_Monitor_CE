RECORD / REPLAY

错过三分钟，
也能倒回来。

每一路都能独立录制，也可以随时留下最近几分钟的即时回放。 录制和导出跑在独立的 FFmpeg 进程里，关掉软件就一起收尾。

RECORD / REPLAY

默认 MP4 原画直存，不重编码；需要时再切 H.264 和显卡编码。 即时回放跟着录制自动开，右键就能保存最近一段。

  • 独立 / PER TILE每格单独录，不混流
  • 原画 / DIRECT原始流直存，画质不二次损失
  • 回放 / BUFFER最近数分钟随时保存
  • 收尾 / CLEAN EXIT主程序退出，后台进程一起结束
