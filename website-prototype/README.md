# DD监控室 CE · 展示页原型 02

这是第二版展示页原型，用来确认新的视觉方向。第一版「广播控制台 / 工业机架」已经不适合软件气质，
保留在提交 `557d595` 中，本版不再沿用。

## 这次换了什么

**从「控制室」换成「夜色直播厅 / Live Stage」。**

软件本身是深色、圆角、偏二次元/游戏直播的 Windows 工具，第一版却用了暖黑、信号橙、
大字重黑体、机架和通道条，视觉上更像一台工业设备。这一版把页面放回用户熟悉的语境：

- **深蓝夜色底**，青蓝与珊瑚粉的柔光从画面里透出来，不再用橙黑对比和硬朗边框。
- **圆角玻璃卡片 + 悬浮直播窗口**，画面像桌面上摆着的一叠直播窗口，而不是插在机柜里的监视器。
- **微软雅黑 + Bahnschrift + Cascadia Mono**，标题更松弛，数据只保留少量等宽字。
- **真实软件截图**继续作为视觉主体，不画假 UI。
- 插件区单独做成一块**奶油色积木货架**，在一整页深色里形成呼吸点，也跟「插件 = 扩展」的心理模型更贴。

主标题也换成了更轻松的表达：

> 把喜欢的直播，  
> 摆成**你的样子**。

「你的样子」用青蓝到珊瑚粉的渐变，语义上落在“布局和观看方式由你决定”，不是“控制台/调度”。

## 动效与交互

零依赖 HTML / CSS / 原生 JS，`prefers-reduced-motion` 可关闭全部动效。

1. **首屏入场**：文案从下方淡入，右侧画面墙从 0.97 倍浮上来，持续 1.1s。
2. **视差**：指针在画面墙区域移动时，主窗口轻微旋转 / 平移，离开后回位；移动端关闭。
3. **氛围光**：青蓝、粉、淡紫的柔光块缓慢漂移；通道灯、REC 点脉冲。
4. **布局切换**：01–04 按钮切换真实截图和说明，竖屏模式自动收进黑色舞台；也可用 `?mode=portrait` 直接打开。
5. **控制微交互**：L/R、录制、插件开关都有真实状态；保存片段按钮有“已加入导出”反馈。
6. **截图模式**：`?capture=1` 冻结装饰性动画，并让首屏直接呈现最终构图。

## 预览与验收

直接双击 `index.html`；也可以在仓库根目录启动静态服务：

```powershell
python -m http.server 8080 --directory website-prototype
```

打开 `http://127.0.0.1:8080/`。

重新生成素材与截图（Windows，需要本机 Chrome 或 Edge）：

```powershell
python website-prototype/build_assets.py
node website-prototype/capture.mjs
python website-prototype/test_prototype.py -v
```

`capture.mjs` 会：

- 在 320 / 375 / 414 / 768 / 1024 / 1440 六个宽度检查横向溢出；
- 检查所有图片是否加载成功；
- 收集浏览器运行时错误；
- 输出 `shots/desktop.png`（1440 宽整页）与 `shots/mobile.png`（390 宽整页）。

当前已通过：六档宽度无横向溢出、图片全部加载、无浏览器错误。

## 原型的边界

- 截图来自仓库现有素材，可能不是当前最新构建；正式上线前应重新截图/录屏。
- 「平分布局」和「大带小」目前共用一张横屏截图，正式站点应分别补真实截图。
- 插件卡片目前是两枚官方插件 + 一条“你的插件”入口的结构示意，正式页应由插件目录数据生成。
- 插件能力按公开文档的已实现接口描述；没有把开发中的能力写进页面。
- 下载按钮指向真实 GitHub Releases；没有接版本 API、下载统计或系统探测。
- 预览没有做移动端折叠菜单、插件搜索、多语言、后台 CMS 或部署配置。
- 字体使用 Windows 系统字体；正式站点应自托管中文 webfont，避免跨平台差异。
- 截图统一使用 `?capture=1` 的冻结状态；直接打开 `index.html` 可看到真实动效。
