# Flutter 移动端预览

Android 与 iOS 共用 Dart 界面、布局、关注状态与匿名 B站取流逻辑。
播放器通过 video_player 使用 Android Media3 / iOS AVPlayer。

## 本版功能

- 四个浮动 Dock 入口：直播墙、关注、插件、设置。
- 深色界面；导航、布局选择器和浮层使用 Flutter 模糊、半透明填充与边缘高光近似玻璃材质。不是 Apple 原生 Liquid Glass；高对比度或“减少透明效果”改用实色。
- 单画面、主画面加双画面、四宫格布局。自动布局在手机用主次三格、宽屏用四格；已有第四格时窄屏继续显示四格，避免隐藏播放。
- 关注使用 16:9 整张封面大卡片，名字、标题、状态叠在封面上；手机单列、平板多列。开播时优先使用实时 keyframe，否则使用封面，与桌面端一致。
- 手动输入公开数字房间号保存本机关注；搜索、开播筛选、下拉刷新、每60秒更新前台状态。失败时标明待更新，不继续显示旧的开播状态。
- 点击开播卡片后展示当前布局的空间缩略图，点击空位播放，替换已有画面需要确认。同一主播移动到新位置时清空旧位置。
- 各路可暂停、继续、静音、移除和全屏；默认只有位置1出声，切换声音时关闭其他路。后台释放播放器，返回恢复各路原有的暂停与静音状态。
- 本机保存关注列表、默认布局和减少透明效果；启动时不自动播放上次的房间。
- 插件页展示实际内置的 B站平台源；插件商店、可下载插件、弹幕与开播通知尚未接入，不显示假开关。

不读取或同步桌面/B站账号、Cookie、本机插件，不发送弹幕；没有录制或回放。
iOS 工程已生成，最低 iOS15；Windows 上不能完成 iOS 构建、签名或设备验收。

## 开发与验收

使用 Flutter3.47.9 / Dart3.13.7、JDK21、Android SDK36、NDK28.2.13676358、CMake3.22.1及项目 Gradle wrapper。
最低 Android7.0/API24；APK 包含 arm64-v8a、armeabi-v7a、x86_64，预览使用独立应用 ID 与 debug 签名。

将 Flutter SDK 的 bin 加入 PATH；仓库根目录 `run.cmd --mobile` 启动移动端，多设备时按提示选择。
`run.cmd` 不带参数继续启动 Windows 客户端。SDK、Pub/Gradle 缓存与 AVD 可放到其他磁盘，不提交本机路径。

在本目录执行：

```powershell
flutter pub get
flutter analyze
flutter test
flutter test integration_test/watch_test.dart -d emulator-5554
flutter build apk --debug
```

离线测试覆盖匿名接口、封面/直播截图选择、关注持久化、状态失效、布局空间对应、占位替换确认、搜索筛选、声音互斥、大字号与手机/平板尺寸。
设备集成测试匿名访问公开房间6和55，验证真实封面卡片、选位、两路播放、Dock保留、暂停/静音状态的后台恢复与停止；停播或网络异常会导致失败。
构建产物在 `build/app/outputs/flutter-apk/app-debug.apk`。安卓真机、长时间与四路解码能力仍需分别验收，不能由模拟器两路实播推断所有设备支持四路。

人工验收：关注页添加数字房间号 → 查看封面大卡片 → 点卡片与目标位置 → 切换布局/声音 → 暂停和后台返回 → 全屏返回 → 移除画面 → 重新启动检查关注仍在。
关注与选位的所有图片都来自公开接口；空列表和图片加载失败显示明确空态，不内置虚构主播。

旧 Kotlin/Chaquopy 原型位于 Git 提交86f841c，当前移动端入口为本目录。
