# DD监控室CE 诊断工具 1.2

双击 `DDMonitorDiagnostics.exe`，无需安装 Python 或启动主软件。使用 Windows 自带的 .NET Framework / WinForms，支持目标为 Windows 10、11；Win10 实机验证仍待完成。

1. 首次启动自动查找软件目录：检查工具所在目录、正在运行的主程序位置、安装记录及默认安装目录，并检查工具附近的 `result/`、`results/` 解压目录（最多向下 3 层、检查 512 个目录，跳过链接与运行数据），不扫描整块硬盘。多个候选时选择目标目录；未找到时可浏览手动选择，或点击“自动查找”重试。
2. 选择诊断包保存位置，填写问题发生时间、操作步骤、实际表现及预期结果。
3. 在问题描述下选择“稳定复现”“概率触发”或“尚未确认”。点击“添加图片”，或从资源管理器将图片文件拖到附件区，添加后显示缩略图；单击缩略图打开大图预览（Esc 关闭），点击每张图右上角的 × 删除附件，不删除原图。也可按 Delete 移除当前选中的附件。同一文件不会重复添加。支持 PNG、JPG、BMP、GIF；最多 5 张，每张原图及转换后不能超过 20MB，转换后合计最多 50MB。单边不超过 8192 像素、像素总数不超过 4000 万。GIF 只保留首帧。
4. 点击“生成诊断包”。完成后查看摘要和收集提示，检查 ZIP 内容，再手动发送给维护者。可勾选“生成成功后自动退出”（默认关闭，仅本次窗口有效）；成功保存 ZIP 后工具自动关闭，失败时保留窗口供重试。自动退出后仍可在选定保存位置找到 ZIP 并检查内容。GUI 使用与主软件接近的深灰底色、蓝色强调色与圆角按钮。

工具不联网，不修改配置，不启动或关闭主软件，不需要管理员权限。附件会将实际图片内容放入 ZIP，不只是文件名；“添加”或“拖入”不会自动上传。部分系统信息无法访问时会记录提示，其余内容继续收集。保存目录无法写入时，可换一个目录重试。

## 收集内容

| 文件 | 内容 |
| --- | --- |
| `诊断摘要.txt` | 问题描述、文件说明、缺失或无法收集的内容 |
| `problem.json` | 发生时间、问题描述、复现情况、附件列表、收集时间与工具版本 |
| `attachments/` | 用户手动添加的问题图片，重新编码为 PNG，去除 EXIF 等元数据；不自动遮挡图片中的个人信息 |
| `system.json` | Windows 版本、架构、CPU、内存、显卡型号与驱动 |
| `software.json` | EXE/源码/构建版本、更新说明标题、关键程序文件版本与 SHA256、当前程序清单缺失项 |
| `native-dependencies.json` | 独立子进程中的 libmpv 实际加载结果、位数检查、Win32 错误码、直接依赖 DLL 和缺少的函数入口；同时记录系统及软件目录的 Vulkan 加载器是否存在 |
| `config/` | 当前配置及备份的脱敏副本；损坏或过大的配置不收集原文 |
| `plugins.json` | 已安装插件 ID 与版本；启用状态见配置中的 `plugins_enabled` |
| `platform-diagnostics.json` | 自动汇总已收集日志中的平台响应、查询、取流、画质和播放器诊断，按阶段计数并保留最多1000条脱敏记录；用户无需手工筛选标记行。缺少记录不代表正常，不自动判定根因 |
| `recording/`、`recording-diagnostics.json` | 从当前配置指定录制目录的 `.ddm-parts` 读取最近5份FFmpeg `.log`，每份仅末尾2MB；匿名编号并脱敏链接、Cookie和路径，另保留HTTP403及URL的 `expires` Unix秒数。跳过链接目录和文件，不读取视频分片 |
| `logs/`、`ddm-pyinstaller-paths.txt` | 最多五份主程序/更新日志，兼容日期日志、轮转备份与 PR61 文件名，优先当前崩溃日志，其余按时间排序；每份仅末尾 2MB，以及已有启动路径日志 |
| `processes.json` | 匹配所选安装路径的主程序进程、内存与启动时间 |
| `crash-events.json` | 最近七天内与所选安装路径匹配的 Windows Application 事件，最多三十条 |
| `collection.json` | 收集限制、警告与隐私范围 |

不读取账号文件、插件私有配置、弹幕聊天记录、录制视频、缓存或内存转储，不自动截取桌面。仅收集近期录制FFmpeg日志，不收集视频。只打包手动选择的图片，请添加前遮挡个人信息。过滤配置与日志中常见的凭据字段、链接、本机路径及用户/计算机名称。自由文本可能包含其他个人信息，自动脱敏不能替代发送前检查；请勿在问题描述中填写密码或 Cookie。

程序清单只检查文件是否存在；关键文件计算的 SHA256 供维护者对照正式包，并不自动判定文件正确。DLL 检测会在隔离子进程中加载所选软件的 libmpv 及其直接依赖，执行库的初始化代码，但不启动主程序、播放器实例或用户插件；最长等待 10 秒，崩溃或超时会记录结果，其余内容继续收集。请只选择可信的软件目录。可检测缺少 Vulkan 等加载依赖或函数入口；它不穷举间接和延迟加载依赖，加载成功也不保证实际播放正常。摘要会列出加载状态和异常依赖。未发现崩溃事件不能证明未崩溃，工具不还原崩溃前内存。

## 1.2 更新

包含 libmpv 原生依赖与函数入口检测、平台查询及播放日志摘要、跨日期日志中最新平台事件保留、PR61 轮转日志兼容，以及安装版和便携版数据目录识别。与本次主软件候选包从同一提交重新构建，Win10 最终验收后再上传。

## 开发

从仓库根目录执行 `powershell -NoProfile -File dev/build_diagnostics.ps1`，验收前默认产物在 `work/diagnostics-preview/`，不写入 `results/`。独立工具可单独分发；主软件发布脚本会从同一 HEAD 源码快照构建诊断工具，附带到源码包、EXE 便携包和安装包，纳入程序文件清单。不会替换已经发布的历史包。

验证：`python dev/selfcheck_diagnostics.py`。使用临时模拟软件目录，验证目录候选筛选、相邻解压目录及带末尾斜杠的启动路径、统一深色滚动条的滚动与边界、复现选项、图片重编码与大小限制、ZIP、凭据脱敏、配置损坏、缺少日志、文件链接与保存失败；不读取真实账号配置或启动主软件。
