# DD监控室CE 诊断工具

双击 `DDMonitorDiagnostics.exe`，无需安装 Python 或启动主软件。使用 Windows 自带的 .NET Framework / WinForms，支持目标为 Windows 10、11；Win10 实机验证仍待完成。

1. 选择主软件所在文件夹。工具放在主程序旁时会自动填写。
2. 选择诊断包保存位置，填写问题发生时间、操作步骤、实际表现及预期结果。
3. 点击“生成诊断包”。完成后查看摘要和收集提示，检查 ZIP 内容，再手动发送给维护者。

工具不联网，不修改配置，不启动或关闭主软件，不需要管理员权限。部分系统信息无法访问时会记录提示，其余内容继续收集。保存目录无法写入时，可换一个目录重试。

## 收集内容

| 文件 | 内容 |
| --- | --- |
| `诊断摘要.txt` | 问题描述、文件说明、缺失或无法收集的内容 |
| `problem.json` | 发生时间、问题描述、收集时间与工具版本 |
| `system.json` | Windows 版本、架构、CPU、内存、显卡型号与驱动 |
| `software.json` | EXE/源码/构建版本、更新说明标题、关键程序文件版本与 SHA256、当前程序清单缺失项 |
| `config/` | 当前配置及备份的脱敏副本；损坏或过大的配置不收集原文 |
| `plugins.json` | 已安装插件 ID 与版本；启用状态见配置中的 `plugins_enabled` |
| `logs/`、`ddm-pyinstaller-paths.txt` | 最多五份近期主程序/更新日志，每份仅末尾 2MB，以及已有启动路径日志 |
| `processes.json` | 匹配所选安装路径的主程序进程、内存与启动时间 |
| `crash-events.json` | 最近七天内与所选安装路径匹配的 Windows Application 事件，最多三十条 |
| `collection.json` | 收集限制、警告与隐私范围 |

不读取账号文件、插件私有配置、弹幕聊天记录、录制、缓存、桌面截图或内存转储。过滤配置与日志中常见的凭据字段、链接、本机路径及用户/计算机名称。自由文本可能包含其他个人信息，自动脱敏不能替代发送前检查；请勿在问题描述中填写密码或 Cookie。

程序清单只检查文件是否存在；关键文件计算的 SHA256 供维护者对照正式包，并不自动判定文件正确。未发现崩溃事件也不能证明未崩溃。此工具收集已有线索，不还原崩溃前内存，不自动诊断根因。

## 开发

从仓库根目录执行 `powershell -NoProfile -File dev/build_diagnostics.ps1`，默认产物在 `results/diagnostics/`。独立工具可单独分发，不改动既有正式版安装包。

验证：`python dev/selfcheck_diagnostics.py`。使用临时模拟软件目录，验证 ZIP、凭据脱敏、配置损坏、缺少日志、文件链接与保存失败；不读取真实账号配置或启动主软件。
